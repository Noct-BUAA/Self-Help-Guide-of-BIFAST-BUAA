    一、单选题（共 5 题，总分：25.00）¶

    1. （5.00 分）¶

    以下关于浮点数的描述，正确的是？

    • A. 浮点数可以精确表示所有实数。
    • B. 在Python中，123e+2表示一个整数。
    • C. 浮点数运算可能存在精度问题。
    • D. 浮点数在内存中通常占用比整数更少的空间。

    正确答案：C

    答案解析： 浮点数由于其表示方式，无法精确表示所有实数，且在进行运算时可能会出现精度损失。

    2. （5.00 分）¶

    根据冯诺依曼体系结构，计算机的核心部件不包括______

    • A. 运算器
    • B. 控制器
    • C. 存储器
    • D. 输入设备

    正确答案：D

    答案解析： 冯诺依曼体系结构中的核心部件包括运算器、控制器、存储器，但不包括输入设备。

    3. （5.00 分）¶

    下列选项中，是有效的 Python 标识符的是______

    • A. 123variable
    • B. variable@name
    • C. _my_var
    • D. class

    正确答案：C

    答案解析： 在 Python 中，标识符不能以数字开头，不能包含特殊字符（如 @），也不能使用关键字（如 class）。

    4. （5.00 分）¶

    执行代码 print(3.14, 2, sep='_', end='!')，输出结果是______

    • A. 3.14 2!
    • B. 3.14_2!
    • C. 3.142!
    • D. 3.14_2 _!

    正确答案：B

    答案解析： 参数 sep 用于指定输出项之间的分隔符，end 用于指定输出结束后的字符。

    5. （5.00 分）¶

    关于图灵机的描述，正确的是______

    • A. 图灵机是一种实际存在的计算机硬件
    • B. 图灵机是用于模拟计算过程的理论模型
    • C. 图灵机的核心是同时处理多个任务
    • D. 图灵机不需要指令就能自动运行

    正确答案：B

    答案解析： 图灵机是一种理论模型，用于模拟计算过程，而不是实际存在的硬件。

    三、编程题（共 5 题，总分：50.00）¶

    1. 输出 "Hello World"（10.00 分）¶

    【问题描述】 编写程序，输出字符串 "Hello World"。

    【输入形式】 无输入

    【输出形式】 一行，输出 "Hello World"

    【样例输出】

    Hello World

    【样例说明】 直接输出指定字符串即可。

    【评分标准】 正确输出 "Hello World"

    参考答案（Python）：

    print("Hello World")

    2. 浮点数加法（10.00 分）¶

    【问题描述】 编写程序，用户输入两个浮点数 num1 和 num2，计算并输出它们的和，结果保留 1 位小数。

    【输入形式】 两行输入，第一行为浮点数 num1，第二行为浮点数 num2

    【输出形式】 一行，格式为 num1 + num2 = 结果（结果保留 1 位小数）

    【样例输入】

    3.5
2.8

    【样例输出】

    3.5 + 2.8 = 6.3

    【样例说明】 输入两个浮点数 3.5 和 2.8，求和得 6.3，按要求格式输出。

    【评分标准】 能正确读取两个浮点数并求和，结果保留 1 位小数，输出格式正确。

    参考答案（Python）：

    num1 = float(input())
num2 = float(input())
sum_result = num1 + num2
print(f"{num1} + {num2} = {sum_result:.1f}")

    3. 整数整除运算（10.00 分）¶

    【问题描述】 用户输入两个整数 \(a\) 和 \(b\)（保证 \(b \neq 0\) 且 \(a\) 能被 \(b\) 整除），计算 \(a\) 除以 \(b\) 的整数商（即 \(a // b\)），并按指定格式输出。

    【输入形式】 两行输入，第一行为整数 \(a\)，第二行为整数 \(b\)

    【输出形式】 一行，格式为 a // b = 商

    【样例输入】

    15
4

    【样例输出】

    15 // 4 = 3

    【样例说明】 15 除以 4 的整数商为 3，按格式输出计算过程和结果。

    【评分标准】 正确读取整数 \(a\) 和 \(b\) 得 30 分，正确计算整数商，输出格式正确。

    参考答案（Python）：

    a = int(input())
b = int(input())
quotient = a // b
print(f"{a} // {b} = {quotient}")

    4. 浮点数乘法（10.00 分）¶

    【问题描述】 用户输入两个浮点数 \(x\) 和 \(y\)，以及一个整数 \(n\)（\(1 \le n \le 5\)），计算 \(x\) 与 \(y\) 的乘积，并将结果保留 \(n\) 位小数后输出。

    【输入形式】 三行输入，第一行为浮点数 \(x\)，第二行为浮点数 \(y\)，第三行为整数 \(n\)

    【输出形式】 一行，格式为 x * y = 结果（结果保留 \(n\) 位小数）

    【样例输入】

    2.5
3.2
2

    【样例输出】

    2.5 * 3.2 = 8.00

    【样例说明】 2.5 与 3.2 的乘积为 8.0，保留 2 位小数后为 8.00，按指定格式输出。

    【评分标准】 正确读取输入，正确计算乘积，按要求保留 \(n\) 位小数并格式化输出。

    参考答案（Python）：

    x = float(input())
y = float(input())
n = int(input())
product = x * y
print(f'{x} * {y} = {product:.{n}f}')

    5. 货币兑换（10.00 分）¶

    【问题描述】 编写一个程序，将用户输入的人民币金额 RMB 兑换成美元 USD。已知当前汇率为 exchange_rate（1 美元兑换多少人民币）。输出兑换后的美元金额，结果保留两位小数。

    【输入形式】 共两行输入，每行一个浮点数：

    • 第一行：人民币金额 RMB
    • 第二行：汇率 exchange_rate（例如，6.8 表示 1 美元兑换 6.8 人民币）

    【输出形式】 一行，输出兑换后的美元金额 USD，保留两位小数。

    【样例输入】

    100.0
6.8

    【样例输出】

    14.71

    【样例说明】 \(100.0 \div 6.8 \approx 14.70588\ldots\)，保留两位小数为 14.71。

    【评分标准】

    • 程序能正确读取输入并进行货币兑换计算。
    • 输出格式正确，结果保留两位小数。

    参考答案（Python）：

    rmb = float(input())
exchange_rate = float(input())
usd = rmb / exchange_rate
print("%.2f" % usd)
