    学习资源¶

    本页面整理了对中法未来科技学院同学最有帮助的在线学习平台、教材与参考书推荐。

    在线学习平台¶

    校内与国内平台¶

    平台 网址 用途
    北航课程中心 校内访问 课程资料下载、作业提交
    北航图书馆 lib.buaa.edu.cn 文献检索、数据库访问
    北航正版软件平台 software.buaa.edu.cn MATLAB、Mathematica 等
    学堂在线 xuetangx.com 国内大学 MOOC 课程
    中国大学MOOC icourse163.org 国内大学在线课程

    国际平台¶

    平台 网址 用途
    INSA Moodle 校内指引 INSA 课程资料与在线教学
    Khan Academy khanacademy.org 数学、物理、化学基础
    MIT OpenCourseWare ocw.mit.edu 顶级大学课程视频与讲义
    Coursera coursera.org 各学科在线课程
    3Blue1Brown 3blue1brown.com 数学可视化视频
    edX edx.org 国际名校在线课程

    法语学习资源¶

    平台 网址 用途
    TV5Monde apprendre.tv5monde.com 法语听力与语法练习
    Le Point du FLE lepointdufle.net 法语语法大全
    Bonjour de France bonjourdefrance.com 分级法语练习
    DeepL deepl.com 高质量法中/法英翻译
    WordReference wordreference.com 多语词典（含专业术语）

    工具推荐¶

    计算与编程¶

    工具 用途
    MATLAB 数值计算、数据可视化、信号处理
    Python (NumPy/SciPy/PyTorch) 科学计算、机器学习、绘图
    Jupyter Notebook 交互式计算与笔记
    Wolfram Alpha 在线符号计算、公式求解
    VS Code 代码编辑器
    Cadence / Synopsys EDA 工具（微电子专业）

    笔记与写作¶

    工具 用途

    Notion 团队协作文档、学习规划
