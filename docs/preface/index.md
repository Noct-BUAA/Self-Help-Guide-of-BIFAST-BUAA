# 前言

## 项目背景

北京航空航天大学中法未来科技学院于 2025 年正式获批成立并开始招收首届本科生。
作为一所全新的中外合作办学机构，学院采用中法融合的工程教育体系，
与法国 INSA 集团深度合作，实行本硕贯通 6 年弹性学制。

对于一所新建学院的首届学生而言，面临的挑战是双重的：

- **信息空白** — 全新学院意味着缺少前人的经验积淀，选课、考核、生活各方面信息需要从零开始积累
- **语言适应** — 中、法、英三语教学环境对多数新生是不小的适应过程
- **体系摸索** — 融合中法两国的课程体系、考核方式，需要在实践中逐步理解和适应
- **杭州新校区** — 北航杭州国际校园为新建成校区，周边配套和校园文化尚在形成中

本项目正是在这样的背景下应运而生——作为"首届探索者"，我们希望将自己在学习和生活中的
经验与心得系统地记录下来，为后来的同学铺路。

## 关于中法未来科技学院

北京航空航天大学**中法未来科技学院**（Beihang INSA Institute for Applied
Sustainable Sciences and Technology）是北航与**法国国立应用科学学院**
（INSA，含 INSA 里昂、图卢兹、鲁昂、上法兰西四个校区）
合作创办的中外合作办学机构，于 **2025 年 5 月**获教育部正式批准设立。

学院坐落于浙江省杭州市余杭区瓶窑镇双红桥街 166 号的**北航杭州国际校园**内，
是北航国际化办学战略的重要组成部分。

!!! quote "学院使命"

    融合中法两国优质工程教育资源，培养具有国际视野、扎实科学基础、
    卓越工程实践能力和可持续发展理念的高素质工程师人才。

### 办学特色

| 项目 | 详情 |
|------|------|
| 办学规模 | 总规模 2100 人，本科生年招生 300 人 |
| 学制 | 本硕贯通 6 年弹性学制 |
| 教学语言 | 中文、法语、英语三语教学 |
| 学位授予 | 北航硕士学位 + 法国工程师职衔委员会（CTI）认证工程师文凭 |
| 培养地点 | 本硕阶段全部在杭州完成（优秀学生可赴法交流） |

### 本科专业

| 专业 | 方向 |
|------|------|
| 材料科学与工程 | 先进材料、纳米技术、可持续材料 |
| 微电子科学与工程 | 集成电路设计、半导体器件、MEMS |
| 计算机科学与技术 | 人工智能、数据科学、软件工程 |
| 生物医学工程 | 医学影像、生物材料、医疗器械 |
| 航空航天工程 | 飞行器设计、推进系统、航天技术 |

### 合作院校

法国国立应用科学学院（INSA）是法国最大的公立工程师教育集团之一，
以培养应用科学与技术领域的精英工程师而闻名，
在全球拥有多所校区，教学质量享誉国际。

## 项目目标

本项目旨在为北航中法未来科技学院的同学提供一套系统化、社区维护、持续更新的自助参考指南：

| 目标 | 说明 |
|------|------|
| 汇集学习资源 | 整理各专业课程的教学大纲、推荐教材、在线学习平台与学习资料 |
| 解析重难点 | 针对课程中的关键概念和常见难点，提供深入浅出的解析与解题思路 |
| 分享杭州生活经验 | 覆盖杭州国际校园的住宿、餐饮、交通、周边等各方面实用信息 |
| 促进互助共享 | 鼓励同学之间知识共享，形成互帮互助的学习氛围 |

## 如何贡献

本项目完全开源，托管于 [GitHub](https://github.com/Noct-BUAA/Self-Help-Guide-of-BIFAST-BUAA)。
欢迎所有同学参与内容贡献！

=== "通过 Issue 反馈"

    1. 点击仓库页面的 **Issues** 标签
    2. 选择 **New Issue**
    3. 描述你发现的问题或想要补充的内容
    4. 提交后维护者会尽快处理

=== "通过 Pull Request 贡献"

    1. **Fork** 本仓库到你的 GitHub 账号
    2. 在本地克隆并进行修改
    3. 提交 **Pull Request**，描述你的修改内容
    4. 维护者审核通过后合并

### 贡献原则

- 内容应准确可靠，有据可查

- 遵守 CC BY-NC 4.0 开源协议
