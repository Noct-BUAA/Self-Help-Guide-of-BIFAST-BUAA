# 住宿指南

北航杭州国际校园为学生提供现代化的住宿条件。

---

## 校内宿舍

| 项目 | 详情 |
|------|------|
| 房间类型 | 双人间（为主）、少量单人间（研究生） |
| 基本设施 | 上床下桌、衣柜、书架、空调 |
| 网络 | 校园网覆盖 |
| 公共设施 | 每层公共卫生间、淋浴间、开水房、洗衣房 |
| 空调 | 全部宿舍已安装空调 |
| 取暖 | 空调取暖（杭州冬季湿冷） |

### 费用参考

| 项目 | 费用（约） |
|------|-----------|
| 住宿费 | 约 2,000 元/学年（双人间） |
| 水电费 | 按实际用量计费 |
| 网络费 | 校园网基础免费 |

### 宿舍管理

- 门禁：各宿舍楼设有门禁系统，凭校园卡进出
- 访客登记：外来访客需在值班室登记
- 电器限制：禁止使用大功率电器
- 报修服务：通过学校后勤服务平台或联系楼管报修

!!! tip "杭州气候住宿小贴士"

    - 杭州梅雨季节（6 – 7 月）湿度极大，建议备置除湿袋/除湿盒
    - 冬季虽无暖气但空调制热足够，怕冷可备电热毯
    - 夏季蚊虫较多，务必准备蚊帐或电蚊香
    - 衣柜内放干燥剂，防止衣物发霉
    - 准备一个插线板，每个床位通常只有 1–2 个插座

## 校外租房

| 区域 | 特点 | 参考租金（单间/月） |
|------|------|:------:|
| 瓶窑镇 | 距离最近 | 800 – 1,500 元 |
| 良渚 | 文化村环境优美 | 1,500 – 2,500 元 |
| 杭州西站周边 | 高铁枢纽区 | 1,800 – 3,000 元 |
| 未来科技城 | 互联网产业聚集区 | 2,000 – 3,500 元 |

!!! warning "租房提醒"

    1. 通过正规中介或知名平台（贝壳、自如、我爱我家）租房
    2. 确认房东身份，避免二房东转租风险
    3. 仔细阅读租期、押金、违约责任等条款
    4. 入住前拍摄房屋状况，退租时避免押金纠纷
