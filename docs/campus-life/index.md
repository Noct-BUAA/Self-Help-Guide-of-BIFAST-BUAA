## 北航杭州国际校园速览

北航杭州国际校园位于浙江省杭州市余杭区瓶窑镇双红桥街 166 号，
是北航国际化办学的新建校区，目前入驻包括中法未来科技学院、
中法航空学院、中西智能学院等多个中外合作办学机构。

| 项目 | 详情 |
|------|------|
| 地址 | 杭州市余杭区瓶窑镇双红桥街 166 号（邮编：311115） |
| 校园状态 | 新建校区，设施现代 |
| 入驻学院 | 中法未来科技学院、中法航空学院、中西智能学院等 |
| 公交站 | 北航中法航空学院站、北航中法航空学院东站 |

!!! note "新生报到"

    新生报到时学院会统一安排接待和引导，发放新生手册。
    因校区较新，部分周边配套设施尚在完善中，
    本指南会持续更新最新的校园生活信息。
