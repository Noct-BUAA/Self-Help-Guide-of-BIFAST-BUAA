## 场馆预约

体育场馆与图书馆使用统一预约系统。

### 预约步骤

1. 钉钉搜索"校园空间预约平台" → 登录
2. 选择"场地预约"
3. 选择场次与场地：绿色区域可预约 → 选择日期 → 场地编号 → 时间段 → 添加同伴、填写手机号 → 阅读并勾选"预约须知" → 提交 → 完成安全验证
4. 支付费用（目前仅游泳馆需付费，其他场地 0 元，选择支付后自动完成）
5. 显示"您已经成功预约"即完成
6. 个人中心可查看订单、取消预约、修改同伴

入场时向管理员出示"会员码"核销。

### 注意事项

!!! warning "预约黑名单"
    羽毛球馆、游泳馆、健身中心预约后未到场核销累计超过 3 次，将被加入黑名单 30 日，期间不可预约以上场馆。请合理安排时间，无法到场请尽早取消。

- 羽毛球馆、游泳馆、健身中心最早可于入场前 3 日 8:00 购票
- 仅支持在线购票，不支持线下购票
- 请仔细阅读并遵守各场地使用说明
