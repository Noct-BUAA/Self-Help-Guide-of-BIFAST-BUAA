## 杭州特色美食

| 美食 | 简介 | 推荐去处 |
| ------ | ------ | ---------- |
| 片儿川 | 杭州特色汤面，雪菜+笋片+肉丝 | 奎元馆、慧娟面馆 |
| 西湖醋鱼 | 糖醋汁浇草鱼，杭州名菜 | 楼外楼、知味观 |
| 东坡肉 | 慢炖五花肉，肥而不腻 | 杭州各大中餐馆 |
| 龙井虾仁 | 龙井茶香配鲜虾仁 | 杭帮菜馆 |
| 定胜糕 | 米粉豆沙糕，传统点心 | 知味观 |

!!! tip "杭州饮食 TIPS"

 - 杭帮菜口味偏清淡鲜甜，喜欢重口味的同学可自带辣椒酱
 - 杭州餐馆多数在 14:00 – 16:30 午休不营业，注意避开
 - 大众点评 APP 在杭州覆盖率极高
