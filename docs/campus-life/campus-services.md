# 校园服务

本页汇总校园卡、网络、维修报修和楼宇服务等日常运行保障信息。

---

## 校园卡

### 办理方式

| 人员类型 | 办理方式 |
|----------|----------|
| 本科生、研究生 | 学校统一批量办理，入学时由辅导员下发 |
| 派驻生、交换生 | 扫描派驻单背面二维码完成支付宝绑定并上传通行照，前往医务中心负一楼 B1017（健身房右侧房间）领取 |

### 支付宝认证绑定

1. 支付宝搜索"智慧易通云"，点击"立即用户认证"
2. 确认单位为"杭州北航国际创新研究院（学院）"，如否在个人中心切换
3. 登录：新用户使用学工号 + 默认密码（身份证/护照后六位，字母改 0）；或使用手机号（需与钉钉一致）+ 验证码
4. 核对账户信息，点击"下一步"，显示照片即绑定成功

!!! warning "注意"
    认证过程中确保个人信息真实有效，切勿向他人泄露验证码。

### 补卡

| 项目 | 详情 |
|------|------|
| 地点 | 医务中心负一楼 B1017 / 北区食堂西南门墙角自助机（仅限师生） |
| 时间 | 工作日 8:00 – 17:00 |
| 费用 | 20 元（需预留在校园卡账户中） |

#### 补卡后智能门锁权限重置

补卡后需断电上电操作以激活新卡权限：

1. 室友/宿管/楼宇管家开门后，从顶部扣开门锁盖板
2. 打开电池盖板
3. 拆出一节电池，等待 3 秒后装回
4. 先上后下安装回电池盖板
5. 先下往上安装回门锁盖板
6. 刷卡验证

如无法开门，拍下门锁编号通过钉钉联系林伟达或李庆华。补卡机故障或缺卡请到线下补卡。

### 充值消费

钉钉工作台 → "充值消费" → 办理充值、账单、挂失/解挂等业务。

## 楼宇服务

### 楼宇管家

国际校园各公共楼宇（实验楼除外）设有专属管家。钉钉搜索框输入楼宇名称（如"科研一楼宇"），系统自动推送管家联系方式。

管家服务范围：师生咨询、报事报修、卫生反馈、协助开门、资产管理、教室管理、便民借用、失物招领。

### 会议室预约

钉钉工作台 → "会议室预约" → 选择会议室 → 填写时间、主题、人数 → 勾选参会人员和服务类型 → 完成。

### 门禁权限

入学时自动开通门禁及宿舍门锁。其他权限需由所在单位教职工申请审批：

| 类型 | 钉钉联系人 |
|------|-----------|
| 办公室门禁 | 荣融老师 |
| 实验室门禁 | 姚远老师 |
| 会议室门禁 | 林伟达老师 |

### 紧急开门

| 时段 | 服务方式 |
|------|----------|
| 工作日 7:30 – 17:30 | 楼宇管家，须出示校园卡/身份证/护照 |
| 非工作时间 / 夜间 | 拨打 24 小时安保热线 `0571-28881110` |
