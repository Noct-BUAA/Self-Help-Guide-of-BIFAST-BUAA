## 专业概览

中法未来科技学院目前开设 5 个本科专业，涵盖工程与应用科学的多个前沿领域：

### 材料科学与工程

| 项目 | 详情 |
|------|------|
| 方向 | 先进结构材料、功能材料、纳米材料、可持续材料 |
| 核心课程 | 材料科学基础、材料力学、材料物理化学、材料加工 |
| INSA 关联 | INSA 里昂在材料领域拥有顶尖实验室和工业合作网络 |

### 微电子科学与工程

| 项目 | 详情 |
|------|------|
| 方向 | 集成电路设计、半导体器件、MEMS、嵌入式系统 |
| 核心课程 | 半导体物理、数字/模拟集成电路、微纳加工、EDA工具 |
| INSA 关联 | INSA 图卢兹在微电子与嵌入式系统领域具有优势 |

### 计算机科学与技术

| 项目 | 详情 |
|------|------|
| 方向 | 人工智能、数据科学、软件工程、网络安全 |
| 核心课程 | 数据结构与算法、操作系统、机器学习、计算机网络 |
| INSA 关联 | INSA 各校区均设有强势计算机与信息科学专业 |

### 生物医学工程

| 项目 | 详情 |
|------|------|
| 方向 | 医学影像、生物材料、生物力学、医疗器械 |
| 核心课程 | 解剖与生理学、生物力学、医学信号处理、生物材料 |
| INSA 关联 | INSA 里昂设有生物科学与工程方向的强势研究团队 |

### 航空航天工程

| 项目 | 详情 |
|------|------|
| 方向 | 飞行器设计、推进系统、航天器技术、空气动力学 |
| 核心课程 | 空气动力学、飞行力学、推进原理、航天器结构设计 |
| INSA 关联 | 依托北航传统优势 + INSA 力学与能源工程 |

## 培养体系说明

中法未来科技学院采用本硕贯通 6 年弹性学制，融合中法两国工程教育优势：

1. **本科阶段（前 4 年）**：夯实数学、物理等基础学科，学习专业核心课程，强化法语/英语能力
2. **硕士阶段（后 2 年）**：深入专业方向，参与科研项目与企业实习
3. **法国元素**：部分课程由 INSA 教授授课，优秀学生可赴法交流

!!! note "关于法语教学"

    学院采用中、法、英三语教学。部分专业核心课程和工程师素养课程由
    INSA 教授以法语或英语授课。建议同学们在入学初期开始系统学习法语，
    重点掌握专业术语和学术表达。

## 学习建议

1. 打好数理基础 — 数学和物理是所有工程学科的核心根基
2. 重视法语学习 — 法语能力直接影响后续课程理解与赴法交流机会
3. 善用在线资源 — 充分利用中外平台
4. 主动参与实践 — 积极参与实验室项目和学科竞赛
5. 建立学习小组 — 与同学合作讨论是攻克难点的有效方法
