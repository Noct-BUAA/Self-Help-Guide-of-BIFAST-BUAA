# 大二上学期

大二上学期开设两门数学课程、一门电路基础课程、一门学术英语阅读与写作课程和一门综合法语实训课程。数学、电路基础与综合法语实训为法语授课，讲义采用中法对照排版；电路基础包含静电学与动电学两部分，并配有三份静电学 TD 与一份动电学 TD 详细解答。网站收录的讲义由原始 LaTeX 源文件渲染为网页，包含完整公式与插图；数学课程另附习题课参考解答。学术英语阅读与写作课程围绕人工智能主题训练学术阅读与写作，并配有 Unit 1 期中复习讲义；综合法语实训围绕“未来的交通”与“低空经济”两个单元训练工程话题的法语理解与表达，配有六课讲义与 Échanger 写作备考手册。

入党积极分子培训与党校入学考试资料已移至「专题资料」板块，可从下方入口进入。
