# 大二上学期

大二上学期开设两门数学课程与一门电路基础课程，均为法语授课，讲义采用中法对照排版。电路基础包含静电学与动电学两部分，并配有两份 TD 与详细解答。网站收录的讲义由原始 LaTeX 源文件渲染为网页，包含完整公式与插图；数学课程另附习题课参考解答。

本学期另收录党校学习资料，供入党积极分子培训与党校入学考试复习使用。

!!! warning "数学期中考试"

    **10 月 28 日（星期三，第 8 周）14:00–17:00**，两门数学课程各一份试卷，共 3 小时。

    [查看考试安排、考试范围与复习建议](期中考试.md)
