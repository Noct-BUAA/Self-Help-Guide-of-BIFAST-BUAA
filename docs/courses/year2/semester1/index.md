# 大二上学期

大二上学期开设两门数学课程与一门电路基础课程，均为法语授课，讲义采用中法对照排版。电路基础包含静电学与动电学两部分，并配有三份静电学 TD 详细解答。网站收录的讲义由原始 LaTeX 源文件渲染为网页，包含完整公式与插图；数学课程另附习题课参考解答。

入党积极分子培训与党校入学考试资料已移至「专题资料」板块，可从下方入口进入。
