## Organisation de l'examen <span class="heading-zh">考试安排</span>

L'examen durera 3 heures et portera sur les deux cours de mathématiques : <strong>Outils mathématiques pour les ingénieurs</strong> et <strong>Analyse réelle</strong>.

考试总时长为 3 小时，涵盖两门数学课程：<strong>工程数学</strong>（Outils mathématiques pour les ingénieurs）与<strong>实分析</strong>（Analyse réelle）。
{: .zh }

Deux sujets distincts vous seront distribués au début de l'examen, un pour chaque cours. Vous disposerez de 3 heures au total pour traiter les deux sujets, dans l'ordre de votre choix. À vous d'organiser votre temps !

考试开始时，你们将同时收到两份独立的试卷，每门课程各一份。你们共有 3 小时完成这两份试卷，可以自行决定答题顺序，并合理分配时间。
{: .zh }

Chaque sujet sera noté sur 100 points. Vous obtiendrez donc deux notes distinctes pour cet examen de mi-semestre, une pour chaque cours.

每份试卷满分为 100 分。因此，本次期中考试将产生两门课程各自独立的成绩，每门课程一项成绩。
{: .zh }

Le nombre de points attribués à chaque exercice sera indiqué sur le sujet.

每道大题的分值将在试卷上明确标出。
{: .zh }

## Programme de l'examen <span class="heading-zh">考试范围</span>

### Outils mathématiques pour les ingénieurs <span class="zh-inline">工程数学</span>

1. **Nombres complexes** : forme algébrique, plan complexe, module, argument, exponentielle complexe, forme exponentielle, résolution des équations du second degré à coefficients réels, racines de l'unité.

    复数：代数形式、复平面、模、辐角、复指数函数、指数形式、实系数一元二次方程的求解、单位根。
    {: .zh }

1. **Trigonométrie** : cercle trigonométrique, fonctions trigonométriques, formules de trigonométrie, fonctions trigonométriques réciproques.

    三角函数：单位圆、三角函数、三角恒等式与公式、反三角函数。
    {: .zh }

1. **Polynômes** : notation des polynômes, fonctions polynomiales, degré, racines, factorisation.

    多项式：多项式的表示方法、多项式函数、次数、根、因式分解。
    {: .zh }

### Analyse réelle <span class="zh-inline">实分析</span>

1. **Topologie de \(\mathbb{R}\)** : description de \(\mathbb{R}\), partie entière, valeur absolue, intervalles, voisinages, ouverts et fermés, densité de \(\mathbb{Q}\), bornes.

    实数集 \(\mathbb{R}\) 的拓扑：实数集 \(\mathbb{R}\) 的基本描述、整数部分、绝对值、区间、邻域、开集与闭集、有理数集 \(\mathbb{Q}\) 的稠密性、上下界。
    {: .zh }

1. **Suites numériques** : suites usuelles, suites réelles, suites réelles convergentes, suites réelles divergentes vers l'infini, nature des suites réelles, théorème de la limite monotone, comparaison de suites réelles.

    数列：常见数列、实数数列、收敛的实数数列、趋于无穷大的实数数列、实数数列的敛散性、单调收敛定理、实数数列的比较。
    {: .zh }

## Nature des questions et attentes <span class="heading-zh">题目类型及答题要求</span>

Chaque sujet comportera plusieurs exercices, composés de différentes questions. Leur difficulté sera comparable à celle des exemples du cours et des exercices travaillés en TD depuis le début du semestre.

每份试卷将包含若干道大题，每道大题由多个小题组成。题目的难度将与本学期以来课堂上的例题和 TD（习题课）中练习过的题目相当。
{: .zh }

Chaque exercice comportera également des questions de cours. Il vous sera demandé de rappeler précisément une définition, une propriété ou un théorème étudié en cours. Pour ces questions, il suffit d'énoncer correctement les éléments demandés, sans démonstration ni justification.

每道大题中还会包含课程知识题。这类题目要求你们准确写出课程中学过的定义、性质或定理。对于这些题目，只需要准确陈述所要求的内容，不需要证明或解释。
{: .zh }

!!! tip "定义、性质、定理合集"

    已按章节汇总两门课讲义中的定义、性质、定理与推论，法文原文 + 中文对照，适合考前背诵课程知识题：

    - [实分析 · 定义、性质、定理合集](实分析/定义性质定理合集.md)
    - [工程数学 · 定义、性质、定理合集](工程数学/定义性质定理合集.md)

Pour les autres questions, sauf indication contraire, vous devrez expliquer votre raisonnement en français et justifier vos réponses.

对于其他题目，除非题目明确说明无须论证，否则你们需要用法语解释自己的推理过程，并对答案进行论证。
{: .zh }

Je vous rappelle que les fautes de français ne seront pas pénalisées. Nous évaluons vos connaissances et votre raisonnement mathématique, pas votre niveau de français !

再次提醒大家：<strong>法语语言错误不会被扣分</strong>。我们评价的是你们的数学知识和数学推理能力，而不是你们的法语水平！
{: .zh }

En revanche, une réponse contenant uniquement des résultats ou des calculs, sans explication, ne permettra pas d'obtenir tous les points, même si les calculs sont corrects.

但是，如果答案只有结果或计算过程，没有必要的文字解释，即使计算正确，也无法获得该题的全部分数。
{: .zh }

!!! danger "Consignes pratiques／考试注意事项"

    - Aucun document, calculatrice ou appareil électronique ne sera autorisé.
    - Vous devrez rédiger vos réponses sur les feuilles distribuées.
    - Vous devrez inscrire votre numéro d'étudiant sur chaque page, à l'emplacement prévu.

    - 考试期间禁止使用任何资料、计算器及电子设备。
    - 请在发放的答题纸上作答。
    - 请在每一页的指定位置填写自己的学号。

## Conseils pour préparer l'examen <span class="heading-zh">复习建议</span>

Pour bien vous préparer, je vous recommande de :

为了更好地准备考试，我建议大家：
{: .zh }

1. Relire attentivement vos cours et apprendre les définitions, propriétés et théorèmes importants. N'oubliez pas les questions de cours !

    认真复习课程讲义，掌握重要的定义、性质和定理。不要忘记考试中会有课程知识题！
    {: .zh }

1. Refaire les exercices de TD en essayant de les résoudre seuls, sans regarder immédiatement les corrigés.

    重新练习 TD 中的习题，尽量独立完成，不要一开始就查看参考答案。
    {: .zh }

1. Étudier les corrigés des TD pour comprendre les méthodes utilisées et apprendre à bien expliquer et justifier vos raisonnements.

    仔细阅读 TD 习题的参考答案，理解解题方法，并学习如何清楚地解释和论证自己的数学推理。
    {: .zh }

Pendant l'examen, prenez le temps de lire attentivement les deux sujets avant de commencer. Organisez votre temps pour traiter les deux matières et ne restez pas trop longtemps bloqués sur une question.

考试时，请先认真阅读两份试卷，再开始答题。合理安排两门课程的答题时间，不要在某一道题目上花费过多时间。
{: .zh }

Enfin, si vous rencontrez des difficultés pendant vos révisions, n'hésitez pas à poser des questions à vos professeurs, notamment dans ce groupe DingTalk. Nous sommes là pour vous aider !

另外，如果大家在复习过程中遇到困难，欢迎随时向老师提问，也可以直接在这个 DingTalk 群里提问。我们会尽力帮助大家！
{: .zh }

Vous avez déjà travaillé en cours et en TD sur les connaissances et les méthodes nécessaires pour réussir cet examen. Si vous connaissez votre cours, si vous avez sérieusement travaillé les exercices de TD et si vous vous entraînez à expliquer vos raisonnements, vous avez tout ce qu'il faut pour bien vous préparer.

你们在课程和 TD 中已经学习并练习了这次考试所需要的知识和方法。只要认真掌握课程内容、扎实练习 TD 习题，并训练自己解释数学推理的能力，你们就具备了充分准备这次考试的基础。
{: .zh }

Pour terminer, je vous retransmets ci-dessous les conseils de travail que je vous avais donnés en début de semestre. N'hésitez pas à les relire et à les appliquer pendant vos révisions.

最后，老师再次转发了本学期初给出的数学学习建议。希望大家在复习期间重新阅读，并尽量将这些建议运用到自己的学习中。
{: .zh }

Bon courage à toutes et à tous pour vos révisions ! 💪

祝大家复习顺利，加油！
{: .zh }
