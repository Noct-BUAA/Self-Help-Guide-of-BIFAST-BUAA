# 实分析

## 课程简介

实分析（Analyse réelle）是北航中法未来科技学院大二上学期的数学课程，承接大一的基础数学与数学分析，系统建立实数系的拓扑结构与数列极限理论。

课程以法语授课，讲义为中法对照形式：每个知识点先给出法语原文，再附中文翻译与术语解释。本页收录的讲义由原始 LaTeX 源文件渲染为网页，公式、插图与版式均按原讲义还原。

课程内容分为两条主线：

- **实数拓扑**：实数轴的结构、序关系、绝对值与整数部分、区间、开集与闭集、上确界与下确界。
- **数列理论**：数列的收敛性、单调收敛、子列、递推数列、相邻项与极限存在定理。

配套的三次习题课（TD）覆盖拓扑、数列与数列极限，均附完整参考解答。

## 备考建议

实分析的考试以定义、定理与证明为核心，计算题相对较少，备考时应把重点放在概念的精确理解与证明的规范书写上：

1. **吃透定义与定理的表述。** 上确界、开集、收敛等概念都有严格的量词结构，考试常要求判断命题真假或改写定义。建议把每个定义的条件逐条拆开，明确每个量词的顺序与作用范围。

2. **重视证明题的书写。** 讲义与习题课中的证明是考试命题的直接参考。练习时不要只看懂思路，要完整写出“假设—推理—结论”的过程，尤其是双向蕴含、反证法与构造性证明。

3. **用好三次习题课。** TD 的难度通常略高于正课例题，覆盖了考试常见的题型。建议先独立完成，再对照参考解答检查每一步的依据是否写清楚。

4. **熟悉法语术语。** 考试为法语命题，讲义中的 borne supérieure、suite convergente、voisinage 等术语需要做到看到即懂。中法对照的排版正是为此设计，复习时可先遮住中文尝试直接阅读法语原文。
