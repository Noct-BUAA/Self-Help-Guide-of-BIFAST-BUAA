# 工程数学

## 课程简介

工程数学（Outils mathématiques pour les ingénieurs）是北航中法未来科技学院大二上学期的数学课程，面向工程应用，系统整理复数、三角学与多项式三套基础工具。

课程以法语授课，讲义为中法对照形式：每个知识点先给出法语原文，再附中文翻译与术语解释。本页收录的讲义由原始 LaTeX 源文件渲染为网页，公式、插图与版式均按原讲义还原。

课程内容分为三大模块：

- **复数**：代数形式、共轭、模与辐角、欧拉公式、棣莫弗定理及其几何意义。
- **三角学**：单位圆与弧度、正弦余弦正切、三角恒等式、反三角函数。
- **多项式**：次数与运算、根与重根、因式分解、拉格朗日插值与代数基本定理。

此外还收录一份研究实数数列的方法讲义（Fiche 5），以及五次习题课（TD）的完整参考解答。

## 备考建议

工程数学的知识点较碎，但考试题型相对固定，备考的关键是把常用公式练到熟练，并能在法语表述下快速识别考点：

1. **背熟公式并理解来源。** 欧拉公式、棣莫弗定理、三角和差公式、二项式定理都是高频考点。不要只记结论，要理解推导过程，这样在变形题中才不会卡住。

2. **重视复数与三角的几何意义。** 复数的模、辐角与单位圆上的旋转是联系两章的纽带。考试中常通过几何图形给出条件，建议把“代数运算”与“几何变换”两种视角都练熟。

3. **多项式部分抓住因式分解与根。** 重根判定、待定系数法、二项式展开是常见题型；拉格朗日插值与代数基本定理的结论也要能准确叙述。帕斯卡三角形与二项式系数的递推关系要能做到不查表快速写出。

4. **用好习题课与 Fiche 5。** TD 覆盖了考试的主要题型，Fiche 5 则集中训练数列方法。建议先独立完成，再对照参考解答整理自己的解题模板。

5. **熟悉法语术语。** 考试为法语命题，module、argument、racine、factorisation 等术语需要做到看到即懂。复习时可先遮住中文，直接阅读讲义的法语部分。
