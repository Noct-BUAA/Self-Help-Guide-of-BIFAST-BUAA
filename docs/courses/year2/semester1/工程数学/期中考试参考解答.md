## Exercice 1　Nombres complexes <span class="heading-zh">练习 1 · 复数（40 分）</span>

<strong>1.</strong> <strong>Question de cours.</strong> Rappeler la définition du module d'un nombre complexe.
{: .fr-exo }

<strong>1.</strong> <strong>课程知识题。</strong>复述复数模的定义。
{: .zh }

!!! sol ""

    Le module d'un nombre complexe \(z=x+iy\in\mathbb{C}\) est \(|z|=\sqrt{x^2+y^2}\).

    复数 \(z=x+iy\in\mathbb{C}\) 的模为 \(|z|=\sqrt{x^2+y^2}\)。
    {: .zh }

<strong>2.</strong> <strong>Question de cours.</strong> Rappeler les formules d'Euler.
{: .fr-exo }

<strong>2.</strong> <strong>课程知识题。</strong>复述欧拉公式。
{: .zh }

!!! sol ""

    \[
    \forall\theta\in\mathbb{R},\quad
    \cos(\theta)=\frac{e^{i\theta}+e^{-i\theta}}{2}
    \qquad\text{et}\qquad
    \sin(\theta)=\frac{e^{i\theta}-e^{-i\theta}}{2i}.
    \]

    即：对任意 \(\theta\in\mathbb{R}\)，\(\cos(\theta)=\dfrac{e^{i\theta}+e^{-i\theta}}{2}\)，\(\sin(\theta)=\dfrac{e^{i\theta}-e^{-i\theta}}{2i}\)。
    {: .zh }

Le but de la suite de l'exercice est de résoudre l'équation suivante d'inconnue \(z\in\mathbb{C}\) :

本练习后续的目标是求解以下关于 \(z\in\mathbb{C}\) 的方程：
{: .zh }

\[
\overline{z}=z^2-3z+7. \tag{E1}
\]

<strong>3.</strong> Montrer que l'équation (E1) n'a pas de solutions réelles.
{: .fr-exo }

<strong>3.</strong> 证明方程 (E1) 没有实根。
{: .zh }

!!! sol ""

    Par l'absurde, on suppose que (E1) a une solution réelle notée \(z=x\in\mathbb{R}\). On a :

    用反证法，假设 (E1) 有一个实根，记为 \(z=x\in\mathbb{R}\)。则：
    {: .zh }

    \[
    x^2-3x+7=z^2-3z+7=\overline{z}=x
    \qquad\text{donc}\qquad
    x^2-4x+7=0.
    \]

    On reconnaît une équation de degré 2 à coefficients réels. Son discriminant est égal à :

    我们认出这是一个实系数二次方程。其判别式为：
    {: .zh }

    \[
    \Delta=(-4)^2-4\times1\times7=16-28=-12<0.
    \]

    Donc \(x=\frac{4+i\sqrt{12}}{2}=2+i\sqrt{3}\) ou \(x=2-i\sqrt{3}\), ce qui est absurde car \(x\in\mathbb{R}\). On en déduit que <strong class="text-red">(E1) n'a pas de solutions réelles</strong>.

    因此 \(x=\frac{4+i\sqrt{12}}{2}=2+i\sqrt{3}\) 或 \(x=2-i\sqrt{3}\)，这与 \(x\in\mathbb{R}\) 矛盾。由此推出 (E1) 没有实根。
    {: .zh }

<strong>4.</strong> L'équation (E1) a-t-elle des solutions imaginaires pures, c'est-à-dire appartenant à \(i\mathbb{R}\) ?
{: .fr-exo }

<strong>4.</strong> 方程 (E1) 是否有纯虚根，即属于 \(i\mathbb{R}\) 的解？
{: .zh }

!!! sol ""

    Soit \(z=iy\in i\mathbb{R}\) une solution imaginaire pure de (E1). On a :

    设 \(z=iy\in i\mathbb{R}\) 是 (E1) 的一个纯虚解。则：
    {: .zh }

    \[
    -y^2-3iy+7=z^2-3z+7=\overline{z}=-iy
    \qquad\text{donc}\qquad
    \underbrace{(y^2-7)}_{=\operatorname{Re}}+i\underbrace{(2y)}_{=\operatorname{Im}}=0.
    \]

    On en déduit que \(y^2-7=0\), donc \(y=\sqrt{7}\) ou \(y=-\sqrt{7}\), et \(2y=0\), donc \(y=0\). C'est absurde, donc <strong class="text-red">(E1) n'a pas de solutions imaginaires pures</strong>.

    由此推出 \(y^2-7=0\)，故 \(y=\sqrt{7}\) 或 \(y=-\sqrt{7}\)；又 \(2y=0\)，故 \(y=0\)。这是荒谬的，因此 (E1) 没有纯虚根。
    {: .zh }

<strong>5.</strong> Montrer que les solutions de (E1) sont aussi solutions de l'équation suivante d'inconnue \(z\in\mathbb{C}\) :
{: .fr-exo }

<strong>5.</strong> 证明 (E1) 的解也是以下关于 \(z\in\mathbb{C}\) 的方程的解：
{: .zh }

\[
z=z^4-6z^3+20z^2-33z+35. \tag{E2}
\]

!!! sol ""

    Soit \(z\in\mathbb{C}\) une solution de (E1). On a :

    设 \(z\in\mathbb{C}\) 是 (E1) 的解。则：
    {: .zh }

    \[
    \begin{aligned}
    z
    &=\overline{z^2-3z+7} &&\text{car } z \text{ est solution de (E1)}\\
    &=\overline{z}^2-3\overline{z}+7 &&\text{(propriétés du conjugué)}\\
    &=\bigl(z^2-3z+7\bigr)^2-3\bigl(z^2-3z+7\bigr)+7\\
    &\qquad\qquad\text{car } z \text{ est solution de (E1)}\\
    &=\bigl(z^4-3z^3+7z^2-3z^3+9z^2-21z+7z^2-21z+49\bigr)\\
    &\qquad -3z^2+9z-21+7\\
    &=z^4-6z^3+20z^2-33z+35.
    \end{aligned}
    \]

    Donc <strong class="text-red">les solutions de (E1) sont aussi solutions de (E2)</strong>.

    因此 (E1) 的解也是 (E2) 的解。
    {: .zh }

<strong>6.</strong> Soit \(z\in\mathbb{C}\). Montrer que \(z\) est solution de (E2) si et seulement si \(\overline{z}\) est solution de (E2).
{: .fr-exo }

<strong>6.</strong> 设 \(z\in\mathbb{C}\)。证明：\(z\) 是 (E2) 的解当且仅当 \(\overline{z}\) 是 (E2) 的解。
{: .zh }

!!! sol ""

    \[
    \begin{aligned}
    &z\ \text{est solution de (E2)}\\
    \Longleftrightarrow\quad
    & z = z^4-6z^3+20z^2-33z+35\\
    \Longleftrightarrow\quad
    & \overline{z} = \overline{z^4-6z^3+20z^2-33z+35}\\
    \Longleftrightarrow\quad
    & \overline{z} = \overline{z}^4-6\overline{z}^3+20\overline{z}^2-33\overline{z}+35
      \quad\text{d'après les propriétés du conjugué}\\
    \Longleftrightarrow\quad
    & \overline{z}\ \text{est solution de (E2)}.
    \end{aligned}
    \]

    On a bien montré que

    以上等价关系表明：
    {: .zh }

    \[
    \boxed{z \text{ est solution de (E2)} \iff \overline{z} \text{ est solution de (E2)}}.
    \]

    其中用到共轭的性质。
    {: .zh }

<strong>7.</strong> Vérifier que \(z_1=2+i\sqrt{3}\) est solution de (E2) et en déduire une autre solution \(z_2\) de (E2).
{: .fr-exo }

<strong>7.</strong> 验证 \(z_1=2+i\sqrt{3}\) 是 (E2) 的解，并由此推出 (E2) 的另一个解 \(z_2\)。
{: .zh }

!!! sol ""

    \[
    \begin{aligned}
    z_1^2&=\bigl(2+i\sqrt{3}\bigr)^2=4+4i\sqrt{3}-3=1+4i\sqrt{3},\\
    z_1^3&=z_1^2z_1=\bigl(1+4i\sqrt{3}\bigr)\bigl(2+i\sqrt{3}\bigr)
     =2+i\sqrt{3}+8i\sqrt{3}-12=-10+9i\sqrt{3},\\
    z_1^4&=\bigl(z_1^2\bigr)^2=\bigl(1+4i\sqrt{3}\bigr)^2
     =1+8i\sqrt{3}-48=-47+8i\sqrt{3}.
    \end{aligned}
    \]

    Par conséquent :

    因此：
    {: .zh }

    \[
    \begin{aligned}
    &z_1^4-6z_1^3+20z_1^2-33z_1+35\\
    &=-47+8i\sqrt{3}-6\bigl(-10+9i\sqrt{3}\bigr)+20\bigl(1+4i\sqrt{3}\bigr)
      -33\bigl(2+i\sqrt{3}\bigr)+35\\
    &=(-47+60+20-66+35)+(8-54+80-33)i\sqrt{3}\\
    &=2+i\sqrt{3}=z_1.
    \end{aligned}
    \]

    Donc \(\boxed{z_1=2+i\sqrt{3} \text{ est solution de (E2)}}\).

    因此 \(z_1=2+i\sqrt{3}\) 是 (E2) 的解。
    {: .zh }

    D'après la question 6, on en déduit que \(\boxed{z_2=\overline{z_1}=2-i\sqrt{3} \text{ est une autre solution de (E2)}}\).

    根据第 6 题，推出 \(z_2=\overline{z_1}=2-i\sqrt{3}\) 是 (E2) 的另一个解。
    {: .zh }

<strong>8.</strong> Déterminer une équation de degré 2 à coefficients réels dont \(z_1\) et \(z_2\) sont les solutions.
{: .fr-exo }

<strong>8.</strong> 求一个以 \(z_1\) 与 \(z_2\) 为解的实系数二次方程。
{: .zh }

!!! sol ""

    On sait que \(z_1\) et \(z_2\) sont les solutions de l'équation \(z^2-Sz+P=0\) d'inconnue \(z\in\mathbb{C}\) où :

    已知 \(z_1\) 与 \(z_2\) 是关于 \(z\in\mathbb{C}\) 的方程 \(z^2-Sz+P=0\) 的解，其中：
    {: .zh }

    \[
    \begin{aligned}
    S&=z_1+z_2=z_1+\overline{z_1}=2\operatorname{Re}(z_1)=4\\
    \text{et}\qquad
    P&=z_1z_2=z_1\overline{z_1}=|z_1|^2=2^2+\bigl(\sqrt{3}\bigr)^2=7.
    \end{aligned}
    \]

    Donc \(z_1\) et \(z_2\) sont les solutions de l'équation \(\boxed{z^2-4z+7=0}\) d'inconnue \(z\in\mathbb{C}\).

    因此 \(z_1\) 与 \(z_2\) 是方程 \(z^2-4z+7=0\)（关于 \(z\in\mathbb{C}\)）的解。
    {: .zh }

<strong>9.</strong> Trouver deux constantes \((a,b)\in\mathbb{R}^2\) telles que :
{: .fr-exo }

<strong>9.</strong> 求两个常数 \((a,b)\in\mathbb{R}^2\)，使得：
{: .zh }

\[
\forall z\in\mathbb{C},\quad
z^4-6z^3+20z^2-34z+35=\bigl(z^2-4z+7\bigr)\bigl(z^2+az+b\bigr).
\]

!!! sol ""

    Soit \(z\in\mathbb{C}\). On a :

    设 \(z\in\mathbb{C}\)。有：
    {: .zh }

    \[
    \begin{aligned}
    \bigl(z^2-4z+7\bigr)\bigl(z^2+az+b\bigr)
    &=z^4+az^3+bz^2-4z^3-4az^2-4bz+7z^2+7az+7b\\
    &=z^4+(a-4)z^3+(b-4a+7)z^2+(-4b+7a)z+7b.
    \end{aligned}
    \]

    On veut :

    我们希望：
    {: .zh }

    \[
    \begin{cases}
    a-4=-6 & \text{donc } a=-2,\\
    b-4a+7=20 & \text{donc } b=13+4a=5.
    \end{cases}
    \]

    Ainsi, pour \(\boxed{(a,b)=(-2,5)}\), on a \(-4b+7a=-34\) et \(7b=35\), donc :

    于是，取 \((a,b)=(-2,5)\) 时，有 \(-4b+7a=-34\) 且 \(7b=35\)，因此：
    {: .zh }

    \[
    \forall z\in\mathbb{C},\quad
    z^4-6z^3+20z^2-34z+35=\bigl(z^2-4z+7\bigr)\bigl(z^2-2z+5\bigr).
    \]

<strong>10.</strong> En déduire les solutions de (E2), puis les solutions de (E1).
{: .fr-exo }

<strong>10.</strong> 由此推出 (E2) 的解，进而推出 (E1) 的解。
{: .zh }

!!! sol ""

    \[
    \begin{aligned}
    (\mathrm{E}2)\quad\Longleftrightarrow\quad
    & z=z^4-6z^3+20z^2-33z+35\\
    \Longleftrightarrow\quad
    & z^4-6z^3+20z^2-34z+35=0\\
    \Longleftrightarrow\quad
    & \bigl(z^2-4z+7\bigr)\bigl(z^2-2z+5\bigr)=0
      \quad\text{d'après la question 9}\\
    \Longleftrightarrow\quad
    & \bigl(z^2-4z+7=0\bigr)\quad\text{ou}\quad\bigl(z^2-2z+5=0\bigr)
      \quad\text{par intégrité.}
    \end{aligned}
    \]

    即 (E2) 等价于 \(z^4-6z^3+20z^2-34z+35=0\)，由第 9 题可分解为两个二次方程之积，再由整性得两个方程之一成立。
    {: .zh }

    On sait déjà que les solutions de \(z^2-4z+7=0\) sont \(z_1=2+i\sqrt{3}\) et \(z_2=\overline{z_1}=2-i\sqrt{3}\) d'après la question 8. Pour \(z^2-2z+5=0\), on reconnaît une équation de degré 2 à coefficients réels dont le discriminant est égal à \(\Delta=(-2)^2-4\times1\times5=-16<0\). Donc \(z=\frac{2+i\sqrt{16}}{2}=1+2i\) ou \(z=1-2i\). Finalement, l'ensemble des solutions de (E2) est égal à :

    由第 8 题已知 \(z^2-4z+7=0\) 的解为 \(z_1=2+i\sqrt{3}\) 与 \(z_2=\overline{z_1}=2-i\sqrt{3}\)。对于 \(z^2-2z+5=0\)，这是一个实系数二次方程，其判别式 \(\Delta=(-2)^2-4\times1\times5=-16<0\)。故 \(z=\frac{2+i\sqrt{16}}{2}=1+2i\) 或 \(z=1-2i\)。最终，(E2) 的解集为：
    {: .zh }

    \[
    \boxed{\bigl\{2+i\sqrt{3},\,2-i\sqrt{3},\,1+2i,\,1-2i\bigr\}}.
    \]

    D'après la question 5, on sait que l'ensemble des solutions de (E1) est inclus dans l'ensemble des solutions de (E2). Il suffit donc de vérifier si les solutions de (E2) sont solutions de (E1).

    根据第 5 题，(E1) 的解集包含于 (E2) 的解集。因此只需检验 (E2) 的解是否为 (E1) 的解。
    {: .zh }

    \[
    \begin{cases}
    \bigl(2+i\sqrt{3}\bigr)^2-3\bigl(2+i\sqrt{3}\bigr)+7\\
    \qquad=\bigl(1+4i\sqrt{3}\bigr)-6-3i\sqrt{3}+7
     =2+i\sqrt{3}\neq\overline{2+i\sqrt{3}},\\[4pt]
    (1+2i)^2-3(1+2i)+7=(-3+4i)-3-6i+7=1-2i=\overline{1+2i}.
    \end{cases}
    \]

    De même pour les conjugués. Finalement, l'ensemble des solutions de (E1) est égal à :

    共轭的情形同理。最终，(E1) 的解集为：
    {: .zh }

    \[
    \boxed{\bigl\{1+2i,\,1-2i\bigr\}}.
    \]

## Exercice 2　Trigonométrie <span class="heading-zh">练习 2 · 三角学（30 分）</span>

<strong>1.</strong> <strong>Question de cours.</strong> Rappeler les formules d'addition du cosinus et du sinus.
{: .fr-exo }

<strong>1.</strong> <strong>课程知识题。</strong>复述余弦与正弦的加法公式。
{: .zh }

!!! sol ""

    \[
    \forall(\alpha,\beta)\in\mathbb{R}^2,\quad
    \begin{cases}
    \cos(\alpha+\beta)=\cos(\alpha)\cos(\beta)-\sin(\alpha)\sin(\beta)\\[2pt]
    \sin(\alpha+\beta)=\cos(\alpha)\sin(\beta)+\sin(\alpha)\cos(\beta)
    \end{cases}.
    \]

    即：对任意 \((\alpha,\beta)\in\mathbb{R}^2\)，\(\cos(\alpha+\beta)=\cos(\alpha)\cos(\beta)-\sin(\alpha)\sin(\beta)\)，\(\sin(\alpha+\beta)=\cos(\alpha)\sin(\beta)+\sin(\alpha)\cos(\beta)\)。
    {: .zh }

<strong>2.</strong> <strong>Question de cours.</strong> Rappeler la définition de arc sinus.
{: .fr-exo }

<strong>2.</strong> <strong>课程知识题。</strong>复述反正弦的定义。
{: .zh }

!!! sol ""

    Pour tout \(y\in[-1,1]\), \(\arcsin(y)\) est l'unique \(\theta\in\bigl[-\frac{\pi}{2},\frac{\pi}{2}\bigr]\) tel que \(\sin(\theta)=y\).

    对任意 \(y\in[-1,1]\)，\(\arcsin(y)\) 是 \(\bigl[-\frac{\pi}{2},\frac{\pi}{2}\bigr]\) 中满足 \(\sin(\theta)=y\) 的唯一角 \(\theta\)。
    {: .zh }

Le but de la suite de l'exercice est de démontrer que :

本练习后续的目标是证明：
{: .zh }

\[
\forall x\in\,]-1,1],\quad
\arccos(x)=2\arctan\left(\sqrt{\frac{1-x}{1+x}}\right).
\]

Pour cela, on fixe \(x\in\,]-1,1]\) et on pose \(\theta=2\arctan\left(\sqrt{\frac{1-x}{1+x}}\right)\).

为此，固定 \(x\in\,]-1,1]\)，并令 \(\theta=2\arctan\left(\sqrt{\frac{1-x}{1+x}}\right)\)。
{: .zh }

<strong>3.</strong> Déterminer le tableau des variations de la fonction \(f:t\mapsto\frac{1-t}{1+t}\) en précisant les limites.
{: .fr-exo }

<strong>3.</strong> 确定函数 \(f:t\mapsto\frac{1-t}{1+t}\) 的变化表，并指出其极限。
{: .zh }

!!! sol ""

    On a \(1+t=0\Longleftrightarrow t=-1\). Donc la fonction \(f\) est définie et dérivable sur \(\mathbb{R}\setminus\{-1\}\) comme quotient de fonctions polynomiales dont le dénominateur ne s'annule pas. De plus :

    有 \(1+t=0\Longleftrightarrow t=-1\)。因此 \(f\) 作为分母不为零的多项式函数之商，在 \(\mathbb{R}\setminus\{-1\}\) 上有定义且可导。此外：
    {: .zh }

    \[
    \forall t\in\mathbb{R}\setminus\{-1\},\quad
    f'(t)=\frac{(-1)\times(1+t)-(1-t)\times1}{(1+t)^2}
    =\frac{-2}{(1+t)^2}<0.
    \]

    On en déduit le tableau des variations de \(f\) :

    由此得到 \(f\) 的变化表：
    {: .zh }

    \[
    \begin{array}{c|ccccccc}
    t & -\infty & & -1 & & 1 & & +\infty\\ \hline
    f'(t) & & - & \| & & - & 0 & \\ \hline
    f(t) & -1 & \searrow & \substack{+\infty\\[2pt]\|\\[2pt]-\infty} & \searrow & 0 & \searrow & -1
    \end{array}
    \]

    car :

    因为：
    {: .zh }

    \[
    \lim_{t\to+\infty} f(t)
    =\lim_{t\to+\infty}
    \underbrace{\frac{1-t}{1+t}}_{\substack{\text{forme}\\[1pt]\text{indéterminée}\\[1pt]\frac{\infty}{\infty}}}
    =\lim_{t\to+\infty}\frac{\frac1t-1}{\frac1t+1}=-1,
    \]

    \[
    \text{de même}\qquad
    \lim_{t\to-\infty} f(t)=\lim_{t\to-\infty}\frac{\frac1t-1}{\frac1t+1}=-1,
    \]

    \[
    \lim_{t\to-1^{+}} f(t)=\lim_{t\to-1^{+}}
    \frac{\overbrace{1-t}^{\to 2^{-}}}{\underbrace{1+t}_{\to 0^{+}}}=+\infty
    \qquad\text{et}\qquad
    \lim_{t\to-1^{-}} f(t)=\lim_{t\to-1^{-}}
    \frac{\overbrace{1-t}^{\to 2^{+}}}{\underbrace{1+t}_{\to 0^{-}}}=-\infty.
    \]

<strong>4.</strong> En déduire que \(\theta\) est bien défini et que \(\theta\in[0,\pi[\).
{: .fr-exo }

<strong>4.</strong> 由此推出 \(\theta\) 有定义，且 \(\theta\in[0,\pi[\)。
{: .zh }

!!! sol ""

    On sait que \(\theta=2\arctan\bigl(\sqrt{f(x)}\bigr)\) où \(x\in\,]-1,1]\). En plaçant la valeur de \(f(1)=0\) dans le tableau des variations, on en déduit que \(f(x)\geqslant0\) donc \(\sqrt{f(x)}\) est bien définie. Par définition de arc tangente, \(\arctan\bigl(\sqrt{f(x)}\bigr)\) est l'unique angle appartenant à \(\bigl]-\frac{\pi}{2},\frac{\pi}{2}\bigr[\) dont la tangente est égale à \(\sqrt{f(x)}\). D'après le cercle trigonométrique, on en déduit que \(\arctan\bigl(\sqrt{f(x)}\bigr)\in\bigl[0,\frac{\pi}{2}\bigr[\) car \(\sqrt{f(x)}\geqslant0\). Ainsi :

    已知 \(\theta=2\arctan\bigl(\sqrt{f(x)}\bigr)\)，其中 \(x\in\,]-1,1]\)。在变化表中代入 \(f(1)=0\)，可推出 \(f(x)\geqslant0\)，故 \(\sqrt{f(x)}\) 有定义。按反正切的定义，\(\arctan\bigl(\sqrt{f(x)}\bigr)\) 是 \(\bigl]-\frac{\pi}{2},\frac{\pi}{2}\bigr[\) 中正切值等于 \(\sqrt{f(x)}\) 的唯一角。由三角圆可知，因 \(\sqrt{f(x)}\geqslant0\)，有 \(\arctan\bigl(\sqrt{f(x)}\bigr)\in\bigl[0,\frac{\pi}{2}\bigr[\)。于是：
    {: .zh }

    \[
    0\leqslant\arctan\left(\sqrt{f(x)}\right)<\frac{\pi}{2}
    \qquad\text{donc}\qquad
    0\leqslant\underbrace{2\arctan\left(\sqrt{f(x)}\right)}_{=\theta}<\pi.
    \]

    Finalement, on a bien montré que <strong class="text-red">\(\theta\) est bien défini</strong> et que <strong class="text-red">\(\theta\in[0,\pi[\)</strong>.

    最终证明了 \(\theta\) 有定义，且 \(\theta\in[0,\pi[\)。
    {: .zh }

<strong>5.</strong> Exprimer \(\cos(\theta)\) en fonction de \(\tan(\theta/2)\).
{: .fr-exo }

<strong>5.</strong> 用 \(\tan(\theta/2)\) 表示 \(\cos(\theta)\)。
{: .zh }

!!! sol ""

    Puisque \(\frac{\theta}{2}\in\bigl[0,\frac{\pi}{2}\bigr[\) d'après la question 4, \(\tan(\theta/2)\) est bien défini et \(\cos(\theta/2)\neq0\). D'après la formule de l'angle double du cosinus, on a :

    由第 4 题知 \(\frac{\theta}{2}\in\bigl[0,\frac{\pi}{2}\bigr[\)，故 \(\tan(\theta/2)\) 有定义且 \(\cos(\theta/2)\neq0\)。由余弦的二倍角公式：
    {: .zh }

    \[
    \cos(\theta)=\cos\left(2\frac{\theta}{2}\right)=2\cos^2\left(\frac{\theta}{2}\right)-1.
    \]

    De plus, d'après les théorèmes de Pythagore et de Thalès, on a :

    此外，由勾股定理与泰勒斯定理：
    {: .zh }

    \[
    1+\tan^2\left(\frac{\theta}{2}\right)
    =1+\frac{\sin^2\left(\frac{\theta}{2}\right)}{\cos^2\left(\frac{\theta}{2}\right)}
    =\frac{\cos^2\left(\frac{\theta}{2}\right)+\sin^2\left(\frac{\theta}{2}\right)}
           {\cos^2\left(\frac{\theta}{2}\right)}
    =\frac{1}{\cos^2\left(\frac{\theta}{2}\right)}.
    \]

    Par conséquent :

    因此：
    {: .zh }

    \[
    \cos(\theta)=2\frac{1}{1+\tan^2\left(\frac{\theta}{2}\right)}-1
    =\frac{2-\left(1+\tan^2\left(\frac{\theta}{2}\right)\right)}{1+\tan^2\left(\frac{\theta}{2}\right)}
    =\boxed{\frac{1-\tan^2\left(\frac{\theta}{2}\right)}{1+\tan^2\left(\frac{\theta}{2}\right)}}.
    \]

<strong>6.</strong> Conclure en rappelant la définition de \(\arccos(x)\).
{: .fr-exo }

<strong>6.</strong> 结合 \(\arccos(x)\) 的定义作出结论。
{: .zh }

!!! sol ""

    Par définition, \(\boxed{\arccos(x) \text{ est l'unique angle appartenant à } [0,\pi] \text{ dont le cosinus est égal à } x}\).

    按定义，\(\arccos(x)\) 是 \([0,\pi]\) 中余弦值等于 \(x\) 的唯一角。
    {: .zh }

    À la question 4, on a montré que \(\theta\in[0,\pi[\), en particulier \(\theta\in[0,\pi]\). Ainsi, il suffit de montrer que \(\cos(\theta)=x\) pour en déduire que \(\theta=\arccos(x)\). Or on a :

    第 4 题已证 \(\theta\in[0,\pi[\)，特别地 \(\theta\in[0,\pi]\)。因此只需证明 \(\cos(\theta)=x\)，即可推出 \(\theta=\arccos(x)\)。而：
    {: .zh }

    \[
    \begin{aligned}
    \tan\left(\frac{\theta}{2}\right)
    &=\tan\left(\arctan\left(\sqrt{\frac{1-x}{1+x}}\right)\right)
      &&\text{car } \theta=2\arctan\left(\sqrt{\frac{1-x}{1+x}}\right)\\
    &=\sqrt{\frac{1-x}{1+x}}
      &&\text{par définition de l'arc tangente.}
    \end{aligned}
    \]

    D'après la question 5, on en déduit que :

    由第 5 题推出：
    {: .zh }

    \[
    \cos(\theta)=\frac{1-\tan^2\left(\frac{\theta}{2}\right)}{1+\tan^2\left(\frac{\theta}{2}\right)}
    =\frac{1-\frac{1-x}{1+x}}{1+\frac{1-x}{1+x}}
    =\frac{(1+x)-(1-x)}{(1+x)+(1-x)}=x.
    \]

    Par définition de l'arc cosinus, on en déduit que \(\theta=\arccos(x)\). Finalement, on a montré que :

    按反余弦的定义，推出 \(\theta=\arccos(x)\)。最终证明了：
    {: .zh }

    \[
    \boxed{\forall x\in\,]-1,1],\quad
    \arccos(x)=2\arctan\left(\sqrt{\frac{1-x}{1+x}}\right)}.
    \]

<strong>1.</strong> <strong>Question de cours.</strong> Rappeler le théorème de factorisation à l'aide d'une racine.

<strong>1.</strong> <strong>课程知识题。</strong>复述利用根进行因式分解的定理。

!!! sol ""

    Soient \(P\in\mathbb{K}[X]\) et \(\alpha\in\mathbb{K}\) où \(\mathbb{K}=\mathbb{R}\) ou \(\mathbb{C}\). Alors :

    设 \(P\in\mathbb{K}[X]\) 且 \(\alpha\in\mathbb{K}\)，其中 \(\mathbb{K}=\mathbb{R}\) 或 \(\mathbb{C}\)。则：

<strong>2.</strong> <strong>Question de cours.</strong> Rappeler la définition de la multiplicité d'une racine.
{: .fr-exo }

<strong>2.</strong> <strong>课程知识题。</strong>复述根的重数的定义。
{: .zh }

!!! sol ""

    Soit \(\alpha\in\mathbb{K}\) une racine de \(P\in\mathbb{K}[X]\setminus\{0\}\) où \(\mathbb{K}=\mathbb{R}\) ou \(\mathbb{C}\). La multiplicité de \(\alpha\) est l'entier \(m\in\mathbb{N}^{*}\) tel que \(P(\alpha)=P'(\alpha)=\cdots=P^{(m-1)}(\alpha)=0\) et \(P^{(m)}(\alpha)\neq0\).

    设 \(\alpha\in\mathbb{K}\) 是 \(P\in\mathbb{K}[X]\setminus\{0\}\) 的根，其中 \(\mathbb{K}=\mathbb{R}\) 或 \(\mathbb{C}\)。\(\alpha\) 的重数是满足 \(P(\alpha)=P'(\alpha)=\cdots=P^{(m-1)}(\alpha)=0\) 且 \(P^{(m)}(\alpha)\neq0\) 的整数 \(m\in\mathbb{N}^{*}\)。
    {: .zh }

<strong>3.</strong> Pour cette question, on fixe un entier \(n\geqslant2\) et on pose \(P=(X+1)^n\).
{: .fr-exo }

<strong>3.</strong> 本题固定整数 \(n\geqslant2\)，并令 \(P=(X+1)^n\)。
{: .zh }

<strong>3 (a).</strong> En dérivant \(P\) de deux manières différentes, montrer que \(\displaystyle\sum_{k=1}^{n}k\binom{n}{k}=n2^{n-1}\).
{: .fr-exo }

<strong>3 (a).</strong> 用两种不同方法对 \(P\) 求导，证明 \(\displaystyle\sum_{k=1}^{n}k\binom{n}{k}=n2^{n-1}\)。
{: .zh }

!!! sol ""

    - <u>Méthode 1.</u> D'après les propriétés de la dérivée :

        <u>方法 1。</u> 根据导数的性质：
        {: .zh }

        \[
        P'=n(X+1)^{n-1}.
        \]

    - <u>Méthode 2.</u> D'après la formule du binôme de Newton :

        <u>方法 2。</u> 根据牛顿二项式公式：
        {: .zh }

        \[
        P=(X+1)^n=\sum_{k=0}^{n}\binom{n}{k}X^k1^{n-k}=\sum_{k=0}^{n}\binom{n}{k}X^k.
        \]

        Par conséquent :

        因此：
        {: .zh }

        \[
        P'=\sum_{k=1}^{n}\binom{n}{k}kX^{k-1}.
        \]

        On en déduit que \(P'(1)\) est égal à :

        由此，\(P'(1)\) 等于：
        {: .zh }

        \[
        n(1+1)^{n-1}=\sum_{k=1}^{n}k\binom{n}{k}1^{k-1}
        \qquad\text{donc}\qquad
        \boxed{\sum_{k=1}^{n}k\binom{n}{k}=n2^{n-1}}.
        \]

<strong>3 (b).</strong> Montrer que \(\displaystyle\sum_{k=2}^{n}k(k-1)\binom{n}{k}=n(n-1)2^{n-2}\).
{: .fr-exo }

<strong>3 (b).</strong> 证明 \(\displaystyle\sum_{k=2}^{n}k(k-1)\binom{n}{k}=n(n-1)2^{n-2}\)。
{: .zh }

!!! sol ""

    On utilise les mêmes méthodes qu'à la question 3(a) pour calculer \(P''\).

    我们采用与第 3(a) 题相同的方法计算 \(P''\)。
    {: .zh }

    - <u>Méthode 1.</u> \(P'=n(X+1)^{n-1}\) donc \(P''=n(n-1)(X+1)^{n-2}\).

        <u>方法 1。</u> \(P'=n(X+1)^{n-1}\)，故 \(P''=n(n-1)(X+1)^{n-2}\)。
        {: .zh }

    - <u>Méthode 2.</u> \(P'=\displaystyle\sum_{k=1}^{n}\binom{n}{k}kX^{k-1}\) donc \(P''=\displaystyle\sum_{k=2}^{n}\binom{n}{k}k(k-1)X^{k-2}\).

        <u>方法 2。</u> \(P'=\displaystyle\sum_{k=1}^{n}\binom{n}{k}kX^{k-1}\)，故 \(P''=\displaystyle\sum_{k=2}^{n}\binom{n}{k}k(k-1)X^{k-2}\)。
        {: .zh }

    On en déduit que \(P''(1)\) est égal à :

    由此，\(P''(1)\) 等于：
    {: .zh }

    \[
    \begin{gathered}
    n(n-1)(1+1)^{n-2}=\sum_{k=2}^{n}k(k-1)\binom{n}{k}1^{k-2}\\
    \text{donc}\qquad
    \boxed{\sum_{k=2}^{n}k(k-1)\binom{n}{k}=n(n-1)2^{n-2}}.
    \end{gathered}
    \]

<strong>3 (c).</strong> En déduire l'expression de \(\displaystyle\sum_{k=0}^{n}k^2\binom{n}{k}\) en fonction de \(n\).
{: .fr-exo }

<strong>3 (c).</strong> 由此推出 \(\displaystyle\sum_{k=0}^{n}k^2\binom{n}{k}\) 关于 \(n\) 的表达式。
{: .zh }

!!! sol ""

    \[
    \begin{aligned}
    \sum_{k=0}^{n}k^2\binom{n}{k}
    &=\sum_{k=1}^{n}k^2\binom{n}{k}\\
    &=\sum_{k=1}^{n}\bigl(k^2-k+k\bigr)\binom{n}{k}\\
    &=\sum_{k=1}^{n}\bigl(k^2-k\bigr)\binom{n}{k}+\sum_{k=1}^{n}k\binom{n}{k}\\
    &=\sum_{k=2}^{n}k(k-1)\binom{n}{k}+n2^{n-1}
      \quad\text{d'après la question 3(a)}\\
    &=n(n-1)2^{n-2}+n2^{n-1}
      \quad\text{d'après la question 3(b)}\\
    &=n\bigl(n-1+2\bigr)2^{n-2}\\
    &=\boxed{n(n+1)2^{n-2}}.
    \end{aligned}
    \]

    即先将求和从 \(k=0\) 改写为 \(k=1\)，再拆出 \(k(k-1)\) 部分并用 3(a)、3(b) 的结论化简。
    {: .zh }

<strong>4.</strong> Pour cette question, on considère le polynôme \(Q_{\lambda}=3X^4+\lambda X^3+1\) où \(\lambda>0\) est un paramètre réel.
{: .fr-exo }

<strong>4.</strong> 本题考虑多项式 \(Q_{\lambda}=3X^4+\lambda X^3+1\)，其中 \(\lambda>0\) 为实参数。
{: .zh }

<strong>4 (a).</strong> Pour quelles valeurs de \(\lambda\) le polynôme \(Q_{\lambda}\) admet-il une racine multiple ?
{: .fr-exo }

<strong>4 (a).</strong> \(\lambda\) 取何值时多项式 \(Q_{\lambda}\) 有重根？
{: .zh }

!!! sol ""

    On suppose que \(Q_{\lambda}\) admet une racine multiple notée \(\alpha\), donc \(Q_{\lambda}(\alpha)=Q'_{\lambda}(\alpha)=0\). En particulier :

    假设 \(Q_{\lambda}\) 有一个重根，记为 \(\alpha\)，即 \(Q_{\lambda}(\alpha)=Q'_{\lambda}(\alpha)=0\)。特别地：
    {: .zh }

    \[
    0=Q'_{\lambda}(\alpha)=12\alpha^3+3\lambda\alpha^2
    =12\left(\alpha+\frac{\lambda}{4}\right)\alpha^2.
    \]

    Puisque \(Q_{\lambda}(0)=1\neq0\), on en déduit que \(\alpha\neq0\) et donc \(\alpha=-\lambda/4\). Par conséquent :

    由于 \(Q_{\lambda}(0)=1\neq0\)，推出 \(\alpha\neq0\)，故 \(\alpha=-\lambda/4\)。因此：
    {: .zh }

    \[
    0=Q_{\lambda}(\alpha)=Q_{\lambda}\left(-\frac{\lambda}{4}\right)
    =3\left(-\frac{\lambda}{4}\right)^4+\lambda\left(-\frac{\lambda}{4}\right)^3+1
    =\frac{3\lambda^4}{4^4}-\frac{\lambda^4}{4^3}+1
    =\frac{-\lambda^4+4^4}{4^4}.
    \]

    Puisque \(\lambda>0\), on en déduit que \(\lambda=4\). Réciproquement, si \(\lambda=4\) alors :

    由于 \(\lambda>0\)，推出 \(\lambda=4\)。反之，若 \(\lambda=4\)，则：
    {: .zh }

    \[
    Q_4(-1)=3(-1)^4+4(-1)^3+1=0
    \qquad\text{et}\qquad
    Q'_4(-1)=12(-1)^3+12(-1)^2=0.
    \]

    Donc \(Q_4\) admet bien une racine multiple. Finalement, \(\boxed{\lambda=4}\) est la seule valeur de \(\lambda\) pour laquelle \(Q_{\lambda}\) a une racine multiple.

    因此 \(Q_4\) 确实有重根。最终，\(\lambda=4\) 是使 \(Q_{\lambda}\) 有重根的唯一取值。
    {: .zh }

<strong>4 (b).</strong> Dans cette question, on suppose que \(\lambda=4\). Factoriser \(Q_4\) dans \(\mathbb{C}[X]\) et dans \(\mathbb{R}[X]\).
{: .fr-exo }

<strong>4 (b).</strong> 本题假设 \(\lambda=4\)。将 \(Q_4\) 分别在 \(\mathbb{C}[X]\) 与 \(\mathbb{R}[X]\) 中因式分解。
{: .zh }

!!! sol ""

    D'après la question 4(a), on sait déjà que \(Q_4\) est factorisable par \((X+1)^2\). On a :

    由第 4(a) 题已知 \(Q_4\) 可被 \((X+1)^2\) 整除。有：
    {: .zh }

    \[
    Q_4=3X^4+4X^3+1=\bigl(X^2+2X+1\bigr)\bigl(3X^2-2X+1\bigr)
    =\boxed{3(X+1)^2\left(X^2-\frac{2}{3}X+\frac{1}{3}\right)}.
    \]

    Puisque le discriminant de \(X^2-\frac{2}{3}X+\frac{1}{3}\) est égal à \(\Delta=\left(-\frac{2}{3}\right)^2-4\times1\times\frac{1}{3}=-\frac{8}{9}<0\), on a trouvé la factorisation dans \(\mathbb{R}[X]\). Il reste deux racines complexes égales à \(\frac{\frac{2}{3}+i\sqrt{\frac{8}{9}}}{2}=\frac{1+i\sqrt{2}}{3}\) et \(\frac{1-i\sqrt{2}}{3}\). Finalement, la factorisation dans \(\mathbb{C}[X]\) est :

    由于 \(X^2-\frac{2}{3}X+\frac{1}{3}\) 的判别式 \(\Delta=\left(-\frac{2}{3}\right)^2-4\times1\times\frac{1}{3}=-\frac{8}{9}<0\)，已得到 \(\mathbb{R}[X]\) 中的因式分解。还剩两个复根 \(\frac{\frac{2}{3}+i\sqrt{\frac{8}{9}}}{2}=\frac{1+i\sqrt{2}}{3}\) 与 \(\frac{1-i\sqrt{2}}{3}\)。最终，\(\mathbb{C}[X]\) 中的因式分解为：
    {: .zh }

    \[
    Q_4=\boxed{3(X+1)^2\left(X-\frac{1+i\sqrt{2}}{3}\right)\left(X-\frac{1-i\sqrt{2}}{3}\right)}.
    \]
