## 第 1 章　复数

### 定义

!!! success "Définition 1.1 : nombre complexe sous forme algébrique<br><span class='zh-title'>定义 1.1：代数形式的复数（nombre complexe sous forme algébrique）</span>"

    Un <strong>nombre complexe</strong> est un nombre de la forme \(z = x + iy\) où :

    一个<strong>复数</strong>是形如 \(z = x + iy\) 的数，其中：
    {: .zh }

    - \(x = \mathrm{Re}(z)\) est un nombre réel appelé la <strong>partie réelle</strong> du nombre complexe \(z\),

        \(x = \mathrm{Re}(z)\) 是一个实数，称为复数 \(z\) 的<strong>实部</strong>（partie réelle）；
        {: .zh }

    - \(y = \mathrm{Im}(z)\) est un nombre réel appelé la <strong>partie imaginaire</strong> du nombre complexe \(z\),

        \(y = \mathrm{Im}(z)\) 是一个实数，称为复数 \(z\) 的<strong>虚部</strong>（partie imaginaire）；
        {: .zh }

    - et \(i\) est un symbole mathématique.

        \(i\) 是一个数学符号。
        {: .zh }

    L'écriture \(x + iy\) est appelée la <strong>forme algébrique</strong> de \(z\). On note \(\mathbb{C}\) l'ensemble des nombres complexes :

    写法 \(x + iy\) 称为 \(z\) 的<strong>代数形式</strong>（forme algébrique）。记 \(\mathbb{C}\) 为复数集：
    {: .zh }

    \[
    \mathbb{C} = \{x + iy \mid (x,y) \in \mathbb{R}^2\}.
    \]

!!! success "Définition 1.3 : opérations avec les nombres complexes<br><span class='zh-title'>定义 1.3：复数的运算（opérations）</span>"

    L'ensemble \(\mathbb{C}\) est muni d'une <strong>addition</strong> et d'une <strong>multiplication</strong> définies par :

    集合 \(\mathbb{C}\) 上定义了<strong>加法</strong>（addition）与<strong>乘法</strong>（multiplication）：
    {: .zh }

    \[
    \forall (z,w) \in \mathbb{C}^2,\quad
    \begin{cases}
    z + w = \left[\mathrm{Re}(z) + \mathrm{Re}(w)\right] + i\left[\mathrm{Im}(z) + \mathrm{Im}(w)\right] \\[4pt]
    zw = \left[\mathrm{Re}(z)\mathrm{Re}(w) - \mathrm{Im}(z)\mathrm{Im}(w)\right]
         + i\left[\mathrm{Re}(z)\mathrm{Im}(w) + \mathrm{Im}(z)\mathrm{Re}(w)\right]
    \end{cases}.
    \]

!!! success "Définition 2.1 : représentation géométrique de \(\mathbb{C}\)<br><span class='zh-title'>定义 2.1：\(\mathbb{C}\) 的几何表示</span>"

    À chaque nombre complexe \(z = x + iy \in \mathbb{C}\), on associe le point \(M\) de coordonnées \((x,y) \in \mathbb{R}^2\) dans le plan euclidien. On dit aussi que \(z\) est l'<strong>affixe</strong> du point \(M\) ou du vecteur \(\overrightarrow{OM} = x\vec{e_1} + y\vec{e_2}\). Cette représentation de \(\mathbb{C}\) est appelée le <strong>plan complexe</strong>.

    对每个复数 \(z = x + iy \in \mathbb{C}\)，对应欧几里得平面中坐标为 \((x,y) \in \mathbb{R}^2\) 的点 \(M\)。 我们也说 \(z\) 是点 \(M\) 或向量 \(\overrightarrow{OM} = x\vec{e_1} + y\vec{e_2}\) 的<strong>坐标</strong>（affixe）。 \(\mathbb{C}\) 的这种表示称为<strong>复平面</strong>（plan complexe）。
    {: .zh }

!!! success "Définition 2.2 : conjugué<br><span class='zh-title'>定义 2.2：共轭（conjugué）</span>"

    Le <strong>conjugué</strong> d'un nombre complexe \(z = x + iy \in \mathbb{C}\) est le nombre complexe \(\bar{z} = x - iy\). Dans le plan complexe, \(\bar{z}\) est l'affixe du symétrique par rapport à l'axe des réels du point d'affixe \(z\).

    复数 \(z = x + iy \in \mathbb{C}\) 的<strong>共轭</strong>是复数 \(\bar{z} = x - iy\)。在复平面中，\(\bar{z}\) 是 坐标为 \(z\) 的点关于实轴的对称点的坐标。
    {: .zh }

!!! success "Définition 3.1 : module<br><span class='zh-title'>定义 3.1：模（module）</span>"

    Le <strong>module</strong> d'un nombre complexe \(z = x + iy \in \mathbb{C}\) est le nombre réel positif :

    复数 \(z = x + iy \in \mathbb{C}\) 的<strong>模</strong>是非负实数：
    {: .zh }

    \[
    |z| = \sqrt{x^2 + y^2}.
    \]

    Dans le plan complexe, \(|z|\) est la distance entre l'origine \(O\) et le point d'affixe \(z\), c'est-à-dire la norme euclidienne du vecteur d'affixe \(z\).

    在复平面中，\(|z|\) 是原点 \(O\) 与坐标为 \(z\) 的点之间的距离，即坐标为 \(z\) 的向量的欧几里得范数。
    {: .zh }

!!! success "Définition 4.1 : argument d'un nombre complexe non nul<br><span class='zh-title'>定义 4.1：非零复数的辐角（argument）</span>"

    Soit \(z \in \mathbb{C}^*\). On appelle <strong>argument</strong> de \(z\), noté \(\arg(z)\), toute mesure en radians de l'angle orienté \((\vec{e_1},\overrightarrow{OM})\) où \(M\) est le point d'affixe \(z\) dans le plan complexe.

    设 \(z \in \mathbb{C}^*\)。称 \(z\) 的<strong>辐角</strong>，记作 \(\arg(z)\)，为有向角 \((\vec{e_1},\overrightarrow{OM})\) 的任意弧度度量，其中 \(M\) 是复平面中坐标为 \(z\) 的点。
    {: .zh }

!!! success "Définition 5.1 : notation exponentielle du cercle unité<br><span class='zh-title'>定义 5.1：单位圆的指数记号</span>"

    Pour tout \(\theta \in \mathbb{R}\), on note \(e^{i\theta}\) l'unique nombre complexe de module 1 et d'argument \(\theta\), c'est-à-dire :

    对任何 \(\theta \in \mathbb{R}\)，记 \(e^{i\theta}\) 为模为 1、辐角为 \(\theta\) 的唯一复数，即：
    {: .zh }

    \[
    e^{i\theta} = \cos(\theta) + i\sin(\theta).
    \]

    On obtient ainsi une nouvelle représentation du <strong>cercle unité</strong> :

    由此得到<strong>单位圆</strong>的一种新表示：
    {: .zh }

    \[
    \mathbb{U} = \{z \in \mathbb{C} \mid |z| = 1\} = \{e^{i\theta} \mid \theta \in \mathbb{R}\}.
    \]

    On a aussi en utilisant seulement l'argument principal : \(\mathbb{U} = \{e^{i\theta} \mid \theta \in\;]-\pi,\pi]\}\).

    只用主辐角也可写为 \(\mathbb{U} = \{e^{i\theta} \mid \theta \in\;]-\pi,\pi]\}\)。
    {: .zh }

!!! success "Définition 5.8 : exponentielle complexe<br><span class='zh-title'>定义 5.8：复指数（exponentielle complexe）</span>"

    On définit l'<strong>exponentielle</strong> d'un nombre complexe \(z = x + iy \in \mathbb{C}\) par :

    定义复数 \(z = x + iy \in \mathbb{C}\) 的<strong>指数</strong>为：
    {: .zh }

    \[
    e^z = e^xe^{iy} = e^x\cos(y) + ie^x\sin(y) \in \mathbb{C}.
    \]

!!! success "Définition 6.1 : forme exponentielle d'un nombre complexe non nul<br><span class='zh-title'>定义 6.1：非零复数的指数形式</span>"

    Tout \(z \in \mathbb{C}^*\) s'écrit de manière unique sous la forme \(z = \rho e^{i\theta}\) où \(\rho > 0\) et \(\theta \in \mathbb{R}\) est défini modulo \(2\pi\). De plus, on a \(\rho = |z|\) et \(\theta = \arg(z)\). Cette écriture est appelée la <strong>forme exponentielle</strong> de \(z\).

    任何 \(z \in \mathbb{C}^*\) 都能唯一地写成 \(z = \rho e^{i\theta}\) 的形式，其中 \(\rho > 0\)， \(\theta \in \mathbb{R}\) 模 \(2\pi\) 定义。此外有 \(\rho = |z|\)、\(\theta = \arg(z)\)。这种写法称为 \(z\) 的<strong>指数形式</strong>（forme exponentielle）。
    {: .zh }

!!! success "Définition 8.1 : racines \(n\)-ièmes de l'unité<br><span class='zh-title'>定义 8.1：\(n\) 次单位根（racines \(n\)-ièmes de l'unité）</span>"

    Soit \(n \in \mathbb{N}^*\). Les <strong>racines \(n\)-ièmes de l'unité</strong> sont les solutions de l'équation \(z^n = 1\) d'inconnue \(z \in \mathbb{C}\). On note \(\mathbb{U}_n\) l'ensemble des racines \(n\)-ièmes de l'unité.

    设 \(n \in \mathbb{N}^*\)。<strong>\(n\) 次单位根</strong>是方程 \(z^n = 1\)（未知量为 \(z \in \mathbb{C}\)）的解。 记 \(\mathbb{U}_n\) 为 \(n\) 次单位根之集。
    {: .zh }

### 性质

!!! danger "Propriété 1.5<br><span class='zh-title'>性质 1.5</span>"

    Les opérations avec les nombres complexes ont les mêmes propriétés algébriques que les opérations avec les nombres réels, en particulier :

    复数的运算与实数的运算具有相同的代数性质，特别地：
    {: .zh }

    - <strong>associativité</strong> : \(\forall (z_1,z_2,z_3) \in \mathbb{C}^3\), \(\begin{cases}(z_1+z_2)+z_3 = z_1+(z_2+z_3) \\[3pt] (z_1z_2)z_3 = z_1(z_2z_3)\end{cases}\) ,

        <strong>结合律</strong>（associativité）：\(\forall (z_1,z_2,z_3) \in \mathbb{C}^3\)， \(\begin{cases}(z_1+z_2)+z_3 = z_1+(z_2+z_3) \\[3pt] (z_1z_2)z_3 = z_1(z_2z_3)\end{cases}\) ,
        {: .zh }

    - <strong>commutativité</strong> : \(\forall (z_1,z_2) \in \mathbb{C}^2\), \(\begin{cases}z_1+z_2 = z_2+z_1 \\[3pt] z_1z_2 = z_2z_1\end{cases}\) ,

        <strong>交换律</strong>（commutativité）：\(\forall (z_1,z_2) \in \mathbb{C}^2\)， \(\begin{cases}z_1+z_2 = z_2+z_1 \\[3pt] z_1z_2 = z_2z_1\end{cases}\) ,
        {: .zh }

    - <strong>distributivité</strong> : \(\forall (z_1,z_2,z_3) \in \mathbb{C}^3\), \(z_1(z_2+z_3) = z_1z_2 + z_1z_3\).

        <strong>分配律</strong>（distributivité）：\(\forall (z_1,z_2,z_3) \in \mathbb{C}^3\)， \(z_1(z_2+z_3) = z_1z_2 + z_1z_3\)。
        {: .zh }

!!! danger "Propriété 2.5<br><span class='zh-title'>性质 2.5</span>"

    {: .zh }

    {: .zh }

!!! danger "Propriété 3.3 : inverse d'un nombre complexe<br><span class='zh-title'>性质 3.3：复数的逆元</span>"

    \forall z \in \mathbb{C},\quad |z| = \sqrt{z\bar{z}}.

    En particulier, tout nombre complexe \(z \neq 0\) admet un inverse qui est égal à \(\frac{1}{z} = \frac{\bar{z}}{|z|^2}\).

    特别地，任何非零复数 \(z \neq 0\) 都有逆元，且 \(\frac{1}{z} = \frac{\bar{z}}{|z|^2}\)。
    {: .zh }

### 定理与推论

!!! danger "Théorème 3.6 : inégalité triangulaire dans \(\mathbb{C}\)<br><span class='zh-title'>定理 3.6：\(\mathbb{C}\) 中的三角不等式</span>"

    \[
    \forall (z,w) \in \mathbb{C}^2,\quad |z + w| \leqslant |z| + |w|.
    \]

    Le cas d'égalité se produit si et seulement si \(z\bar{w} \in \mathbb{R}_+\), c'est-à-dire si et seulement si les points d'affixes \(z\) et \(w\) appartiennent à la même demi-droite issue de l'origine \(O\) dans le plan complexe.

    <strong>等号成立</strong>（cas d'égalité）当且仅当 \(z\bar{w} \in \mathbb{R}_+\)，即当且仅当坐标为 \(z\) 与 \(w\) 的点 在复平面中属于同一条从原点 \(O\) 出发的射线（demi-droite issue de l'origine）。
    {: .zh }

!!! danger "Corollaire 3.8<br><span class='zh-title'>推论 3.8</span>"

    \[
    \forall (z,w) \in \mathbb{C}^2,\quad \bigl||z| - |w|\bigr| \leqslant |z - w|.
    \]

!!! danger "Théorème 4.2 : forme trigonométrique d'un nombre complexe non nul<br><span class='zh-title'>定理 4.2：非零复数的三角形式</span>"

    Tout \(z \in \mathbb{C}^*\) s'écrit de manière unique sous la forme :

    任何 \(z \in \mathbb{C}^*\) 都能唯一地写成如下形式：
    {: .zh }

    \[
    z = \rho\left(\cos(\theta) + i\sin(\theta)\right)
    \]

    où \(\rho > 0\) et \(\theta \in \mathbb{R}\) est défini modulo \(2\pi\). De plus, on a \(\rho = |z|\) et \(\theta = \arg(z)\). Cette écriture est appelée la <strong>forme trigonométrique</strong> de \(z\).

    其中 \(\rho > 0\)，\(\theta \in \mathbb{R}\) 模 \(2\pi\) 定义。此外有 \(\rho = |z|\)、\(\theta = \arg(z)\)。 这种写法称为 \(z\) 的<strong>三角形式</strong>（forme trigonométrique）。
    {: .zh }

!!! danger "Théorème 7.1 : résolution des équations de degré 2 à coefficients réels<br><span class='zh-title'>定理 7.1：实系数二次方程的求解</span>"

    On considère une équation de degré 2 d'inconnue \(z \in \mathbb{C}\) de la forme :

    考虑未知量为 \(z \in \mathbb{C}\) 的二次方程，形如：
    {: .zh }

    \[
    \begin{aligned}
    az^2 + bz + c = 0 \tag{E}
    \end{aligned}
    \]

    où \((a,b,c) \in \mathbb{R}^3\) et \(a \neq 0\). Il y a trois cas selon le signe du nombre réel \(\Delta = b^2 - 4ac\) appelé le <strong>discriminant</strong> de (E).

    其中 \((a,b,c) \in \mathbb{R}^3\) 且 \(a \neq 0\)。根据实数 \(\Delta = b^2 - 4ac\)（称为 (E) 的 <strong>判别式</strong> discriminant）的符号分三种情况。
    {: .zh }

    - Si \(\Delta > 0\) alors (E) admet deux solutions réelles :

        若 \(\Delta > 0\)，则 (E) 有两个实根：
        {: .zh }

        \[
        \frac{-b + \sqrt{\Delta}}{2a} \quad \text{et} \quad \frac{-b - \sqrt{\Delta}}{2a}.
        \]

    - Si \(\Delta = 0\) alors (E) admet une seule solution réelle :

        若 \(\Delta = 0\)，则 (E) 只有一个实根：
        {: .zh }

        \[
        \frac{-b}{2a}.
        \]

    - Si \(\Delta < 0\) alors (E) admet deux solutions complexes conjuguées :

        若 \(\Delta < 0\)，则 (E) 有两个共轭复根：
        {: .zh }

        \[
        \frac{-b + i\sqrt{-\Delta}}{2a} \quad \text{et} \quad \frac{-b - i\sqrt{-\Delta}}{2a}.
        \]

!!! danger "Corollaire 7.3<br><span class='zh-title'>推论 7.3</span>"

    Si on note \(z_1\) et \(z_2\) les deux solutions de (E) (avec \(z_1 = z_2 = -\frac{b}{2a}\) dans le cas où \(\Delta = 0\)), alors :

    若记 \(z_1\) 与 \(z_2\) 为 (E) 的两个解（当 \(\Delta = 0\) 时 \(z_1 = z_2 = -\frac{b}{2a}\)），则：
    {: .zh }

    \[
    z_1 + z_2 = -\frac{b}{a} \quad \text{et} \quad z_1z_2 = \frac{c}{a}.
    \]

!!! danger "Corollaire 7.4<br><span class='zh-title'>推论 7.4</span>"

    Soit \((S,P) \in \mathbb{R}^2\). Deux nombres complexes \(z_1\) et \(z_2\) ont pour somme \(S\) et pour produit \(P\) si et seulement s'ils sont les solutions de l'équation \(z^2 - Sz + P = 0\) d'inconnue \(z \in \mathbb{C}\) :

    设 \((S,P) \in \mathbb{R}^2\)。两个复数 \(z_1\) 与 \(z_2\) 的和为 \(S\)、积为 \(P\)，当且仅当它们是方程 \(z^2 - Sz + P = 0\)（未知量为 \(z \in \mathbb{C}\)）的解：
    {: .zh }

    \[
    \begin{cases}
    z_1 + z_2 = S \\
    z_1z_2 = P
    \end{cases}
    \quad \Longleftrightarrow \quad
    \left\{z \in \mathbb{C} \mid z^2 - Sz + P = 0\right\} = \{z_1,z_2\}.
    \]

!!! danger "Théorème 8.2 : racines \(n\)-ièmes de l'unité sous forme exponentielle<br><span class='zh-title'>定理 8.2：\(n\) 次单位根的指数形式</span>"

    Soit \(n \in \mathbb{N}^*\). On a :

    设 \(n \in \mathbb{N}^*\)。有：
    {: .zh }

    \[
    \mathbb{U}_n = \left\{e^{2ik\pi/n} \mid k \in \{0,1,\dots,n-1\}\right\}
    = \left\{1,\ e^{2i\pi/n},\ e^{4i\pi/n},\ \dots,\ e^{2i(n-1)\pi/n}\right\} \subset \mathbb{U}.
    \]

    En particulier, il y a exactement \(n\) racines \(n\)-ièmes de l'unité.

    特别地，\(n\) 次单位根恰好有 \(n\) 个。
    {: .zh }

## 第 2 章　三角学

### 定义

!!! success "Définition 1.1 : le cercle trigonométrique<br><span class='zh-title'>定义 1.1：单位圆（le cercle trigonométrique）</span>"

    Le <strong>cercle trigonométrique</strong> est le cercle de centre \(O\) et de rayon \(1\) dans le plan euclidien :

    <strong>单位圆</strong>（cercle trigonométrique）是欧几里得平面中圆心为 \(O\)、半径为 \(1\) 的圆：
    {: .zh }

    \[
    \left\{(x,y)\in\mathbb{R}^2 \;\middle|\; x^2+y^2=1\right\}.
    \]

!!! success "Définition 1.2 : le nombre \(\pi\)<br><span class='zh-title'>定义 1.2：数 π</span>"

    Le <strong>demi-périmètre</strong> du cercle trigonométrique est noté \(\pi\). En particulier, la longueur totale parcourue après un <strong>tour complet</strong> du cercle trigonométrique est égale à \(2\pi\).

    单位圆的<strong>半周长</strong>（demi-périmètre）记作 \(\pi\)。特别地，绕单位圆<strong>一整圈</strong> （tour complet）所走过的总长度为 \(2\pi\)。
    {: .zh }

!!! success "Définition 1.3 : mesure d'angle orienté en radians<br><span class='zh-title'>定义 1.3：有向角的弧度数</span>"

    Soit \(M\) un point du cercle trigonométrique. La <strong>mesure en radians de l'angle orienté</strong> \((\vec{e_1},\overrightarrow{OM})\) est la longueur parcourue sur le cercle trigonométrique pour aller du point de coordonnées \((1,0)\) au point \(M\) avec un signe :

    设 \(M\) 是单位圆上的一点。<strong>有向角的弧度数</strong>（mesure en radians de l'angle orienté） \((\vec{e_1},\overrightarrow{OM})\) 是指：在单位圆上从坐标为 \((1,0)\) 的点走到点 \(M\) 所经过的 弧长，并带有一个符号：
    {: .zh }

    - <strong>positif</strong> si le cercle est parcouru dans le sens trigonométrique,

        若沿三角正方向绕圆，则为<strong>正</strong>；
        {: .zh }

    - <strong>négatif</strong> si le cercle est parcouru dans le sens opposé.

        若沿相反方向绕圆，则为<strong>负</strong>。
        {: .zh }

    En pratique, une mesure en radians d'un angle orienté est appelée plus simplement <strong>angle</strong>.

    实践中，有向角的弧度数被更简单地称为<strong>角</strong>（angle）。
    {: .zh }

!!! success "Définition 2.1 : cosinus et sinus<br><span class='zh-title'>定义 2.1：余弦与正弦</span>"

    Pour tout angle \(\theta\in\mathbb{R}\), on note \((\cos(\theta),\sin(\theta))\) les coordonnées du point \(M\) du cercle trigonométrique tel que l'angle orienté \((\vec{e_1},\overrightarrow{OM})\) ait \(\theta\) pour mesure en radians. On définit ainsi sur \(\mathbb{R}\) deux fonctions \(2\pi\)-périodiques, appelées respectivement <strong>cosinus</strong> et <strong>sinus</strong>.

    对任意角 \(\theta\in\mathbb{R}\)，记 \((\cos(\theta),\sin(\theta))\) 为单位圆上使得有向角 \((\vec{e_1},\overrightarrow{OM})\) 的弧度数为 \(\theta\) 的点 \(M\) 的坐标。由此在 \(\mathbb{R}\) 上 定义了两个以 \(2\pi\) 为周期的函数，分别称为<strong>余弦</strong>（cosinus）与<strong>正弦</strong>（sinus）。
    {: .zh }

!!! success "Définition 2.2 : tangente<br><span class='zh-title'>定义 2.2：正切</span>"

    On note \(T\) la droite <strong>tangente</strong> au cercle trigonométrique au point de coordonnées \((1,0)\), qui est donc <strong>parallèle</strong> à l'axe des ordonnées \((O\vec{e_2})\). Pour tout angle \(\theta\in\mathbb{R}\) tel que \(\cos(\theta)\neq 0\), on note \((1,\tan(\theta))\) les coordonnées du point d'<strong>intersection</strong> de \(T\) avec la droite passant par \(O\) et le point de coordonnées \((\cos(\theta),\sin(\theta))\). On définit ainsi sur \(\mathbb{R}\setminus\left\{\frac{\pi}{2}+k\pi \;\middle|\; k\in\mathbb{Z}\right\}\) une fonction \(\pi\)-périodique, appelée <strong>tangente</strong>.

    记 \(T\) 为单位圆在坐标为 \((1,0)\) 的点处的<strong>切线</strong>（droite tangente），它因此<strong>平行</strong>于 纵轴 \((O\vec{e_2})\)。对任意满足 \(\cos(\theta)\neq 0\) 的角 \(\theta\in\mathbb{R}\)，记 \((1,\tan(\theta))\) 为 \(T\) 与过 \(O\) 及坐标为 \((\cos(\theta),\sin(\theta))\) 的直线之<strong>交点</strong> （intersection）的坐标。由此在 \(\mathbb{R}\setminus\left\{\frac{\pi}{2}+k\pi \;\middle|\; k\in\mathbb{Z}\right\}\) 上定义了一个以 \(\pi\) 为周期的函数，称为<strong>正切</strong>（tangente）。
    {: .zh }

!!! success "Définition 4.1 : arc cosinus, arc sinus et arc tangente<br><span class='zh-title'>定义 4.1：反余弦、反正弦与反正切</span>"

    - Pour tout \(x\in[-1,1]\), l'unique \(\theta\in[0,\pi]\) tel que \(\cos(\theta)=x\) est noté \(\theta=\arccos(x)\). On définit ainsi une fonction \(\arccos:[-1,1]\to[0,\pi]\) appelée <strong>arc cosinus</strong>.

        对任意 \(x\in[-1,1]\)，使得 \(\cos(\theta)=x\) 的<strong>唯一</strong>的 \(\theta\in[0,\pi]\) 记作 \(\theta=\arccos(x)\)。由此定义了一个函数 \(\arccos:[-1,1]\to[0,\pi]\)，称为 <strong>反余弦</strong>（arc cosinus）。
        {: .zh }

    - Pour tout \(y\in[-1,1]\), l'unique \(\theta\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]\) tel que \(\sin(\theta)=y\) est noté \(\theta=\arcsin(y)\). On définit ainsi une fonction \(\arcsin:[-1,1]\to\left[-\frac{\pi}{2},\frac{\pi}{2}\right]\) appelée <strong>arc sinus</strong>.

        对任意 \(y\in[-1,1]\)，使得 \(\sin(\theta)=y\) 的唯一的 \(\theta\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]\) 记作 \(\theta=\arcsin(y)\)。由此定义了一个 函数 \(\arcsin:[-1,1]\to\left[-\frac{\pi}{2},\frac{\pi}{2}\right]\)，称为<strong>反正弦</strong> （arc sinus）。
        {: .zh }

    - Pour tout \(t\in\mathbb{R}\), l'unique \(\theta\in\left]-\frac{\pi}{2},\frac{\pi}{2}\right[\) tel que \(\tan(\theta)=t\) est noté \(\theta=\arctan(t)\). On définit ainsi une fonction \(\arctan:\mathbb{R}\to\left]-\frac{\pi}{2},\frac{\pi}{2}\right[\) appelée <strong>arc tangente</strong>.

        对任意 \(t\in\mathbb{R}\)，使得 \(\tan(\theta)=t\) 的唯一的 \(\theta\in\left]-\frac{\pi}{2},\frac{\pi}{2}\right[\) 记作 \(\theta=\arctan(t)\)。由此定义了一个 函数 \(\arctan:\mathbb{R}\to\left]-\frac{\pi}{2},\frac{\pi}{2}\right[\)，称为<strong>反正切</strong> （arc tangente）。
        {: .zh }

!!! danger "Théorème 4.3 : résolution des équations trigonométriques<br><span class='zh-title'>定理 4.3：三角方程的求解</span>"

    - Soit \(x\in[-1,1]\). Pour tout \(\theta\in\mathbb{R}\), on a :

        换言之，以 \(\theta\) 为未知量的方程 \(\cos(\theta)=x\) 的解集为：
        {: .zh }

        \[
        \left\{\arccos(x)+2k\pi \mid k\in\mathbb{Z}\right\}
        \cup\left\{-\arccos(x)+2k\pi \mid k\in\mathbb{Z}\right\}.
        \]

    - Soit \(y\in[-1,1]\). Pour tout \(\theta\in\mathbb{R}\), on a :

        设 \(y\in[-1,1]\)。对任意 \(\theta\in\mathbb{R}\)，有：
        {: .zh }

        \sin(\theta)=y \iff \theta\equiv\arcsin(y)\ \text{ou}\ \pi-\arcsin(y)\ \text{modulo}\ 2\pi .

        即 \(\sin(\theta)=y\) 当且仅当 \(\theta\equiv\arcsin(y)\) 或 \(\pi-\arcsin(y)\)（模 \(2\pi\)）。
        {: .zh .gloss }

        Autrement dit, l'ensemble des solutions de l'équation \(\sin(\theta)=y\) d'inconnue \(\theta\) est :

        换言之，以 \(\theta\) 为未知量的方程 \(\sin(\theta)=y\) 的解集为：
        {: .zh }

        \[
        \left\{\arcsin(y)+2k\pi \mid k\in\mathbb{Z}\right\}
        \cup\left\{\pi-\arcsin(y)+2k\pi \mid k\in\mathbb{Z}\right\}.
        \]

    - Soit \(t\in\mathbb{R}\). Pour tout \(\theta\in\mathbb{R}\setminus\left\{\frac{\pi}{2}+k\pi \mid k\in\mathbb{Z}\right\}\), on a :

        设 \(t\in\mathbb{R}\)。对任意 \(\theta\in\mathbb{R}\setminus\left\{\frac{\pi}{2}+k\pi \mid k\in\mathbb{Z}\right\}\)，有：
        {: .zh }

        \tan(\theta)=t \iff \theta\equiv\arctan(t)\ \text{ou}\ \arctan(t)+\pi\ \text{modulo}\ 2\pi .

        \]

## 第 3 章　多项式

### 定义

!!! success "Définition 1.1 : polynôme<br><span class='zh-title'>定义 1.1：多项式（polynôme）</span>"

    Un <strong>polynôme</strong> est une suite \((a_n)_{n\geqslant 0}\in\mathbb{K}^{\mathbb{N}}\) dont tous les termes sont nuls à partir d'un certain rang :

    <strong>多项式</strong>（polynôme）是一个序列 \((a_n)_{n\geqslant 0}\in\mathbb{K}^{\mathbb{N}}\)，其所有项从某一项起均为零：
    {: .zh }

    \[
    \exists N\in\mathbb{N},\quad \forall n>N,\quad a_n=0.
    \]

    Le polynôme est alors noté :

    该多项式则记为：
    {: .zh }

    \[
    P=a_0+a_1X+a_2X^2+\cdots+a_NX^N=\sum_{n=0}^{N}a_nX^n
    \]

    où \(X\) est un symbole mathématique. Les termes de la suite \((a_0,a_1,a_2,\dots)\in\mathbb{K}^{\mathbb{N}}\) sont appelés les <strong>coefficients</strong> du polynôme \(P\), en particulier le premier terme \(a_0\) est appelé le <strong>coefficient constant</strong> de \(P\). On note \(\mathbb{K}[X]\) l'ensemble des polynômes.

    其中 \(X\) 是一个数学符号。序列 \((a_0,a_1,a_2,\dots)\in\mathbb{K}^{\mathbb{N}}\) 的各项称为多项式 \(P\) 的<strong>系数</strong>（coefficients），特别地，第一项 \(a_0\) 称为 \(P\) 的<strong>常数项</strong>（coefficient constant）。所有多项式的集合记为 \(\mathbb{K}[X]\)。
    {: .zh }

!!! success "Définition 1.3 : opérations avec les polynômes<br><span class='zh-title'>定义 1.3：多项式的运算</span>"

    L'ensemble \(\mathbb{K}[X]\) est muni d'une <strong>addition</strong> et d'une <strong>multiplication</strong> définies pour tout \(P=\sum_{n=0}^{N_P}a_nX^n\in\mathbb{K}[X]\) et tout \(Q=\sum_{n=0}^{N_Q}b_nX^n\in\mathbb{K}[X]\) par :

    集合 \(\mathbb{K}[X]\) 上定义了<strong>加法</strong>（addition）与<strong>乘法</strong>（multiplication），对任意 \(P=\sum_{n=0}^{N_P}a_nX^n\in\mathbb{K}[X]\) 与 \(Q=\sum_{n=0}^{N_Q}b_nX^n\in\mathbb{K}[X]\)，定义为：
    {: .zh }

    \[
    \left\{
    \begin{aligned}
    P+Q &= (a_0+b_0)+(a_1+b_1)X+(a_2+b_2)X^2+\cdots\\
        &= \sum_{n=0}^{\max\{N_P,N_Q\}}(a_n+b_n)X^n,\\[4pt]
    PQ &= a_0b_0+(a_0b_1+a_1b_0)X+(a_0b_2+a_1b_1+a_2b_0)X^2+\cdots\\
       &= \sum_{n=0}^{N_P+N_Q}\left(\sum_{k=0}^{n}a_kb_{n-k}\right)X^n.
    \end{aligned}
    \right.
    \]

!!! success "Définition 2.1 : fonction polynomiale<br><span class='zh-title'>定义 2.1：多项式函数（fonction polynomiale）</span>"

    Une fonction \(f:\mathscr{D}\to\mathbb{K}\) définie sur \(\mathscr{D}\subset\mathbb{K}\) est dite <strong>polynomiale</strong> lorsqu'il existe un polynôme \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) tel que :

    定义在 \(\mathscr{D}\subset\mathbb{K}\) 上的函数 \(f:\mathscr{D}\to\mathbb{K}\) 称为<strong>多项式函数</strong>（fonction polynomiale），若存在多项式 \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) 使得：
    {: .zh }

    \[
    \forall x\in\mathscr{D},\quad f(x)=a_0+a_1x+a_2x^2+\cdots+a_Nx^N=\sum_{n=0}^{N}a_nx^n=P(x).
    \]

!!! success "Définition 2.3 : composition<br><span class='zh-title'>定义 2.3：复合（composition）</span>"

    L'ensemble \(\mathbb{K}[X]\) est muni d'une <strong>composition</strong> définie comme pour les fonctions, c'est-à-dire pour tout \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) et tout \(Q\in\mathbb{K}[X]\) :

    集合 \(\mathbb{K}[X]\) 上定义了<strong>复合</strong>（composition），其定义方式与函数的复合相同，即对任意 \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) 与 \(Q\in\mathbb{K}[X]\)：
    {: .zh }

    \[
    P\circ Q=a_0+a_1Q+a_2Q^2+\cdots+a_NQ^N=\sum_{n=0}^{N}a_nQ^n=P(Q).
    \]

!!! success "Définition 2.5 : dérivation<br><span class='zh-title'>定义 2.5：求导（dérivation）</span>"

    Pour tout polynôme \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\), on définit son <strong>polynôme dérivé</strong> par :

    对任意多项式 \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\)，定义其<strong>导多项式</strong>（polynôme dérivé）为：
    {: .zh }

    \[
    P'=a_1+2a_2X+3a_3X^2+\cdots+Na_NX^{N-1}=\sum_{n=0}^{N-1}(n+1)a_{n+1}X^n.
    \]

    On peut dériver plusieurs fois : pour tout \(k\in\mathbb{N}\), on note \(P^{(k)}\) le <strong>polynôme dérivé \(k\) fois</strong> qui est défini par \(P^{(0)}=P\) et la relation de récurrence \(P^{(k+1)}=(P^{(k)})'\).

    可以多次求导：对任意 \(k\in\mathbb{N}\)，记 \(P^{(k)}\) 为<strong>求导 \(k\) 次所得的多项式</strong>，它由 \(P^{(0)}=P\) 与递推关系 \(P^{(k+1)}=(P^{(k)})'\) 定义。
    {: .zh }

!!! success "Définition 3.1 : degré d'un polynôme<br><span class='zh-title'>定义 3.1：多项式的次数（degré）</span>"

    Soit \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\). Si \(P\neq0\) alors il existe un unique entier \(\deg(P)\in\mathbb{N}\), appelé le <strong>degré</strong> de \(P\), tel que :

    设 \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\)。若 \(P\neq0\)，则存在唯一的整数 \(\deg(P)\in\mathbb{N}\)，称为 \(P\) 的<strong>次数</strong>（degré），使得：
    {: .zh }

    \[
    P=a_0+a_1X+a_2X^2+\cdots+a_{\deg(P)}X^{\deg(P)}
    \qquad\text{et}\qquad a_{\deg(P)}\neq0.
    \]

    Si \(P=0\), on utilise la convention \(\deg(0)=-\infty\). Pour tout \(n\in\mathbb{N}\), on note \(\mathbb{K}_n[X]\) l'ensemble des polynômes de degré inférieur ou égal à \(n\) (y compris le polynôme nul).

    若 \(P=0\)，采用约定 \(\deg(0)=-\infty\)。对任意 \(n\in\mathbb{N}\)，记 \(\mathbb{K}_n[X]\) 为次数小于或等于 \(n\) 的多项式（包括零多项式）的集合。
    {: .zh }

!!! success "Définition 3.3 : coefficient dominant<br><span class='zh-title'>定义 3.3：首项系数（coefficient dominant）</span>"

    Soit \(P\in\mathbb{K}[X]\setminus\{0\}\). Le coefficient d'indice \(\deg(P)\) de \(P\) est appelé son <strong>coefficient dominant</strong>. De plus, on dit que \(P\) est <strong>unitaire</strong> lorsque son coefficient dominant est égal à 1.

    设 \(P\in\mathbb{K}[X]\setminus\{0\}\)。\(P\) 中下标为 \(\deg(P)\) 的系数称为它的<strong>首项系数</strong>（coefficient dominant）。此外，若首项系数等于 1，则称 \(P\) 是<strong>首一的</strong>（unitaire）。
    {: .zh }

!!! success "Définition 4.1 : racine<br><span class='zh-title'>定义 4.1：根（racine）</span>"

    On dit qu'un nombre \(\alpha\in\mathbb{K}\) est une <strong>racine</strong> d'un polynôme \(P\in\mathbb{K}[X]\) lorsque \(P(\alpha)=0\).

    若 \(P(\alpha)=0\)，则称数 \(\alpha\in\mathbb{K}\) 是多项式 \(P\in\mathbb{K}[X]\) 的一个<strong>根</strong>（racine）。
    {: .zh }

!!! success "Définition 4.7 : multiplicité d'une racine<br><span class='zh-title'>定义 4.7：根的重数（multiplicité）</span>"

    On dit qu'un nombre \(\alpha\in\mathbb{K}\) est une racine de <strong>multiplicité</strong> \(m\in\mathbb{N}^*\) d'un polynôme \(P\in\mathbb{K}[X]\setminus\{0\}\) lorsque :

    若对多项式 \(P\in\mathbb{K}[X]\setminus\{0\}\) 有：
    {: .zh }

    \[
    P(\alpha)=P'(\alpha)=\cdots=P^{(m-1)}(\alpha)=0
    \quad\text{et}\quad P^{(m)}(\alpha)\neq0,
    \]

    Autrement dit, la <strong>multiplicité</strong> d'une racine \(\alpha\) de \(P\) est le plus grand entier \(m\in\mathbb{N}^*\) tel que \(P\) est factorisable par \((X-\alpha)^m\). Une racine de multiplicité 1 est dite <strong>simple</strong> alors qu'une racine de multiplicité au moins égale à 2 est dite <strong>multiple</strong>.

    则称数 \(\alpha\in\mathbb{K}\) 是 \(P\) 的一个<strong>重数</strong>（multiplicité）为 \(m\in\mathbb{N}^*\) 的根。换言之，\(P\) 的根 \(\alpha\) 的<strong>重数</strong>是使得 \(P\) 可被 \((X-\alpha)^m\) 因式分解的最大整数 \(m\in\mathbb{N}^*\)。重数为 1 的根称为<strong>单根</strong>（simple），而重数至少为 2 的根称为<strong>重根</strong>（multiple）。
    {: .zh }

### 性质

!!! danger "Propriété 1.5<br><span class='zh-title'>性质 1.5</span>"

    Comme pour les nombres (réels ou complexes), l'addition et la multiplication de polynômes ont les mêmes propriétés algébriques : l'<strong>associativité</strong>, la <strong>commutativité</strong> et la <strong>distributivité</strong>.

    与（实或复）数一样，多项式的加法与乘法具有相同的代数性质：<strong>结合律</strong>（associativité）、<strong>交换律</strong>（commutativité）与<strong>分配律</strong>（distributivité）。
    {: .zh }

!!! danger "Propriété 2.6<br><span class='zh-title'>性质 2.6</span>"

    Pour tout \((P,Q)\in\mathbb{K}[X]^2\) :

    对任意 \((P,Q)\in\mathbb{K}[X]^2\)：
    {: .zh }

    \[
    (P+Q)'=P'+Q',\qquad (PQ)'=P'Q+PQ'\qquad\text{et}\qquad (P\circ Q)'=(P'\circ Q)Q'.
    \]

!!! danger "Propriété 3.4<br><span class='zh-title'>性质 3.4</span>"

    - \(\forall(P,Q)\in\mathbb{K}[X]^2\), \(\deg(P+Q)\leqslant\max\bigl\{\deg(P),\deg(Q)\bigr\}\) avec égalité si \(\deg(P)\neq\deg(Q)\),

        对任意 \((P,Q)\in\mathbb{K}[X]^2\)，\(\deg(P+Q)\leqslant\max\{\deg(P),\deg(Q)\}\)，且当 \(\deg(P)\neq\deg(Q)\) 时取等号，
        {: .zh }

    - \(\forall(P,Q)\in\mathbb{K}[X]^2\), \(\deg(PQ)=\deg(P)+\deg(Q)\),

        对任意 \((P,Q)\in\mathbb{K}[X]^2\)，\(\deg(PQ)=\deg(P)+\deg(Q)\)，
        {: .zh }

    - \(\forall(P,Q)\in\mathbb{K}[X]^2\), \(\deg(Q)\geqslant1\implies\deg(P\circ Q)=\deg(P)\deg(Q)\),

        对任意 \((P,Q)\in\mathbb{K}[X]^2\)，\(\deg(Q)\geqslant1\implies\deg(P\circ Q)=\deg(P)\deg(Q)\)，
        {: .zh }

    - \(\forall(P,k)\in\mathbb{K}[X]\times\mathbb{N}\), \(\deg(P^{(k)})=\begin{cases}\deg(P)-k & \text{si } \deg(P)\geqslant k,\\ -\infty & \text{sinon}.\end{cases}\)

        对任意 \((P,k)\in\mathbb{K}[X]\times\mathbb{N}\)，\(\deg(P^{(k)})=\begin{cases}\deg(P)-k & \text{若 } \deg(P)\geqslant k,\\ -\infty & \text{否则}.\end{cases}\)
        {: .zh }

### 定理与推论

!!! danger "Théorème 1.6 : formule du binôme de Newton<br><span class='zh-title'>定理 1.6：牛顿二项式公式</span>"

    Pour tout \((P,Q)\in\mathbb{K}[X]^2\) et tout \(n\in\mathbb{N}\) :

    对任意 \((P,Q)\in\mathbb{K}[X]^2\) 与任意 \(n\in\mathbb{N}\)：
    {: .zh }

    \[
    (P+Q)^n=\sum_{k=0}^{n}\binom{n}{k}P^kQ^{n-k}
    \quad\text{où}\quad \binom{n}{k}=\frac{n!}{k!(n-k)!}.
    \]

!!! danger "Théorème 2.7 : formule de Taylor pour les polynômes<br><span class='zh-title'>定理 2.7：多项式的泰勒公式</span>"

    Soient \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) et \(a\in\mathbb{K}\). Alors :

    设 \(P=\sum_{n=0}^{N}a_nX^n\in\mathbb{K}[X]\) 且 \(a\in\mathbb{K}\)。则：
    {: .zh }

    \[
    P=\sum_{n=0}^{N}\frac{P^{(n)}(a)}{n!}(X-a)^n.
    \]

    En particulier : \(\forall n\in\mathbb{N},\ a_n=\frac{P^{(n)}(0)}{n!}\).

    特别地：\(\forall n\in\mathbb{N},\ a_n=\frac{P^{(n)}(0)}{n!}\)。
    {: .zh }

!!! danger "Théorème 3.6 : intégrité dans \(\mathbb{K}[X]\)<br><span class='zh-title'>定理 3.6：\(\mathbb{K}[X]\) 的整性</span>"

    \[
    \forall(P,Q)\in\mathbb{K}[X]^2,\quad PQ=0\iff(P=0\ \text{ou}\ Q=0).
    \]

    即：两个多项式之积为零，当且仅当其中至少有一个为零。
    {: .zh }

!!! danger "Théorème 4.3 : factorisation à l'aide d'une racine<br><span class='zh-title'>定理 4.3：利用根进行因式分解</span>"

    Soient \(P\in\mathbb{K}[X]\) et \(\alpha\in\mathbb{K}\). Alors \(\alpha\) est une racine de \(P\) si et seulement si \(P\) est <strong>factorisable</strong> par \(X-\alpha\) :

    设 \(P\in\mathbb{K}[X]\) 且 \(\alpha\in\mathbb{K}\)。则 \(\alpha\) 是 \(P\) 的根当且仅当 \(P\) 可被 \(X-\alpha\) <strong>因式分解</strong>：
    {: .zh }

    \[
    P(\alpha)=0\iff\exists R\in\mathbb{K}[X],\quad P=(X-\alpha)R.
    \]

!!! danger "Théorème 4.5 : factorisation à l'aide d'une racine multiple<br><span class='zh-title'>定理 4.5：利用重根进行因式分解</span>"

    Soient \(P\in\mathbb{K}[X]\), \(\alpha\in\mathbb{K}\) et \(m\in\mathbb{N}^*\). Alors :

    设 \(P\in\mathbb{K}[X]\)，\(\alpha\in\mathbb{K}\)，\(m\in\mathbb{N}^*\)。则：
    {: .zh }

    \[
    P(\alpha)=P'(\alpha)=\cdots=P^{(m-1)}(\alpha)=0
    \iff\exists R\in\mathbb{K}[X],\quad P=(X-\alpha)^mR.
    \]

!!! danger "Théorème 4.9 : nombre de racines<br><span class='zh-title'>定理 4.9：根的个数</span>"

    Tout polynôme \(P\in\mathbb{K}[X]\) de degré \(d=\deg(P)\geqslant0\) (donc \(P\neq0\)) admet au plus \(d\) racines comptées avec leurs multiplicités, c'est-à-dire que si \(m_1,m_2,\dots,m_r\) sont les multiplicités des racines de \(P\) alors \(m_1+m_2+\cdots+m_r\leqslant d\).

    任意次数为 \(d=\deg(P)\geqslant0\)（故 \(P\neq0\)）的多项式 \(P\in\mathbb{K}[X]\) 至多有 \(d\) 个按重数计算的根，即若 \(m_1,m_2,\dots,m_r\) 是 \(P\) 的各根的重数，则 \(m_1+m_2+\cdots+m_r\leqslant d\)。
    {: .zh }

!!! danger "Théorème 5.1 : interpolation de Lagrange<br><span class='zh-title'>定理 5.1：拉格朗日插值</span>"

    Soit \(n\in\mathbb{N}\). On considère \(n+1\) points \((x_0,y_0),(x_1,y_1),\dots,(x_n,y_n)\) dans le plan \(\mathbb{R}^2\), tels que \(x_0<x_1<\cdots<x_n\). Alors il existe un unique polynôme \(P\in\mathbb{R}_n[X]\) de degré inférieur ou égal à \(n\) dont la courbe représentative passe par ces points, c'est-à-dire tel que :

    设 \(n\in\mathbb{N}\)。考虑平面 \(\mathbb{R}^2\) 中 \(n+1\) 个点 \((x_0,y_0),(x_1,y_1),\dots,(x_n,y_n)\)，满足 \(x_0<x_1<\cdots<x_n\)。则存在唯一的次数小于或等于 \(n\) 的多项式 \(P\in\mathbb{R}_n[X]\)，其图像经过这些点，即满足：
    {: .zh }

    \[
    \forall i\in\llbracket0,n\rrbracket,\quad P(x_i)=y_i.
    \]

    De plus :

    此外：
    {: .zh }

    \[
    P=\sum_{j=0}^{n}y_jL_j
    \qquad\text{où}\qquad
    L_j=\prod_{\substack{i=0\\i\neq j}}^{n}\frac{X-x_i}{x_j-x_i}.
    \]

    Les polynômes \(L_0,L_1,\dots,L_n\) sont appelés les <strong>polynômes interpolateurs de Lagrange</strong> associés à \(x_0,x_1,\dots,x_n\).

    多项式 \(L_0,L_1,\dots,L_n\) 称为与 \(x_0,x_1,\dots,x_n\) 相关联的<strong>拉格朗日插值多项式</strong>（polynômes interpolateurs de Lagrange）。
    {: .zh }

!!! danger "Théorème 6.1 : théorème fondamental de l'algèbre (de d'Alembert-Gauss)<br><span class='zh-title'>定理 6.1：代数基本定理（达朗贝尔--高斯定理）</span>"

    Tout polynôme \(P\in\mathbb{C}[X]\) qui n'est pas constant admet au moins une racine complexe.

    任意非常数多项式 \(P\in\mathbb{C}[X]\) 至少有一个复根。
    {: .zh }

!!! danger "Corollaire 6.2 : factorisation dans \(\mathbb{C}[X]\)<br><span class='zh-title'>推论 6.2：\(\mathbb{C}[X]\) 中的因式分解</span>"

    Tout polynôme \(P\in\mathbb{C}[X]\) de degré \(d=\deg(P)\geqslant0\) (donc \(P\neq0\)) admet exactement \(d\) racines complexes comptées avec leurs multiplicités. De plus, si on note \(\alpha_1,\alpha_2,\dots,\alpha_r\) les racines complexes de \(P\), toutes différentes, et \(m_1,m_2,\dots,m_r\) leurs multiplicités respectives, alors on peut <strong>factoriser</strong> \(P\) sous la forme :

    任意次数为 \(d=\deg(P)\geqslant0\)（故 \(P\neq0\)）的多项式 \(P\in\mathbb{C}[X]\) 恰有 \(d\) 个按重数计算的复根。此外，若记 \(\alpha_1,\alpha_2,\dots,\alpha_r\) 为 \(P\) 的互不相同的复根，\(m_1,m_2,\dots,m_r\) 为它们各自的重数，则可将 \(P\) <strong>因式分解</strong>为：
    {: .zh }

    \[
    P=a_d(X-\alpha_1)^{m_1}(X-\alpha_2)^{m_2}\dots(X-\alpha_r)^{m_r}
    \]

    où \(a_d\neq0\) est le coefficient dominant de \(P\) et \(m_1+m_2+\cdots+m_r=d\).

    其中 \(a_d\neq0\) 是 \(P\) 的首项系数，且 \(m_1+m_2+\cdots+m_r=d\)。
    {: .zh }

!!! danger "Corollaire 6.4 : factorisation dans \(\mathbb{R}[X]\)<br><span class='zh-title'>推论 6.4：\(\mathbb{R}[X]\) 中的因式分解</span>"

    Tout polynôme \(P\in\mathbb{R}[X]\setminus\{0\}\) peut se factoriser sous la forme d'un produit de son coefficient dominant, de polynômes unitaires de degré 1 à coefficients réels (qui correspondent aux racines réelles de \(P\)), et de polynômes unitaires de degré 2 à coefficients réels de discriminant strictement négatif.

    任意多项式 \(P\in\mathbb{R}[X]\setminus\{0\}\) 都可分解为其首项系数、次数为 1 的实系数首一多项式（对应于 \(P\) 的实根）以及判别式严格为负的次数为 2 的实系数首一多项式的乘积。
    {: .zh }
