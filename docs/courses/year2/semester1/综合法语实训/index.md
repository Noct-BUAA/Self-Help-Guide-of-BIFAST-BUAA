# 综合法语实训

## 课程简介

综合法语实训（Français Général – Travaux Pratiques 3）是北航中法未来科技学院大二上学期的法语实践课程。课程以法国原版法语实训讲义 *Français Général – Travaux Pratiques 3* 为依托，围绕“未来的交通”（Transport de demain）与“低空经济”（Économie de basse altitude）两个单元展开，把语言学习与工程技术话题结合起来。

每课遵循“头脑风暴（Brainstorming）— 理解（Comprendre）— 表达工具（Outils d'expression）— 交流（Échanger）— 文化（Culture）— 词汇（Vocabulaire）”的结构：先通过图片、视频和阅读材料接触真实语料，再整理比较、论证、让步、预测等功能表达，最后围绕技术与社会议题进行口头讨论和书面表达。

网站收录的六课讲义均由课程 LaTeX 源文件转换为网页，保留法语原文与中文对照；每课附手写答案整理、词汇表与打印版 PDF。另收录一份 Échanger 写作备考手册，汇总写作结构、六个话题的论点与句型、功能句型库和四篇范文；并附一份作文考前速记，帮助在考场上复用电动车与自动驾驶两篇重点范文。

## 学习建议

1. **先掌握话题词汇，再练句型。** 每课词汇表按“交通工具—市场—环境—风险—产业”分组。先遮住中文用法语复述，再把词放进 Outils d'expression 的句子里，避免只背单词不会用。

2. **把每课的 Outils 部分当作写作素材。** 比较领先与落后（être en avance sur / être en retard dans）、表达让步（même si / malgré tout）、介绍利弊（offrir des avantages / soulever des questions）都是议论文和口语讨论的骨架，建议整句背诵。

3. **语法点跟着课文走。** 第 3 课的简单将来时、第 4 课的条件式现在时、第 5 课的关系代词、第 6 课的 mettre 表达，都是课后练习和写作的高频考点。先理解课文中的原句，再完成 S'entraîner 的改写与填空。

4. **用 Échanger 手册做输出训练。** 每个话题先列自己的三点论点，再从手册中挑选对应句型和连接词，最后对照四篇范文检查结构：引言—两方面论证—结论。写作时注意法语议论文常用的让步与限定，避免绝对化表达。考前再用《作文考前速记》把重点范文压缩成通用骨架与专用句块，减少背诵量。

5. **打印版适合批注与背诵。** 网页版便于检索和跳转，PDF 版保留原讲义的版式，适合打印后在课堂或自习时做笔记。
