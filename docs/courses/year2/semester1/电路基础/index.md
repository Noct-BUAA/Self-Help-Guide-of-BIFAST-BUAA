# 电路基础

## 课程简介

电路基础（Électrocinétique et circuits électriques，动电学与电路）是北航中法未来科技学院大二上学期的专业基础课程，以法语授课，系统介绍电荷输运、电路基本量、能量耗散与电路结构。

课程从微观的电荷运动出发，建立电流密度、漂移速度、德鲁德模型与微观欧姆定律，再过渡到宏观的电流强度、电压、二端元件、电动势与电源模型；随后讨论电阻、欧姆定律、电功率与焦耳效应，最后引入节点、支路、回路与基尔霍夫定律。

讲义为中法对照形式：每个知识点先给出法语原文，再附中文翻译与术语解释。本页收录的讲义由原始 LaTeX 源文件渲染为网页，公式、插图与版式均按原讲义还原。原讲义是课堂填空版，推导与例题中的公式留白供课上填写；网站版本已补全全部公式，便于课后复习与核对。

课程内容分为四大模块：

- **电荷输运**：电荷载流子、电流密度、漂移速度、德鲁德模型、微观欧姆定律、电导率与电阻率。
- **电路基础**：电流强度、电压与电势差、二端元件与约定方向、电动势、理想电压源与理想电流源。
- **能量耗散**：电阻与电导、欧姆定律、电功率、焦耳效应、电容器的储能与释能。
- **电路结构**：节点、支路与回路，串联与并联的等效电阻/电容，基尔霍夫节点定律与回路定律。

## 学习建议

电路基础的概念密度不高，但公式与符号约定较多，且考试为法语命题。建议按以下顺序梳理：

1. **先抓住“微观—宏观”两条线。** 第 1 章从电子运动讲到电流密度与微观欧姆定律，第 2、3 章则转向电流强度、电压、电阻等宏观量。复习时把 \(J \leftrightarrow I\)、\(\sigma \leftrightarrow R\)、\(\vec{E} \leftrightarrow U\) 这三组对应关系串起来，公式就不容易混。

2. **记公式时同时记适用条件。** 欧姆定律只适用于欧姆导体，焦耳效应的 \(P = RI^2\) 也只对电阻成立；电容器公式 \(Q = CU\)、\(E = \frac{1}{2}CU^2\) 与电阻公式不要混用。

3. **符号约定先定后算。** 二端元件的接收器约定与电源约定、基尔霍夫定律中的电流/电压正负号，是例题与考试中最容易出错的地方。列方程前先在图上标清方向，再统一代入符号。

4. **注意单位与数量级。** mm\(^2\) 与 m\(^2\)、mA 与 A、m\(\Omega\) 与 \(\Omega\) 的换算在例题中反复出现；算完后用单位检查等式是否齐次，是快速验算的好方法。

5. **熟悉法语术语。** 考试为法语命题，intensité、tension、dipôle、maille、nœud 等术语需要做到看到即懂。复习时可先遮住中文，直接阅读讲义的法语部分，再用[词汇表](词汇表.md)查漏补缺。
