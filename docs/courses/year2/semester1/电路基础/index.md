# 电路基础

## 课程简介

电路基础（Électrostatique et électrocinétique）是北航中法未来科技学院大二上学期的专业基础课程，以法语授课。课程由两大部分组成：**静电学**建立电荷、电场、高斯定理、导体与电容器的基本理论；**动电学与电路**则从电荷输运出发，建立电流、电压、电阻、电功率与基尔霍夫定律，为后续电路分析打基础。

课程从微观的电荷运动出发，建立电流密度、漂移速度、德鲁德模型与微观欧姆定律，再过渡到宏观的电流强度、电压、二端元件、电动势与电源模型；静电学部分则从库仑定律讲到高斯定理、导体平衡、电容器与电偶极子。

讲义为中法对照形式：每个知识点先给出法语原文，再附中文翻译与术语解释。本页收录的讲义由原始 LaTeX 源文件渲染为网页，公式、插图与版式均按原讲义还原。动电学部分的原讲义是课堂填空版，推导与例题中的公式留白供课上填写；网站版本已补全全部公式，便于课后复习与核对。

课程内容分为两大部分：

- **第一部分 静电学**：电荷的基本性质、库仑力、电场与场线、三种坐标系、连续电荷分布、静电势与等势线；高斯定理及其在无限大平面、圆柱、球体上的应用；导体的静电平衡、法拉第笼、尖端效应、电容器与储能；电偶极子的电势、电场及其在外场中的受力与力矩。
- **第二部分 动电学与电路**：电荷载流子、电流密度、漂移速度、德鲁德模型、微观欧姆定律、电导率与电阻率；电流强度、电压与电势差、二端元件与约定方向、电动势、理想电压源与电流源；电阻与电导、欧姆定律、电功率、焦耳效应、电容器储能；节点、支路与回路，串并联等效，基尔霍夫定律。

## 学习建议

电路基础的概念密度不高，但公式与符号约定较多，且考试为法语命题。建议按以下顺序梳理：

1. **先建立静电学的图像。** 从库仑力到电场、场线、电势，再到高斯定理，核心是“场”的观点：不再追踪电荷之间的直接作用，而是先求场，再由 \(\vec{F}=q\vec{E}\) 求力。高斯定理的难点在对称性分析，复习时先判断场的方向与依赖变量，再选高斯面。

2. **抓住“微观—宏观”两条线。** 动电学部分从电子运动讲到电流密度与微观欧姆定律，再转向电流强度、电压、电阻等宏观量。复习时把 \(J\leftrightarrow I\)、\(\sigma\leftrightarrow R\)、\(\vec{E}\leftrightarrow U\) 这三组对应关系串起来，公式就不容易混。

3. **记公式时同时记适用条件。** 欧姆定律只适用于欧姆导体，焦耳效应的 \(P=RI^2\) 也只对电阻成立；电容器公式 \(Q=CU\)、\(E=\frac12CU^2\) 与电阻公式不要混用。静电学中，高斯定理对任意闭合曲面成立，但只有高对称情形才能直接求出场。

4. **符号约定先定后算。** 二端元件的接收器约定与电源约定、基尔霍夫定律中的电流/电压正负号、偶极矩由负电荷指向正电荷，都是最容易出错的地方。列方程前先在图上标清方向。

5. **注意单位与数量级。** mm\(^2\) 与 m\(^2\)、mA 与 A、m\(\Omega\) 与 \(\Omega\) 的换算在例题中反复出现；算完后用单位检查等式是否齐次，是快速验算的好方法。

6. **熟悉法语术语。** 考试为法语命题，intensité、tension、dipôle、maille、nœud、équipotentielle 等术语需要做到看到即懂。复习时可先遮住中文，直接阅读讲义的法语部分，再用词汇表查漏补缺。
