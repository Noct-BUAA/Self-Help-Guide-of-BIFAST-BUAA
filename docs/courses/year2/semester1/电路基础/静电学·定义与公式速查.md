## 第 1 章　力与静电场 <span class="heading-zh">Force et champ électrostatiques</span>

### 定义与基本关系

| 法文术语 | 中文 | 公式 / 表述 |
|---|---|---|
| force de Coulomb | 库仑力 | \(\overrightarrow{F_{12}}=\dfrac{q_1q_2}{4\pi\varepsilon_0 r^2}\,\vec{u}_{12}\) |
| champ électrique | 电场 | \(\vec{E}(M)=\dfrac{q}{4\pi\varepsilon_0 r^2}\,\vec{u}_r\)，且 \(\vec{F}=q\vec{E}\) |
| champ électrostatique | 静电场 | 由静止电荷产生、只依赖于位置的电场 |
| ligne de champ | 场线 | \(\vec{A}\wedge\mathrm{d}\overrightarrow{OM}=\vec{0}\)，且 \(\vec{A}\cdot\mathrm{d}\overrightarrow{OM}>0\) |
| distribution linéique | 线电荷分布 | \(\vec{E}(M)=\displaystyle\int_{P\in\Gamma}\dfrac{\lambda\,\mathrm{d}l}{4\pi\varepsilon_0 PM^2}\,\vec{u}\) |
| distribution surfacique | 面电荷分布 | \(\vec{E}(M)=\displaystyle\iint_{P\in\Sigma}\dfrac{\sigma\,\mathrm{d}S}{4\pi\varepsilon_0 PM^2}\,\vec{u}\) |
| distribution volumique | 体电荷分布 | \(\vec{E}(M)=\displaystyle\iiint_{P\in V}\dfrac{\rho\,\mathrm{d}V}{4\pi\varepsilon_0 PM^2}\,\vec{u}\) |
| principe de superposition | 叠加原理 | \(\vec{E}(M)=\displaystyle\sum_k\vec{E}_k(M)\) |
| énergie potentielle électrostatique | 静电势能 | \(E_p=\dfrac{q_1q_2}{4\pi\varepsilon_0 r}\)（取无穷远处为零） |
| potentiel électrostatique | 静电势 | \(V=\dfrac{q}{4\pi\varepsilon_0 r}\)，且 \(\vec{E}(M)=-\dfrac{\mathrm{d}V}{\mathrm{d}r}\vec{u}\) |
| circulation du champ | 静电场的环流 | \(C_{A\to B}=\displaystyle\int_A^B\vec{E}\cdot\mathrm{d}\vec{l}=V(A)-V(B)\) |
| équipotentielle | 等势线／等势面 | \(\mathrm{d}V=0\)，即 \(\mathrm{d}\vec{l}\perp\vec{E}\) |

### 三种坐标系的元位移

| 坐标系 | \(\mathrm{d}\overrightarrow{OM}\) |
|---|---|
| cartésiennes（笛卡尔） | \(\mathrm{d}x\,\vec{e}_x+\mathrm{d}y\,\vec{e}_y+\mathrm{d}z\,\vec{e}_z\) |
| cylindriques（柱） | \(\mathrm{d}r\,\vec{e}_r+r\,\mathrm{d}\theta\,\vec{e}_\theta+\mathrm{d}z\,\vec{e}_z\) |
| sphériques（球） | \(\mathrm{d}r\,\vec{e}_r+r\,\mathrm{d}\theta\,\vec{e}_\theta+r\sin\theta\,\mathrm{d}\phi\,\vec{e}_\phi\) |

## 第 2 章　高斯定理 <span class="heading-zh">Théorème de Gauss</span>

### 定义与定理

| 法文术语 | 中文 | 公式 / 表述 |
|---|---|---|
| plan de symétrie | 对称平面 | 分布关于平面成镜像且电荷符号不变；\(\vec{E}\) 在对称平面内 |
| plan d'antisymétrie | 反对称平面 | 分布关于平面成镜像但电荷符号相反；\(\vec{E}\) 垂直于该平面 |
| principe de Curie | 居里原理 | 原因的对称要素出现在结果中 |
| surface de Gauss | 高斯面 | 为利用对称性而选取的闭合曲面 |
| théorème de Gauss | 高斯定理 | \(\displaystyle\Phi=\oint_S\vec{E}\cdot\overrightarrow{\mathrm{d}S}=\frac{Q_{int}}{\varepsilon_0}\) |
| flux sortant | 向外通量 | 闭合曲面取外法向时的通量 |

### 高对称性结果

| 构型 | 区域 | 电场 |
|---|---|---|
| plan infini（无限大平面） | 平面外 | \(\vec{E}=\pm\dfrac{\sigma}{2\varepsilon_0}\,\vec{e}_x\) |
| cylindre infini（无限长圆柱） | \(r<a\) | \(\vec{E}=\dfrac{\rho r}{2\varepsilon_0}\,\vec{u}_r\) |
| cylindre infini | \(r>a\) | \(\vec{E}=\dfrac{\rho a^2}{2\varepsilon_0 r}\,\vec{u}_r\) |
| boule uniforme（均匀球体） | \(r<R\) | \(\vec{E}=\dfrac{\rho r}{3\varepsilon_0}\,\vec{u}_r\) |
| boule uniforme | \(r>R\) | \(\vec{E}=\dfrac{Q}{4\pi\varepsilon_0 r^2}\,\vec{u}_r=\dfrac{\rho R^3}{3\varepsilon_0 r^2}\,\vec{u}_r\) |

### 球体的电势

\[
\left\{
\begin{aligned}
r<R &: \qquad V(r)=\frac{\rho R^2}{6\varepsilon_0}\left(3-\frac{r^2}{R^2}\right),\\[4pt]
r\geq R &: \qquad V(r)=\frac{\rho R^3}{3\varepsilon_0 r}.
\end{aligned}
\right.
\]

### 引力类比

| Électrostatique | Gravitation |
|---|---|
| \(\vec{F}=\dfrac{1}{4\pi\varepsilon_0}\dfrac{q_1q_2}{r^2}\vec{u}\) | \(\vec{F}=-G\dfrac{m_1m_2}{r^2}\vec{u}\) |
| \(\displaystyle\oint\vec{E}\cdot\mathrm{d}\vec{S}=\frac{Q_{int}}{\varepsilon_0}\) | \(\displaystyle\oint\vec{A}\cdot\mathrm{d}\vec{S}=-4\pi G M_{int}\) |
| \(E_p=qV\) | \(E_{pg}=mV_g\) |

## 第 3 章　导体与电容器 <span class="heading-zh">Conducteurs et condensateurs</span>

### 定义与性质

| 法文术语 | 中文 | 公式 / 表述 |
|---|---|---|
| conducteur / isolant | 导体／绝缘体 | 导体有可移动电荷；绝缘体没有 |
| équilibre électrostatique | 静电平衡 | 导体内部宏观电场为零，电荷分布在表面 |
| volume équipotentiel | 等势体 | 导体内部电势处处相等 |
| cage de Faraday | 法拉第笼 | 封闭导体壳内部场为零，可屏蔽外场 |
| théorème de Coulomb | 库仑定理 | 导体表面紧邻处 \(\vec{E}=\dfrac{\sigma}{\varepsilon_0}\,\vec{n}\) |
| effet de pointe | 尖端效应 | 尖端处 \(\sigma\) 与 \(E\) 极大 |
| condensateur | 电容器 | 两块处于完全静电感应平衡的极板，带 \(\pm Q\) |
| capacité | 电容 | \(Q=C\,U\) |
| condensateur plan | 平行板电容器 | \(C=\dfrac{\varepsilon_0 S}{e}\)（介质中 \(C=\dfrac{\varepsilon S}{e}\)） |
| énergie stockée | 储存能量 | \(E=\dfrac{Q^2}{2C}=\dfrac12 C\,U^2\) |

### 平行板电容器的场

\[
\vec{E}(M)=-\frac{\sigma}{\varepsilon_0}\,\vec{e}_x
\quad\text{entre les armatures},\qquad
\vec{E}(M)=\vec{0}\quad\text{à l'extérieur}.
\]

## 第 4 章　电偶极子 <span class="heading-zh">Dipôles électrostatiques</span>

### 定义与场

| 法文术语 | 中文 | 公式 / 表述 |
|---|---|---|
| dipôle électrostatique | 电偶极子 | 两个等量异号点电荷 \(q,-q\) 相距 \(a\) |
| moment dipolaire | 电偶极矩 | \(\vec{p}=q\,\overrightarrow{NP}\)，方向由 \(-q\) 指向 \(+q\) |
| approximation dipolaire | 偶极近似 | \(r\gg a\)，偶极子只用 \(\vec{p}\) 刻画 |
| debye | 德拜 | \(1\ \mathrm{D}=3{,}336\cdot10^{-30}\ \mathrm{C\,m}\) |
| potentiel du dipôle | 偶极子电势 | \(V(M)=\dfrac{1}{4\pi\varepsilon_0}\dfrac{\vec{p}\cdot\vec{u}_r}{r^2}=\dfrac{1}{4\pi\varepsilon_0}\dfrac{\vec{p}\cdot\overrightarrow{OM}}{r^3}\) |
| champ du dipôle | 偶极子电场 | \(\vec{E}=\dfrac{1}{4\pi\varepsilon_0 r^3}\left(3(\vec{p}\cdot\vec{u}_r)\vec{u}_r-\vec{p}\right)\) |

### 外场中的作用

| 情形 | 合力 | 力矩 | 势能 |
|---|---|---|---|
| champ uniforme（均匀场） | \(\vec{F}=\vec{0}\) | \(\overrightarrow{M_O}=\vec{p}\wedge\vec{E}\) | \(E_p=-\vec{p}\cdot\vec{E}\) |
| champ non uniforme（非均匀场） | \(\vec{F}=\vec{\nabla}(\vec{p}\cdot\vec{E})\)，沿场强增大方向 | \(\overrightarrow{M_O}=\vec{p}\wedge\vec{E}\)（\(E\) 取在 \(O\) 点） | \(E_p=-\vec{p}\cdot\vec{E}\) |

!!! tip "记忆要点"

    - 均匀场中偶极子不受合力，只受力矩；力矩倾向于让 \(\vec{p}\) 与 \(\vec{E}\) 同向。
    - \(\theta=0\) 为稳定平衡，\(\theta=\pi\) 为不稳定平衡；势能 \(E_p=-\vec{p}\cdot\vec{E}\) 在 \(\theta=0\) 处最小。
    - 非均匀场中，偶极子被吸引到场强更大的区域。
