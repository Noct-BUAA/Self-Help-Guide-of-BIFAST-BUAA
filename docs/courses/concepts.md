## 数学基础

### 极限计算的常见方法

1. **等价无穷小替换** — $e^x-1 \sim x$、$\ln(1+x) \sim x$、$\sin x \sim x$ 等
2. **洛必达法则** — 适用于 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型未定式
3. **泰勒展开** — 法国工程师数学中最核心的极限计算工具
4. **夹逼定理** — 配合绝对值不等式使用

??? example "例题：求 $\lim_{x \to 0} \frac{e^x - \cos x}{x}$"

    当 $x \to 0$ 时：
    $$e^x = 1 + x + \frac{x^2}{2} + o(x^2)$$
    $$\cos x = 1 - \frac{x^2}{2} + o(x^2)$$

    代入得极限为 $1$。

### 线性代数核心概念

| 概念 | 直观理解 | 工程应用 |
|------|----------|----------|
| 特征值与特征向量 | 矩阵作用的"不变方向" | PCA降维、振动模态分析 |
| 奇异值分解 (SVD) | 矩阵分解为旋转-缩放-旋转 | 图像压缩、推荐系统 |
| 矩阵求导 | 标量对矩阵的偏导数 | 机器学习中的反向传播 |

## 物理概念辨析

### 力学中的三大守恒律

| 守恒律 | 条件 | 公式 |
|--------|------|------|
| 动量守恒 | 合外力为零 | $\sum \vec{p} = C^{te}$ |
| 角动量守恒 | 合外力矩为零 | $\sum \vec{L} = C^{te}$ |
| 机械能守恒 | 只有保守力做功 | $E_k + E_p = C^{te}$ |

### 电磁学基础

$$\oint \vec{E} \cdot d\vec{A} = \frac{Q_{int}}{\varepsilon_0} \quad \text{(高斯定理)}$$
$$\oint \vec{B} \cdot d\vec{l} = \mu_0 I + \mu_0\varepsilon_0\frac{d\Phi_E}{dt} \quad \text{(安培-麦克斯韦定律)}$$

## 专业核心难点

### 材料科学：晶体结构与缺陷

- **晶体结构**：FCC、BCC、HCP 是三种最基本的金属晶体结构
- **晶格缺陷**：点缺陷（空位、间隙原子）、线缺陷（位错）、面缺陷（晶界）
- **位错理论**：材料的塑性变形本质上是位错的运动

### 微电子：PN 结与 MOSFET

- **PN 结**：正向偏置导通、反向偏置截止
- **MOSFET**：通过栅极电压控制沟道导电性

### 计算机科学：算法复杂度

| 复杂度 | 常见算法 | 典型场景 |
|------|----------|----------|
| $O(1)$ | 数组下标访问 | 常数时间 |
| $O(\log n)$ | 二分查找 | 有序数据查找 |
| $O(n)$ | 线性查找 | 未排序数据遍历 |
| $O(n \log n)$ | 归并排序、快速排序 | 高效排序 |
| $O(n^2)$ | 冒泡排序 | 朴素算法 |
