# 数理基础法语（1）

## 课程简介

数理基础法语（1）是北航中法未来科技学院大一上学期的法语数学基础课程，由中法教师共同授课，课堂使用法语。课程旨在帮助学生在法语语境下掌握基础数学概念与表达，为后续全法语授课的数学和物理课程做好语言和知识双重准备。

课程内容涵盖数字与运算、字母表与拼读、分数幂与根、数集、集合关系、直线与角、多边形与圆七大模块，兼顾法语数学词汇积累与数学基础知识回顾。
