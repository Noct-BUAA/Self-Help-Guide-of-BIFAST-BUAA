## 一、Les articles（冠词）

法语中的冠词放在名词前面，用来表示名词的**性**（阴阳性）和**数**（单复数）。中文没有冠词的概念，因此这是中国学生容易出错的地方。法语冠词分为四种：**不定冠词**、**定冠词**、**缩合冠词**和**部分冠词**。使用冠词时，必须与名词的阴阳性和单复数保持一致。

**不定冠词（Articles indéfinis）** —— 表示「一个/一些」

不定冠词用于初次提到或不确定的人或事物，相当于中文的「一个/某个/一些」。

|  | **阳性**（*Masculin*） | **阴性**（*Féminin*） |
|--|------------------------|----------------------|
| **单数**（*Singulier*） | *un* | *une* |
| **复数**（*Pluriel*） | *des* |  |

**例句：**

* *un livre* —— 一本书
* *une table* —— 一张桌子
* *des amis* —— 一些朋友
* *C'est un étudiant.* —— 这是一个大学生。
* *J'ai une idée.* —— 我有一个想法。

!!! warning "否定句中的冠词变化"

    在否定句中，不定冠词 *un*, *une*, *des* 通常变成 *de*（或 *d'*）：

    * *J'ai un livre.* → *Je n'ai pas de livre.*（我没有书。）
    * *Il y a des amis.* → *Il n'y a pas d'amis.*（没有朋友。）

**定冠词（Articles définis）** —— 表示「这个/那个/这些/那些」

定冠词用于特指已知的、唯一的人或事物，或用于概括一类事物。

|  | **阳性** | **阴性** |
|--|----------|----------|
| **单数** | *le* | *la* |
| **复数** | *les* |  |

!!! warning "省音规则（Élision）"

    当 *le* 或 *la* 后面紧跟以元音或哑音 *h* 开头的名词时，必须省音为 *l'*：

    * *le + ami* → *l'ami*（那个朋友）
    * *la + école* → *l'école*（那所学校）
    * *le + hôtel* → *l'hôtel*（那家酒店）
    * 注意：*les* 不与后面的词省音，但需要联诵：*les\_amis*（[lezami]）

**例句：**

* *Le livre est sur la table.* —— 那本书在桌子上。
* *Les étudiants sont en cours.* —— 学生们在上课。
* *La France est un beau pays.* —— 法国是一个美丽的国家。

**缩合冠词（Articles contractés）** —— 介词 à/de 与定冠词的缩合

当介词 *à*（在/去）或 *de*（从/的）后面跟定冠词 *le* 或 *les* 时，必须进行缩合。这是法语的强制性规则。

| **组合** | **à + 冠词** | **de + 冠词** |
|----------|-------------|---------------|
| *à / de + le* | *au* | *du* |
| *à / de + la* | *à la*（不缩合） | *de la*（不缩合） |
| *à / de + l'* | *à l'*（不缩合） | *de l'*（不缩合） |
| *à / de + les* | *aux* | *des* |

**详解：**

* *à + le* = *au* ：*Je vais au cinéma.*（我去电影院。）
* *à + les* = *aux* ：*Il parle aux étudiants.*（他对学生们说话。）
* *de + le* = *du* ：*Le livre du professeur.*（教授的书。）
* *de + les* = *des* ：*Les amis des enfants.*（孩子们的朋友们。）

!!! warning "注意"

    当名词是**阴性**（*la*）或**元音开头**（*l'*）时，*à* 和 *de* 不缩合：

    * *à la* ：*Je vais à la bibliothèque.*（我去图书馆。）
    * *de l'* ：*Le prix de l'hôtel.*（酒店的价格。）

**部分冠词（Articles partitifs）** —— 表示「一些/部分」

部分冠词用于不可数名词（如食物、饮料、材料等），表示整体中的一部分。中文中常译为「一些」或省略不译。

|  | **阳性** | **阴性** |
|--|----------|----------|
| **辅音前** | *du* | *de la* |
| **元音前** | *de l'* |  |
| **复数** | *des* |  |

**例句：**

* *du pain* —— 一些面包
* *de la confiture* —— 一些果酱
* *de l'eau* —— 一些水
* *des légumes* —— 一些蔬菜
* *Je voudrais du café.* —— 我想要一些咖啡。
* *Il y a de la soupe.* —— 有一些汤。

!!! warning "否定句中的部分冠词变化"

    在否定句中，部分冠词 *du*, *de la*, *de l'*, *des* 都变成 *de*（或 *d'*）：

    * *Je mange du pain.* → *Je ne mange pas de pain.*
    * *Je prends de la soupe.* → *Je ne prends pas de soupe.*
    * *Il boit de l'eau.* → *Il ne boit pas d'eau.*

## 二、Le nom（名词）

法语名词都有性别：要么是**阳性**（*masculin*），要么是**阴性**（*féminin*）。记住名词的阴阳性是学习法语的基础——它影响冠词、形容词、代词等很多语法变化。虽然大部分以 *-e* 结尾的名词是阴性，但有很多例外，最好在学习每个新名词时一起记住它的性别。

**名词阴阳性变化规则（6种主要模式）**

| **规则** | **阳性** | **阴性** | **示例** |
|----------|----------|----------|----------|
| **一般规则**（加 *-e*） | *ami* | *amie* | *étudiant → étudiante*（学生） |
| **不变词**（同形） | \*élève\*, \*journaliste\*, \*artiste\*, \*secrétaire\* |  |  |
| **双写辅音 + e** | *lion* | *lionne* | *paysan → paysanne*（农民） |
| *-er → -ère* | *boulanger* | *boulangère* | *étranger → étrangère*（外国人） |
| *-ien → -ienne* | *musicien* | *musicienne* | *Parisien → Parisienne*（巴黎人） |
| *-eur → -euse* | *vendeur* | *vendeuse* | *danseur → danseuse*（舞者） |
| *-teur → -trice* | *acteur* | *actrice* | *chanteur → chanteuse*（歌手） |
| *-f → -ve* | *sportif* | *sportive* | *naïf → naïve*（天真的） |
| *-x → -se* | *époux* | *épouse* | *jaloux → jalouse*（嫉妒的） |
| *-c → -que* | *Turc* | *Turque* | *Grec → Grecque*（希腊人） |

**完全不规则词（阴阳性完全不同）**

| **阳性** | **中文** | **阴性** | **中文** |
|----------|----------|----------|----------|
| *le père* | 父亲 | *la mère* | 母亲 |
| *le mari / l'époux* | 丈夫 | *la femme / l'épouse* | 妻子 |
| *le frère* | 兄弟 | *la sœur* | 姐妹 |
| *le fils* | 儿子 | *la fille* | 女儿 |
| *l'oncle* | 叔叔/舅舅 | *la tante* | 阿姨/姑姑 |
| *le neveu* | 侄子/外甥 | *la nièce* | 侄女/外甥女 |
| *le roi* | 国王 | *la reine* | 女王/王后 |
| *l'homme* | 男人 | *la femme* | 女人 |

**名词复数变化规则（5种主要模式）**

| **规则** | **单数** | **复数** |
|----------|----------|----------|
| **一般规则**：加 *-s* | *un livre* | *des livres*（书） |
| 以 *-s/-x/-z* 结尾：不变 | *un cours* | *des cours*（课程） |
| *-al → -aux* | *le cheval* | *les chevaux*（马） |
| *-ail → -aux*（部分） | *le travail* | *les travaux*（工作） |
| *-eau → -eaux* | *le bureau* | *les bureaux*（办公室） |
| *-eu → -eux* | *le feu* | *les feux*（火） |
| *-ou → -ous*（一般规则） | *le clou* | *des clous*（钉子） |

!!! warning "7个以 *-ou* 结尾的例外名词"

    以下 7 个以 *-ou* 结尾的名词变复数时要加 *-x*：
    *bijou*（珠宝）、*caillou*（石头）、*chou*（卷心菜）、*genou*（膝盖）、*hibou*（猫头鹰）、*joujou*（玩具）、*pou*（虱子）

**完全不规则复数：**

* *œil*（眼睛）→ *yeux*
* *ciel*（天空）→ *cieux*
* *genou*（膝盖）→ *genoux*
* *travail*（工作）→ *travaux*

## 三、L'adjectif（形容词）

法语形容词要与所修饰的名词保持**性数一致**（阳性/阴性、单数/复数）。大多数情况下，在阳性形式后面加 *-e* 变成阴性，加 *-s* 变成复数。但也有许多特殊变化规则。

**形容词阴性变化规则**

| **规则** | **阳性** | **阴性** |
|----------|----------|----------|
| **一般规则**（加 *-e*） | *grand* | *grande*（大的） |
| 以 *-e* 结尾（不变） | *jeune* | *jeune*（年轻的） |
| *-s → -sse* | *gros* | *grosse*（大的/胖的） |
| *-er → -ère* | *cher* | *chère*（贵的/亲爱的） |
| *-ien → -ienne* | *italien* | *italienne*（意大利的） |
| *-on → -onne* | *bon* | *bonne*（好的） |
| *-eux → -euse* | *heureux* | *heureuse*（幸福的） |
| *-if → -ive* | *actif* | *active*（积极的） |
| *-f → -ve* | *neuf* | *neuve*（新的） |

**形容词的位置规则**

法语的品质形容词通常放在名词后面（与英语不同），但有一部分常用形容词放在名词前面（**BAGS** 规则：**B**eauty, **A**ge, **G**oodness, **S**ize）。

* **通常后置**（大多数形容词）：*un livre intéressant*（一本有趣的书）
* **必须前置**（常见特例）：

| 形容词 | 示例 |
|--------|------|
| *beau*（美丽的） | *un beau garçon*（一个帅气的男孩） |
| *bon*（好的） | *un bon restaurant*（一家好餐馆） |
| *grand*（大的） | *une grande maison*（一栋大房子） |
| *petit*（小的） | *un petit chien*（一只小狗） |
| *gros*（大的/胖的） | *un gros problème*（一个大问题） |
| *nouveau*（新的） | *un nouveau livre*（一本新书） |
| *vieux*（旧的） | *un vieux bâtiment*（一栋旧建筑） |
| *joli*（漂亮的） | *une jolie robe*（一条漂亮的裙子） |
| *jeune*（年轻的） | *un jeune homme*（一位年轻男士） |

!!! warning "特殊形式：*bel* 和 *nouvel*"

    *beau* 和 *nouveau* 在以元音开头的阳性单数名词前有特殊形式：
    *bel*（*un bel homme*）、*nouvel*（*un nouvel ami*）

**主有形容词（Adjectifs possessifs）**

主有形容词相当于中文的「我的、你的、他/她的、我们的、您/你们的、他/她们的」。注意：法语中主有形容词的**性数取决于被拥有的东西，而不是所有者**！

| **所有者** | **单数物品** | **复数物品** |  |
|-----------|-------------|-------------|--|
|  | **阳性** | **阴性** | **复数** | **中文** |
| *je* | *mon* | *ma*（→ *mon*） | *mes* | 我的 |
| *tu* | *ton* | *ta*（→ *ton*） | *tes* | 你的 |
| *il / elle* | *son* | *sa*（→ *son*） | *ses* | 他/她的 |
| *nous* | *notre* | *notre* | *nos* | 我们的 |
| *vous* | *votre* | *votre* | *vos* | 您/你们的 |
| *ils / elles* | *leur* | *leur* | *leurs* | 他/她们的 |

!!! warning "阴性名词 + 元音开头：用 *mon/ton/son* 代替 *ma/ta/sa*"

    当阴性单数名词以元音或哑音 *h* 开头时，不能用 *ma*, *ta*, *sa*，而要用 *mon*, *ton*, *son*（为了读音流畅）：

    * *mon amie*（✅）—— 不是 *ma amie*
    * *ton école*（✅）
    * *son histoire*（✅）

**指示形容词（Adjectifs démonstratifs）**

指示形容词相当于中文的「这个/那个」或「这些/那些」。法语中用一个词 *ce* 表示「这/那」，通过名词的性数判断具体含义。如果需要区分「这个」和「那个」，可以在名词后加 *-ci*（这个）或 *-là*（那个）。

|  | **单数** | **复数** |
|--|----------|----------|
| **阳性** | *ce / cet*（元音前） | *ces* |
| **阴性** | *cette* |  |

**用法举例：**

* *ce livre* —— 这本书/那本书
* *cet ami*（元音前用 *cet*）—— 这位朋友/那位朋友
* *cette table* —— 这张桌子/那张桌子
* *ces étudiants* —— 这些学生/那些学生
* *ce livre-ci* —— 这本书（近指）
* *ce livre-là* —— 那本书（远指）

## 四、L'interrogation（疑问句）

**三种疑问句形式**

* **语调疑问句**（口语/非正式）：陈述句语序，句末语调上扬
  *Tu habites à Paris* ?（你住在巴黎吗？）

* **Est-ce que 疑问句**（标准/中性）：陈述句前加 *est-ce que*
  *Est-ce que tu habites à Paris* ?

* **主谓倒装疑问句**（正式/书面）：主语和动词倒装
  *Habites-tu à Paris* ?

**初学者建议优先掌握前两种方式。**

**7个核心疑问词**

| **疑问词** | **中文** | **例句** |
|-----------|----------|----------|
| *Qui* | 谁 | *Qui est-ce* ? / *Qui parle* ?（这是谁？/谁在说话？） |
| *Que / Quoi* | 什么 | *Que faites-vous* ? / *Tu fais quoi* ?（您在做什么？） |
| *Où* | 哪里 | *Où habitez-vous* ?（您住在哪里？） |
| *Quand* | 什么时候 | *Quand partez-vous* ?（您什么时候出发？） |
| *Comment* | 怎么/怎么样 | *Comment allez-vous* ?（您好吗？） |
| *Combien* | 多少 | *Combien ça coûte* ?（这个多少钱？） |
| *Pourquoi* | 为什么 | *Pourquoi êtes-vous en retard* ?（您为什么迟到？） |

**Quel / Quels / Quelle / Quelles（哪个/哪些）**

这是一个需要与名词性数配合的疑问形容词。

|  | **单数** | **复数** |
|--|----------|----------|
| **阳性** | *Quel* | *Quels* |
| **阴性** | *Quelle* | *Quelles* |

**用法举例：**

* *Quel âge as-tu* ? —— 你几岁？（*âge* 是阳性单数）
* *Quelle heure est-il* ? —— 几点了？（*heure* 是阴性单数）
* *Quels sont vos hobbies* ? —— 你的爱好是什么？（复数阳性）
* *Quelles langues parlez-vous* ? —— 您说什么语言？（*langues* 复数阴性）

## 五、La négation（否定）

法语的否定句使用 *ne ... pas* 将动词包围起来的结构。在简单时态中，*ne* 放在动词前，*pas* 放在动词后。

* *Je ne mange **pas de viande**.*（我不吃肉。）
* *Il n'habite **pas ici**.*（他不住在这里。）
* 注意：*ne* 在元音前省音为 *n'*

**多种否定结构对比表**

| **否定结构** | **中文意思** | **例句** |
|-------------|-------------|----------|
| *ne ... pas* | 不/没有 | *Je ne mange pas de viande.* |
| *ne ... rien* | 什么也不 | *Je ne comprends rien.*（我什么都不懂。） |
| *ne ... jamais* | 从不 | *Je ne fume jamais.*（我从不抽烟。） |
| *ne ... personne* | 没有人 | *Je ne vois personne.*（我没看见任何人。） |
| *ne ... plus* | 不再 | *Il n'habite plus ici.*（他不再住在这里了。） |
| *ne ... aucun(e)* | 没有一个 | *Je n'ai aucune idée.*（我一点主意都没有。） |

!!! warning "复合时态中的否定（重要！）"

    在复合过去时（*passé composé*）等复合时态中，否定结构包围**助动词**，而不是过去分词。

    **结构公式：** *ne + 助动词 + pas/rien/jamais/plus + 过去分词*

    * *Je n'ai **pas mangé**.*（我没吃。）
    * *Il n'a **jamais voyagé**.*（他从未旅行过。）
    * *Elle n'a **rien dit**.*（她什么都没说。）

## 六、La comparaison（比较级）

比较级用于比较两个人或事物的程度。形容词要与主语进行性数配合。

| **结构** | **中文意思** | **例句** |
|----------|-------------|----------|
| *plus ... que* | 比......更...... | *Pierre est plus grand **que Paul**.*（皮埃尔比保罗高。） |
| *aussi ... que* | 和......一样...... | *Marie est aussi intelligente **que son frère**.*（玛丽和她的哥哥一样聪明。） |
| *moins ... que* | 不如...... | *Ce livre est moins intéressant **que le film**.*（这本书不如电影有趣。） |

**补充说明：**

* *plus* = 更（程度高）
* *moins* = 更少/不如（程度低）
* *aussi* = 一样（程度相等）
* *que* = 比/和（连接比较对象）
* 形容词要与主语性数配合：*Elle est aussi grande que lui.*（她和一样高。）

## 七、Les pronoms（代词）

**主语人称代词（Pronoms sujets）**

| **人称** | **单数** | **复数** |
|----------|----------|----------|
| **第一人称** | *je (j')* 我 | *nous* 我们 |
| **第二人称** | *tu* 你 | *vous* 您/你们 |
| **第三人称** | *il / elle / on* 他/她/我们/人们 | *ils / elles* 他们/她们 |

**特别说明：**

* *je* 在以元音开头的动词前省音为 *j'*（如 *j'ai*, *j'habite*）
* *on* 在口语中常代替 *nous*，表示「我们」
* *vous* 既是「您」（尊称单数）也是「你们」（复数）

**重读人称代词（Pronoms toniques）—— 完整表格**

重读人称代词用在：*c'est* 之后、介词之后、比较级之后。

| **人称** | **单数** | **复数** |
|----------|----------|----------|
| **第一人称** | *moi* 我 | *nous* 我们 |
| **第二人称** | *toi* 你 | *vous* 您/你们 |
| **第三人称（阳性）** | *lui* 他 | *eux* 他们 |
| **第三人称（阴性）** | *elle* 她 | *elles* 她们 |

**使用场景：**

* 用于 *c'est* 后：*C'est moi.*（是我。）
* 用于介词后：*avec lui*（和他一起）、*chez eux*（在他们家）
* 用于比较级：*plus grand que lui*（比他高）
* 用于加强语气：*Moi, je suis français.*（我嘛，我是法国人。）

**代词 y**

*y* 是法语中非常重要的代词，用来代替由介词 *à*, *dans*, *sur*, *en*, *chez* 等引导的地点。

* *y* 代替地点：*Je vais à Paris.* → *J'y vais.*（我去那里。）
* *y* 也可以代替 *à +* 事物：*Je pense à mon examen.* → *J'y pense.*
* 否定句中：*Je n'y vais pas.*（我不去那里。）
* 复合时态中：*J'y suis allé.*（我去过那里。）

## 八、Les verbes（动词）

法语动词变位是整个语法体系的核心。每个动词根据主语（6个人称）和时态有不同的词尾变化。本章节涵盖了本学期所有核心动词的变位规则，包括：*être/avoir*、第一组 *-er* 动词、第二组 *-ir* 动词、第三组不规则动词、代动词、命令式、最近将来时、复合过去时和最近过去时。

**être / avoir（是/有——最核心的两个动词）**

**Être（是 / 在）**

| **人称** | **现在时** | **中文** |
|----------|-----------|----------|
| *je* | *suis* | 我是 |
| *tu* | *es* | 你是 |
| *il / elle / on* | *est* | 他/她/我们是 |
| *nous* | *sommes* | 我们是 |
| *vous* | *êtes* | 您/你们是 |
| *ils / elles* | *sont* | 他们/她们是 |

**Avoir（有）**

| **人称** | **现在时** | **中文** |
|----------|-----------|----------|
| *j'* | *ai* | 我有 |
| *tu* | *as* | 你有 |
| *il / elle / on* | *a* | 他/她/我们有 |
| *nous* | *avons* | 我们有 |
| *vous* | *avez* | 您/你们有 |
| *ils / elles* | *ont* | 他/她们有 |

!!! warning "*avoir* 的常见固定搭配"

    *avoir* 用于很多常见表达（注意：中文说「是」，但法语用 *avoir*）：

    * *avoir faim* —— 饿了（不是 *être faim*！）
    * *avoir soif* —— 渴了
    * *avoir froid* —— 冷
    * *avoir chaud* —— 热
    * *avoir ... ans* —— ......岁
    * *avoir besoin de* —— 需要

**第一组动词（Premier groupe：-er）**

规则变位：以 *-er* 结尾的动词（约占法语动词的90%）。去掉词尾 *-er*，分别加 *-e*, *-es*, *-e*, *-ons*, *-ez*, *-ent*。

| **人称** | **词尾** | **例：*parler*（说）** | **中文** |
|----------|----------|-----------------------|----------|
| *je* | *-e* | *je parle* | 我说 |
| *tu* | *-es* | *tu parles* | 你说 |
| *il / elle / on* | *-e* | *il parle* | 他/她说 |
| *nous* | *-ons* | *nous parlons* | 我们说 |
| *vous* | *-ez* | *vous parlez* | 您/你们说 |
| *ils / elles* | *-ent* | *ils parlent* | 他们/她们说 |

注意：*je*, *tu*, *il/elle* 和 *ils/elles* 的发音相同（*parle/parles/parlent* 都读 [paʁl]），只有 *nous* 和 *vous* 的发音不同。

**4种特殊拼写变化（非常重要！）**

* ***-ger* 结尾**：在 *nous* 形式中保留 *g* 的软音，加 *e*
  *manger*（吃）→ *nous mangeons*（不是 *mangons*）

* ***-cer* 结尾**：在 *nous* 形式中，*c* → *ç* 保持软音
  *commencer*（开始）→ *nous commençons*

* ***-ayer / -oyer / -uyer* 结尾**：单数形式 *y* 变成 *i*（可选的）
  *payer*（付钱）→ *je paye* 或 *je paie*（两种均可）
  *nettoyer*（清洁）→ *je nettoie*（*y* 必变 *i*）

* ***é + 辅音 + -er* 结尾**：重音在倒数第二音节时 *é* → *è*
  *préférer*（更喜欢）→ *je préfère*（*é* → *è*）
  但 *nous* 和 *vous* 形式中 *é* 不变：*nous préférons*

* ***-eler / -eter* 结尾**：单数形式双写辅音（部分动词）
  *appeler*（叫）→ *j'appelle*（双写 *l*）
  *jeter*（扔）→ *je jette*（双写 *t*）

**第二组动词（Deuxième groupe：-ir）**

第二组动词以 *-ir* 结尾，复数人称有 *-iss-* 插入。判断一个 *-ir* 动词是否为第二组：看其现在分词是否以 *-issant* 结尾。

**例：*finir*（完成）**

| **人称** | **变位** | **词尾** | **中文** |
|----------|----------|----------|----------|
| *je* | *finis* | *-is* | 我完成 |
| *tu* | *finis* | *-is* | 你完成 |
| *il / elle / on* | *finit* | *-it* | 他/她完成 |
| *nous* | *finissons* | *-issons* | 我们完成 |
| *vous* | *finissez* | *-issez* | 您/你们完成 |
| *ils / elles* | *finissent* | *-issent* | 他们/她们完成 |

**特征：** 现在分词以 *-issant* 结尾（*finissant*）。

**其他常见第二组动词：** *choisir*（选择）、*réussir*（成功）、*grandir*（长大）、*grossir*（变胖）、*maigrir*（变瘦）、*obéir*（服从）、*réagir*（反应）

**第三组不规则动词（Troisième groupe）**

***aller*（去）—— 完全不规则**

| **人称** | **变位** | **中文** |
|----------|----------|----------|
| *je* | *vais* | 我去 |
| *tu* | *vas* | 你去 |
| *il / elle / on* | *va* | 他/她去 |
| *nous* | *allons* | 我们去 |
| *vous* | *allez* | 您/你们去 |
| *ils / elles* | *vont* | 他们/她们去 |

用法：*aller* 除了表示「去」，还用来构成**最近将来时**（*futur proche*）。

***venir*（来）**

| **人称** | **变位** | **中文** |
|----------|----------|----------|
| *je* | *viens* | 我来 |
| *tu* | *viens* | 你来 |
| *il / elle / on* | *vient* | 他/她来 |
| *nous* | *venons* | 我们来 |
| *vous* | *venez* | 您/你们来 |
| *ils / elles* | *viennent* | 他们/她们来 |

**同模式动词：** *devenir*（变成）、*revenir*（回来）

用法：*venir de +* 不定式构成**最近过去时**（*passé récent*）。

***dormir*（睡觉）**

| **人称** | **变位** | **中文** |
|----------|----------|----------|
| *je* | *dors* | 我睡觉 |
| *tu* | *dors* | 你睡觉 |
| *il / elle / on* | *dort* | 他/她睡觉 |
| *nous* | *dormons* | 我们睡觉 |
| *vous* | *dormez* | 您/你们睡觉 |
| *ils / elles* | *dorment* | 他们/她们睡觉 |

**同模式动词：** *servir*（服务）、*partir*（离开）、*sortir*（出去）

注意：*venir* 和 *dormir* 类动词的 *je/tu/il* 形式都去掉词尾的结尾辅音字母。

***ouvrir*（打开）—— 特殊：按第一组变位！**

| **人称** | **变位** | **中文** |
|----------|----------|----------|
| *j'* | *ouvre* | 我打开 |
| *tu* | *ouvres* | 你打开 |
| *il / elle / on* | *ouvre* | 他/她打开 |
| *nous* | *ouvrons* | 我们打开 |
| *vous* | *ouvrez* | 您/你们打开 |
| *ils / elles* | *ouvrent* | 他们/她们打开 |

注意：*ouvrir* 虽属第三组，但变位方式与第一组 *-er* 动词完全一样！**同模式：** *couvrir*（覆盖）、*découvrir*（发现）、*souffrir*（忍受）

**代词式动词（Verbes pronominaux）**

代动词是法语中一类特殊的动词，前面必须加一个**自反代词**（*me, te, se, nous, vous, se*）。代动词的变位分两步：先变自反代词，再变动词本身。

**例：*se coucher*（躺下 / 睡觉）**

| **人称** | **自反代词** | **动词变位** | **中文** |
|----------|-------------|-------------|----------|
| *je* | *me* | *couche* | 我躺下 |
| *tu* | *te* | *couches* | 你躺下 |
| *il / elle / on* | *se* | *couche* | 他/她躺下 |
| *nous* | *nous* | *couchons* | 我们躺下 |
| *vous* | *vous* | *couchez* | 您/你们躺下 |
| *ils / elles* | *se* | *couchent* | 他们/她们躺下 |

**例：*se lever*（起床）—— 注意 *é* → *è* 拼写变化**

| **人称** | **自反代词** | **动词变位** | **中文** |
|----------|-------------|-------------|----------|
| *je* | *me* | *lève* | 我起床 |
| *tu* | *te* | *lèves* | 你起床 |
| *il / elle / on* | *se* | *lève* | 他/她起床 |
| *nous* | *nous* | *levons* | 我们起床 |
| *vous* | *vous* | *levez* | 您/你们起床 |
| *ils / elles* | *se* | *lèvent* | 他们/她们起床 |

**其他常见代动词：** *se réveiller*（醒来）、*s'habiller*（穿衣）、*se promener*（散步）、*se laver*（洗澡/洗手）、*s'appeler*（名叫）

**命令式（Impératif）**

命令式用于发出命令、提出请求或给出建议。它只有三个人称：*tu*, *nous*, *vous*。命令式的变位与现在时相同，但去掉主语代词。

**三种人称的命令式**

| **人称** | **肯定命令** | **否定命令** | **中文** |
|----------|-------------|-------------|----------|
| *tu* | *Parle* ! | *Ne parle pas* ! | 说话！/ 别说话！ |
| *nous* | *Parlons* ! | *Ne parlons pas* ! | 让我们说吧！/ 别说了！ |
| *vous* | *Parlez* ! | *Ne parlez pas* ! | 请说！/ 请别说！ |

!!! warning "第一组 *-er* 动词 *tu* 命令式的特殊规则"

    第一组 *-er* 动词的 *tu* 命令式去掉词尾 *-s*：
    *Parle* !（不是 *Parles* !）、*Mange* !（不是 *Manges* !）
    但遇到 *en* 或 *y* 时 *-s* 要恢复：*Manges-en* !（吃点吧！）

**动词 *être* 和 *avoir* 的命令式（特殊形式）：**

* *être* ：*sois / soyons / soyez*
* *avoir* ：*aie / ayons / ayez*

**代动词的命令式（特殊规则）：**

* **肯定命令**：自反代词 *te* → *toi*（放在动词后，用连字符）
  *Lève-toi* !（起床！）—— 不是 *Lève-te* !
* **否定命令**：自反代词位置不变（在 *ne* 和动词之间）
  *Ne te lève pas* !（别起床！）

**更多例子：**

* *Assieds-toi* !（坐下！）/ *Ne t'assieds pas* !（别坐下！）
* *Levez-vous* !（请起立！）/ *Ne vous levez pas* !（请别起立！）

**最近将来时（Futur proche）**

最近将来时表示「即将发生」或「将要去做」的事情，相当于中文的「将要/打算做」。这是法语中最常用的将来表达方式。

**结构公式：** *aller*（现在时）+ 不定式

| **主语** | **最近将来时** | **中文** |
|----------|---------------|----------|
| *je* | *je vais manger* | 我将要吃 |
| *tu* | *tu vas manger* | 你将要吃 |
| *il / elle / on* | *il va manger* | 他/她将要吃 |
| *nous* | *nous allons manger* | 我们将要吃 |
| *vous* | *vous allez manger* | 您/你们将要吃 |
| *ils / elles* | *ils vont manger* | 他们/她们将要吃 |

**例句：**

* *Je vais étudier ce soir.*（我今晚将要学习。）
* *Il va pleuvoir.*（天要下雨了。）
* *Nous allons partir en vacances.*（我们将要去度假。）

**复合过去时（Passé composé）**

复合过去时是法语中最常用的过去时态，用于表达已经完成的动作。它是「复合」时态，由**助动词**（*avoir* 或 *être*）+ **过去分词**两部分构成。

**结构公式：** 助动词（*avoir/être* 现在时）+ 过去分词

**用 *avoir* 作助动词的情况：**

大部分动词使用 *avoir* 作助动词。此时过去分词不变（无性数配合）。

| **主语** | **复合过去时** | **中文** |
|----------|---------------|----------|
| *j'* | *ai mangé* | 我吃了 |
| *tu* | *as fini* | 你完成了 |
| *il / elle / on* | *a attendu* | 他/她等了 |
| *nous* | *avons vu* | 我们看见了 |
| *vous* | *avez pris* | 您/你们拿了 |
| *ils / elles* | *ont parlé* | 他们/她们说了 |

**用 *être* 作助动词的情况：**

以下两类动词必须用 *être* 作助动词：

* **所有代动词（*verbes pronominaux*）**
  *Je me suis levé.*（我起床了。）
  *Elle s'est habillée.*（她穿好衣服了。）

* **16个表示移动/状态变化的动词（核心列表）：**

| **动词** | **中文** | **复合过去时（*je*）** |
|----------|----------|------------------------|
| *aller* | 去 | *je suis allé(e)* |
| *venir* | 来 | *je suis venu(e)* |
| *arriver* | 到达 | *je suis arrivé(e)* |
| *partir* | 离开 | *je suis parti(e)* |
| *entrer* | 进入 | *je suis entré(e)* |
| *sortir* | 出去 | *je suis sorti(e)* |
| *naître* | 出生 | *je suis né(e)* |
| *mourir* | 死亡 | *je suis mort(e)* |
| *rester* | 留下 | *je suis resté(e)* |
| *retourner* | 返回 | *je suis retourné(e)* |
| *monter* | 登上 | *je suis monté(e)* |
| *descendre* | 下来 | *je suis descendu(e)* |
| *tomber* | 跌倒 | *je suis tombé(e)* |
| *passer* | 经过 | *je suis passé(e)* |
| *devenir* | 变成 | *je suis devenu(e)* |
| *revenir* | 回来 | *je suis revenu(e)* |

!!! warning "DR & MRS VANDERTRAMP 记忆口诀"

    *Devenir, Revenir, &*（和）*Monter, Rester, Sortir, Venir, Aller, Naître, Descendre, Entrer, Rentrer, Tomber, Retourner, Arriver, Mourir, Partir, Passer*

**过去分词的性数配合规则：**

使用 *être* 作助动词时，过去分词必须与主语进行**性数配合**：

* 阳性单数：*Il est allé.*（他去了。）
* 阴性单数：*Elle est allée.*（她去了。）
* 阳性复数：*Ils sont partis.*（他们出发了。）
* 阴性复数：*Elles sont arrivées.*（她们到达了。）
* 代动词：*Nous nous sommes levés.*（我们起床了。）

**过去分词构成规则：**

| 第三组（不规则） | 多种形式 | 见下方不规则动词表 |

**不规则过去分词完整列表（25个核心动词）：**

**最近过去时（Passé récent）**

最近过去时表示「刚刚发生」的动作，强调与现在的紧密关联。

**结构公式：** *venir*（现在时）+ *de* + 不定式

| **主语** | **最近过去时** | **中文** |
|----------|---------------|----------|
| *je* | *je viens de manger* | 我刚刚吃了 |
| *tu* | *tu viens de manger* | 你刚刚吃了 |
| *il / elle / on* | *il vient de manger* | 他/她刚刚吃了 |
| *nous* | *nous venons de manger* | 我们刚刚吃了 |
| *vous* | *vous venez de manger* | 您/你们刚刚吃了 |
| *ils / elles* | *ils viennent de manger* | 他们/她们刚刚吃了 |

**例句：**

* *Je viens de finir mes devoirs.*（我刚刚做完作业。）
* *Il vient de partir.*（他刚刚离开。）
* *Nous venons d'arriver.*（我们刚刚到达。——注意 *de* 省音为 *d'*）

**三个「时态」对比总结**

| **时态** | **中文** | **结构** | **例句** |

| 最近过去时 | 刚刚 | *venir de* + 不定式 | *Je viens de manger.* 我刚吃 |
| 复合过去时 | 已经/过去 | 助动词+过去分词 | *J'ai mangé.* 我吃了 |

## 十、Prépositions（介词）

**国家/城市前置词**

法语中在表示「去某地」或「在某地」时，国家名称的阴阳性决定了使用哪个介词。这是一个非常重要的规则，考试中经常出现。

| **地点类型** | **介词** | **例句** | **中文** |
|-------------|----------|----------|----------|
| 城市 | *à* | *Je vais à Paris.* | 我去巴黎。 |
| 阳性国家 | *au* | *Je vais au Canada.* | 我去加拿大。 |
| 阴性国家 | *en* | *Je vais en France.* | 我去法国。 |
| 元音开头的国家 | *en* | *Je vais en Italie.* | 我去意大利。 |
| 复数国家 | *aux* | *Je vais aux États-Unis.* | 我去美国。 |

**快速判断方法：**

* 城市名 → *à*（*à Beijing*, *à Tokyo*）
* 以 *-e* 结尾的国家大多数是阴性 → *en*（*en France*, *en Chine*）
* 不以 *-e* 结尾的国家大多数是阳性 → *au*（*au Canada*, *au Japon*）
* 例外：*le Mexique*（墨西哥）、*le Cambodge*（柬埔寨）虽以 *-e* 结尾但为阳性
* 元音开头的国家不管阴阳性都用 *en*（*en Iran*, *en Irak*）

**常用地点介词（Prépositions de lieu courantes）**

| **介词** | **中文** | **例句** |
|----------|----------|----------|
| *à côté de* | 在......旁边 | *Le musée est à côté de l'église.*（博物馆在教堂旁边。） |
| *loin de* | 远离 | *J'habite loin de l'école.*（我住得离学校远。） |
| *près de* | 靠近 | *Il y a un parc près de chez moi.*（我家附近有个公园。） |
| *devant* | 在......前面 | *La voiture est devant la maison.*（车在房子前面。） |
| *derrière* | 在......后面 | *Le jardin est derrière la maison.*（花园在房子后面。） |
| *sur* | 在......上面 | *Le livre est sur la table.*（书在桌子上。） |
| *sous* | 在......下面 | *Le chat est sous la table.*（猫在桌子下面。） |
| *dans* | 在......里面 | *Les clés sont dans le sac.*（钥匙在包里。） |
| *entre* | 在......之间 | *Le café est entre la banque et l'hôtel.*（咖啡馆在银行和酒店之间。） |
| *en face de* | 在......对面 | *Le cinéma est en face de la gare.*（电影院在火车站对面。） |

**时间介词（Prépositions de temps）**

| **介词/结构** | **用法说明** | **例句** |
|--------------|-------------|----------|
| *en* | 年/季节/月份（没有具体日期） | *en 2024, en hiver, en janvier* |
| *dans* | 一段时间之后（未来） | *dans trois jours*（三天后） |
| *à* | 具体时间点 | *à 8 heures, à midi, à minuit* |
| *le* | 星期几/具体日期 | *le lundi, le 10 mai* |
| *de ... à* | 从......到...... | *du lundi au vendredi*（从周一到周五） |
| *pendant* | 某事持续的时间段 | *pendant les vacances*（假期间） |
| *il y a* | 一段时间之前（过去） | *il y a une heure*（一小时前） |
| *depuis* | 从过去某时开始持续至今 | *je l'attends depuis 10 minutes*（我等了10分钟了） |

!!! warning "时间表达中的易混淆点"

    * *il y a* + 时间段 = 「......之前」（*il y a deux ans* = 两年前）
    * *depuis* + 时间段 = 「自从......以来」（一直持续到现在）
    * *dans* + 时间段 = 「......之后」（*dans deux jours* = 两天后）
    * *en* + 时间段 = 「在......之内」（*en une heure* = 一小时内完成）

**频率副词（Adverbes de fréquence）**

| **法语** | **中文** |
|----------|----------|
| *toujours* | 总是（100%） |
| *souvent* | 经常（约80%） |
| *parfois / quelquefois* | 有时（约50%） |
| *rarement* | 很少（约20%） |
| *ne ... jamais* | 从不（0%） |
| *tous les jours* | 每天 |
| *toutes les semaines* | 每周 |
| *tous les mois* | 每月 |
| *tous les ans* | 每年 |

**例句：**

* *Je vais souvent au cinéma.*（我经常去看电影。）
* *Il ne fume **jamais**.*（他从不抽烟。）
* *Nous mangeons parfois au restaurant.*（我们有时在餐馆吃。）
* *Je fais du sport tous les jours.*（我每天做运动。）
