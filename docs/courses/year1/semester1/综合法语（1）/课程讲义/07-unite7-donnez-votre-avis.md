## Leçon 24 : Santé et conseils（健康与建议）

### Impératif（命令式完整变位表）

| 人称 | *Parler* 肯定 | *Parler* 否定 |
|:---:|:---:|:---:|
| **tu** | *Parle !* | *Ne parle pas !* |
| **nous** | *Parlons !* | *Ne parlons pas !* |
| **vous** | *Parlez !* | *Ne parlez pas !* |

!!! warning "-er 动词 tu 命令式去掉词尾 -s。例外：*aller* → *Va !*"

### Impératif des verbes pronominaux（代词动词命令式——核心难点）

**肯定形式：** 动词 + 连字符 + 代词（*te* → *toi*）
**否定形式：** *Ne* + 代词 + 动词 + *pas*

**四条规则：**

1. 肯定命令式中，代词置于动词后，用连字符连接
2. *te* 变为重读形式 *toi*
3. 否定命令式中，代词置于 *ne* 和动词之间
4. 否定命令式用正常语序，不加连字符

**练习：肯定 ↔ 否定转换**

| 肯定 | 否定 |
|:---|:---|
| *Asseyez-vous !* | *Ne vous asseyez pas !* |
| *Arrêtez-vous !* | *Ne vous arrêtez pas !* |
| *Commence !* | *Ne commence pas !* |
| *Attendez-moi !* | *Ne m'attendez pas !* |
| *Prends-le !* | *Ne le prends pas !* |
| *Dites-moi !* | *Ne me dites pas !* |
| *Invite-la !* | *Ne l'invite pas !* |
| *Remerciez-moi !* | *Ne me remerciez pas !* |

### Quatre structures de conseil（四种建议句型）

按强度从强到弱排序：

| 强度 | 结构 | 例句 | 中文 |
|:---:|:---|:---|:---|
| 1 | **Impératif** | *Repose-toi !* | 休息吧！ |
| 2 | ***Il faut** + inf.* | *Il faut manger équilibré.* | 必须均衡饮食。 |
| 3 | ***Devoir** + inf.* | *Tu dois boire de l'eau.* | 你应该喝水。 |
| 4 | ***Pouvoir** + inf.* | *Tu peux faire du sport.* | 你可以做运动。 |

!!! warning "语义区分：*Il faut* = 客观必须 / *Devoir* = 主观义务 / *Pouvoir* = 委婉建议"

**补充例句：**

- *Il faut consulter un médecin.*（必须看医生。）
- *Tu devrais te reposer.*（你应该休息一下。）
- *Vous pouvez prendre ce médicament.*（您可以吃这个药。）

### Depuis（持续至今）

与 **现在时** 连用，表示从过去某时开始并持续到现在的动作。

- *J'habite à Paris **depuis** 2018.*（我从 2018 年起住在巴黎。）
- *Il étudie le français **depuis** deux ans.*（他学法语两年了。）

**结构：** *Depuis* + 时间段 + 现在时

### Il y a vs Depuis（对比表）

| 结构 | 时态 | 含义 |
|:---|:---|:---|
| ***Il y a*** + 时间段 | 复合过去时 | 动作已结束（多久以前） |
| ***Depuis*** + 时间段 | 现在时 | 动作持续至今 |

**核心区别：** *Il y a* 强调动作发生的过去时间点（已结束），*Depuis* 强调动作从过去延续到现在（仍在持续）。

## Leçon 25 : Projets et futur（项目与将来）

### Pour + infinitif（目的）

表示做某事的目的，意为"为了……"。

- *Je vais à la pharmacie **pour acheter** des médicaments.*（我去药店买药。）
- *Il économise **pour voyager** au Japon.*（他存钱为了去日本旅行。）
- *Nous faisons du sport **pour rester** en forme.*（我们做运动为了保持健康。）

### Pourquoi / Parce que（原因）

| 问句 | 回答 |
|:---|:---|
| ***Pourquoi** tu vas chez le médecin ?* | ***Parce que** j'ai de la fièvre.* |
| （你为什么去看医生？） | （因为我发烧了。） |
| ***Pourquoi** elle étudie le français ?* | ***Parce qu'**elle veut travailler en France.* |
| （她为什么学法语？） | （因为她想在法国工作。） |

- ***Pourquoi** est-ce que tu apprends le chinois ? — **Parce que** j'adore la culture chinoise.*（你为什么学中文？——因为我热爱中国文化。）
- ***Pourquoi** il ne vient pas ? — **Parce qu'**il est malade.*（他为什么不来？——因为他生病了。）

### Futur proche pronominal（最近将来时代词动词）

**结构：** *aller*（变位）+ 代词 + *infinitif*

以 *s'inscrire*（注册）为例：

| 人称 | 变位 |
|:---:|:---|
| **je** | *vais **m'** inscrire* |
| **tu** | *vas **t'** inscrire* |
| **il / elle / on** | *va **s'** inscrire* |
| **nous** | *allons **nous** inscrire* |
| **vous** | *allez **vous** inscrire* |
| **ils / elles** | *vont **s'** inscrire* |

!!! warning "代词放在 *aller* 和不定式之间，即：*aller*（变位）+ 自反代词 + *infinitif*"

**例句：**

- *Je **vais me reposer** après le travail.*（我下班后要休息。）
- *Nous **allons nous promener** dans le parc.*（我们要去公园散步。）
- *Ils **vont s'installer** à Lyon.*（他们将要定居里昂。）

### Dans + 时间段（将来）

表示"在……之后"，与将来时连用。

- *dans trois jours*（三天后）
- *dans une semaine*（一周后）
- *dans un mois*（一个月后）

**例句：**

- *Je partirai **dans** une semaine.*（我将在一周后出发。）
- *Il arrivera **dans** trois jours.*（他将在三天后到达。）

### Ne...rien（什么都不）

**结构：** *ne* + 动词 + *rien*

- *Je **ne** mange **rien**.*（我什么都不吃。）
- *Il **ne** dit **rien**.*（他什么也不说。）
- *Nous **ne** faisons **rien**.*（我们什么都不做。）

**复合时态结构：** *ne* + 助动词 + *rien* + 过去分词

- *Je **n'** ai **rien** mangé.*（我什么都没吃。）
- *Elle **n'** a **rien** dit.*（她什么也没说。）

## Texte : Mon voyage au Japon（我的日本之旅）

**法汉对照全文：**

*L'été dernier, je suis allé(e) au Japon avec ma famille.*
去年夏天，我和家人去了日本。

*Nous avons visité Tokyo, Kyoto et Osaka.*
我们参观了东京、京都和大阪。

*Nous avons pris le train à grande vitesse Shinkansen.*
我们乘坐了新干线高速列车。

*Je me suis réveillé(e) très tôt chaque jour pour profiter du voyage.*
我每天起得很早来享受这次旅行。

**动词复合过去时分析表：**

| 动词 | 助动词 | 过去分词 | 配合 | 中文 |
|:---|:---:|:---:|:---:|:---|
| *aller* | *être* | *allé(e)* | 有 | 去 |
| *visiter* | *avoir* | *visité* | 无 | 参观 |
| *prendre* | *avoir* | *pris* | 无 | 乘坐 |
| *se réveiller* | *être* | *réveillé(e)* | 有 | 醒来 |
| *arriver* | *être* | *arrivé(e)* | 有 | 到达 |
| *manger* | *avoir* | *mangé* | 无 | 吃 |
| *voir* | *avoir* | *vu* | 无 | 看见 |
| *faire* | *avoir* | *fait* | 无 | 做 |
| *dire* | *avoir* | *dit* | 无 | 说 |
| *partir* | *être* | *parti(e)* | 有 | 离开 |
| *revenir* | *être* | *revenu(e)* | 有 | 回来 |
| *dormir* | *avoir* | *dormi* | 无 | 睡觉 |
| *acheter* | *avoir* | *acheté* | 无 | 买 |
| *pouvoir* | *avoir* | *pu* | 无 | 能够 |
| *vouloir* | *avoir* | *voulu* | 无 | 想要 |

**语法要点总结：**

- ***avoir* 助动词**：过去分词不需要与主语配合
- ***être* 助动词**：过去分词需要与主语配合（性数一致）
- **代词动词**：永远用 *être* 作助动词，过去分词需与前置代词配合

## Leçon 26 : Temps du passé（过去时态）

### En + année / mois（时间定位）

表示"在……年/月"。

- ***En** 2020, j'ai commencé l'université.*（2020 年，我开始上大学。）
- ***En** janvier, il a voyagé en France.*（一月，他去法国旅行了。）
- ***En** été, nous sommes allés à la plage.*（夏天，我们去了海滩。）

**en / au / à 区别表：**

| 介词 | 用法 | 示例 |
|:---|:---|:---|
| ***en*** | 年份、月份、季节（阴性国名） | *en 2024, en mai, en été, en France* |
| ***au*** | 阳性国名 | *au Japon, au Canada* |
| ***à*** | 城市 | *à Paris, à Tokyo* |

### Imparfait d'évaluation（未完成过去时评价）

用未完成过去时对经历过的某事进行主观评价，句型：***C'était** + adj.*

- ***C'était magique !***（太神奇了！）
- ***C'était délicieux !***（太美味了！）
- ***C'était magnifique !***（太壮观了！）
- ***C'était incroyable !***（太不可思议了！）

**句型：** *C'était* + 形容词

### Passé composé pronominal négatif（代词动词复合过去时否定）

**结构：** *ne* + 代词 + *être*（变位）+ *pas* + 过去分词

| 肯定 | 否定 |
|:---|:---|
| *Je me suis levé(e).* | *Je **ne** me **suis pas** levé(e).* |
| *Tu t'es reposé(e).* | *Tu **ne** t'**es pas** reposé(e).* |
| *Il s'est installé.* | *Il **ne** s'**est pas** installé.* |
| *Nous nous sommes promené(e)s.* | *Nous **ne** nous **sommes pas** promené(e)s.* |
| *Vous vous êtes préparé(e)(s).* | *Vous **ne** vous **êtes pas** préparé(e)(s).* |
| *Ils se sont réveillés.* | *Ils **ne** se **sont pas** réveillés.* |

**例句：**

- *Je **ne** me **suis pas** réveillé(e) tôt.*（我没有早起。）
- *Elle **ne** s'**est pas** installée à Paris.*（她没有在巴黎定居。）
- *Ils **ne** se **sont pas** promenés.*（他们没有散步。）

**肯定 / 否定对比：**

| 肯定 | 否定 |
|:---|:---|
| *Je me suis levé(e).* | *Je ne me suis pas levé(e).* |
| *Nous nous sommes reposé(e)s.* | *Nous ne nous sommes pas reposé(e)s.* |
| *Ils se sont installés.* | *Ils ne se sont pas installés.* |

| *J'ai visité Tokyo et Kyoto.* | *avoir* 助动词，无配合 | 我参观了东京和京都。 |
| *J'ai pris le Shinkansen.* | *prendre* 的不规则过去分词 *pris* | 我乘坐了新干线。 |
| *Je me suis réveillé(e) tôt.* | 代词动词，*être* 助动词，配合 | 我醒得很早。 |
| *C'était magnifique !* | 未完成过去时评价 | 太壮观了！ |
| *Nous avons mangé des sushis.* | *avoir* 助动词 | 我们吃了寿司。 |
| *Nous avons vu le mont Fuji.* | *voir* → *vu* | 我们看到了富士山。 |
| *Je me suis promené(e) dans les temples.* | 代词动词，配合 | 我在寺庙里散步。 |
| *Nous sommes restés trois jours à Osaka.* | *être* 助动词，配合 | 我们在大阪待了三天。 |
| *Ce voyage était incroyable !* | *C'était +* 形容词评价 | 这次旅行太不可思议了！ |

### 7. Donner une appréciation（评价）

| 法语 | 中文 |
|:---|:---|
| *C'était magnifique !* | 太壮观了！ |
| *J'ai trouvé ça passionnant.* | 我觉得这很激动人心。 |
| *C'est vraiment intéressant.* | 这真的很有趣。 |
| *C'était délicieux.* | 很美味。 |
| *C'était incroyable.* | 太不可思议了。 |
| *C'était génial.* | 棒极了。 |

## Carte mentale（语法思维导图）

```
                        ┌─ Impératif（命令式）
                        ├─ Il faut + inf.（客观必须）
        Conseils（建议）─┼─ Devoir + inf.（主观义务）
                        ├─ Pouvoir + inf.（委婉建议）
                        └─ 代词动词命令式

                        ├─ Depuis + 现在时（持续至今）
        Temps（时间）────┼─ Dans + 将来时（……之后）
                        ├─ En + 过去/年份（时间定位）
                        └─ Il y a + 复合过去时（多久以前）

        But / Cause──────┼─ Pour + inf.（目的）
                        └─ Pourquoi / Parce que（原因）

        Futur proche──────┴─ 代词动词：aller + 代词 + inf.

                          ├─ 肯定：être 助动词 + 过去分词配合
        Passé composé─────┼─ 否定：ne + 代词 + être + pas + 过去分词
        （代词动词）       └─ 代词永远用 être

        Imparfait──────────┴─ 评价：C'était + adj.

        Négation──────────┴─ Ne...rien（复合时态：ne + 助动词 + rien + 过去分词）
```
