## Leçon 20 : Cuisine et recettes（烹饪与食谱）

**Quantité（数量表达）**

法语中使用不同的量词来表达数量多少，其基本结构为：量词 + *de* + 名词（不加冠词）。

| 表达 | 含义 | 例句 1 | 例句 2 |
|------|------|--------|--------|
| *pas de* | 没有（零数量） | *Je ne mange pas de viande.*（我不吃肉。） | *Il n'y a pas de sucre.*（没有糖。） |
| *un peu de* | 少量 | *Ajoute un peu de sel.*（加一点点盐。） | *Je veux un peu d'eau.*（我想要一点水。） |
| *beaucoup de* | 大量 | *Il met beaucoup de fromage.*（他放了很多奶酪。） | *Nous avons beaucoup d'amis.*（我们有很多朋友。） |
| *un kilo de* | 一公斤 | *Achète un kilo de pommes.*（买一公斤苹果。） | *Il faut un kilo de farine.*（需要一公斤面粉。） |

!!! tip "注意：*un peu de* 与 *pas de* 含义不同"
    *un peu de* 表示"少量"，是肯定意义；*pas de* 表示"没有"，是否定意义。两者后面都直接跟名词，不加冠词。

更多例子：

- *une bouteille de lait*（一瓶牛奶）
- *une tasse de thé*（一杯茶）
- *une tranche de pain*（一片面包）

---

**Infinitif pour les食谱（食谱中的不定式）**

在食谱说明中，可以使用动词不定式来替代命令式，表达更加客观简洁。

**肯定形式：** 直接使用动词原形开头。

| 例子 | 中文 |
|------|------|
| *Couper les légumes.* | 切蔬菜。 |
| *Ajouter le sel et le poivre.* | 加盐和胡椒。 |
| *Mélanger les ingrédients.* | 混合所有食材。 |
| *Chauffer le four à 180°C.* | 将烤箱预热至180°C。 |
| *Servir chaud.* | 趁热享用。 |

**否定形式：** *Ne pas* + 动词原形。

| 例子 | 中文 |
|------|------|
| *Ne pas ajouter trop de sel.* | 不要加太多盐。 |
| *Ne pas faire cuire trop longtemps.* | 不要煮太久。 |
| *Ne pas ouvrir le four.* | 不要打开烤箱。 |
| *Ne pas mélanger trop fort.* | 不要搅拌太用力。 |

!!! tip "为什么用不定式？"
    食谱中使用不定式比命令式更加客观、简洁，是一种中性表达方式，广泛应用于书面食谱和说明书中。

**Manger（吃）动词变位**

| 人称 | 变位 | 中文 |
|------|------|------|
| *je* | *mange* | 我吃 |
| *tu* | *manges* | 你吃 |
| *il / elle / on* | *mange* | 他/她/我们吃 |
| *nous* | *mangeons* | 我们吃 |
| *vous* | *mangez* | 你们/您吃 |
| *ils / elles* | *mangent* | 他们/她们吃 |

!!! warning "重点：*nous mangeons* 保留字母 *e*"
    以 *-ger* 结尾的动词，在 *nous* 变位时需要保留字母 *e*，以维持 /ʒ/（软腭擦音）的发音。如果不加 *e*，*mangons* 会被读作 /g/ 音。
    
    同类常见动词：
    - *nager*（游泳）：*nous nageons*
    - *voyager*（旅行）：*nous voyageons*
    - *changer*（改变）：*nous changeons*
    - *partager*（分享）：*nous partageons*

## Leçon 22 : Passé Composé avec être（复合过去时——用 *être* 作助动词）

**课文背景：电影院惊喜求婚**

Antoine 策划了一场特别的求婚——在电影院里，当影片结束、灯光亮起时，屏幕上突然出现了他对 Julie 的深情告白。Julie 惊喜万分，感动落泪，在全场观众的掌声中，Antoine 单膝跪地，拿出了戒指。

- *Antoine a préparé une surprise pour Julie.*（Antoine 为 Julie 准备了一个惊喜。）
- *Il est allé au cinéma avec elle.*（他带她去了电影院。）
- *La lumière s'est allumée après le film.*（电影结束后灯光亮起。）
- *Il est tombé à genoux.*（他单膝跪地。）
- *Elle est devenue très émue.*（她变得非常感动。）
- *Ils sont sortis du cinéma ensemble.*（他们一起走出了电影院。）
- *Elle a dit "oui" devant tout le monde.*（她在所有人面前说了"oui"。）
- *Ils sont retournés chez eux heureux.*（他们幸福地回了家。）

---

**Qu'est-ce que le passé composé ?（什么是复合过去时？）**

复合过去时（*passé composé*）用于表达**过去已经完成**的动作或事件。它的构成是：

**助动词（*avoir* 或 *être*）的现在时变位 + 动词的过去分词**

| 结构 | 示例 |
|------|------|
| *avoir / être*（现在时）+ *participe passé* | *J'ai mangé.* / *Je suis allé.* |

---

**14个用 *être* 作助动词的动词**

大多数动词用 *avoir* 作助动词，但以下表示**方向性移动**或**状态变化**的动词用 *être*：

| 动词原形 | 中文 | 过去分词 | 例句 |
|----------|------|----------|------|
| *arriver* | 到达 | *arrivé* | *Je suis arrivé à 8h.* |
| *partir* | 离开 | *parti* | *Il est parti tôt.* |
| *aller* | 去 | *allé* | *Elle est allée à Paris.* |
| *venir* | 来 | *venu* | *Nous sommes venus en taxi.* |
| *descendre* | 下来/下 | *descendu* | *Tu es descendu du train.* |
| *monter* | 上去/上 | *monté* | *Ils sont montés dans la chambre.* |
| *entrer* | 进入 | *entré* | *Vous êtes entrés par la porte.* |
| *sortir* | 出去 | *sorti* | *Elles sont sorties du magasin.* |
| *passer* | 经过/度过 | *passé* | *Je suis passé chez toi.* |
| *retourner* | 返回 | *retourné* | *Il est retourné en France.* |
| *tomber* | 掉落 | *tombé* | *Elle est tombée par terre.* |
| *devenir* | 变成 | *devenu* | *Il est devenu ingénieur.* |
| *naître* | 出生 | *né* | *Je suis né en 1995.* |
| *mourir* | 死亡 | *mort* | *Il est mort en 2010.* |

**注意：** *rester*（停留/留下）也用 *être* 作助动词：*Je suis resté à la maison.*

!!! tip "记忆口诀"
    用 *être* 作助动词的动词可以借助 **DR. & MRS. VANDERTRAMP** 来记忆：
    
    **D**evenir — **R**evenir — **&** — **M**onter — **R**ester — **R**etourner — **S**ortir —
    **V**enir — **A**ller — **N**aître — **D**escendre — **E**ntrer — **R**entrer —
    **T**omber — **R**etourner — **A**rriver — **M**ourir — **P**artir — **P**asser

---

!!! warning "核心规则：过去分词的性数配合"
    使用 *être* 作助动词时，**过去分词必须与主语的性数保持一致**！
    
    | 主语情况 | 变化规则 | 示例 |
    |----------|----------|------|
    | 阳性单数 | 不变（原形） | *Il est **parti.*** |
    | 阴性单数 | 加 *-e* | *Elle est **partie.*** |
    | 阳性复数 | 加 *-s* | *Ils sont **partis.*** |
    | 阴性复数 | 加 *-es* | *Elles sont **parties.*** |
    
    对照例句：
    
    - *Paul est **arrivé** à 8h.*（Paul 8点到了。）
    - *Marie est **arrivée** à 8h.*（Marie 8点到了。）
    - *Paul et Luc sont **arrivés** à 8h.*（Paul 和 Luc 8点到了。）
    - *Marie et Sophie sont **arrivées** à 8h.*（Marie 和 Sophie 8点到了。）

**Négation（否定形式）**

复合过去时的否定形式结构为：

**主语 + *ne / n'* + 助动词 + *pas* + 过去分词**

| 肯定句 | 否定句 |
|--------|--------|
| *J'ai mangé.* | *Je n'ai pas mangé.* |
| *Tu as vu le film.* | *Tu n'as pas vu le film.* |
| *Il est arrivé.* | *Il n'est pas arrivé.* |
| *Elle est partie.* | *Elle n'est pas partie.* |
| *Nous avons compris.* | *Nous n'avons pas compris.* |
| *Ils sont sortis.* | *Ils ne sont pas sortis.* |

**省音说明：** 当 *ne* 后面的助动词 (*avoir* / *être*) 以元音字母开头时，*ne* 缩写成 *n'*：
- *n'ai*（= *ne + ai*）
- *n'as*（= *ne + as*）
- *n'a*（= *ne + a*）
- *n'avons*（= *ne + avons*）
- *n'avez*（= *ne + avez*）
- *n'ont*（= *ne + ont*）
- *n'es*（= *ne + es*）
- *n'est*（= *ne + est*）
- *n'sommes*（= *ne + sommes*）
- *n'êtes*（= *ne + êtes*）
- *n'sont*（= *ne + sont*）

**Séquenceurs temporels（时间顺序词）**

**叙事四步顺序词：**

| 顺序词 | 中文 | 例句 |
|--------|------|------|
| *D'abord* | 首先 | *D'abord, nous sommes allés au cinéma.*（首先，我们去了电影院。） |

**完整叙事示例：**

（首先，他们到了电影院。然后，他们买了爆米花。接着，他们看了电影。最后，惊喜开始了。）

**Il y a + 时间段（……之前）**

*Il y a* 后面跟时间段，表示"……之前"，用于过去时间点：

| 例句 | 中文 |
|------|------|
| *Il y a cinq mois, il a préparé la surprise.* | 五个月前，他准备了惊喜。 |
| *Il y a une semaine, j'ai visité Paris.* | 一周前，我参观了巴黎。 |
| *Il y a deux ans, nous avons déménagé.* | 两年前，我们搬了家。 |
| *Il y a trois jours, elle est partie en voyage.* | 三天前，她出发去旅行了。 |

!!! tip "*Il y a* ≠ *depuis*"
    - *Il y a* + 时间段：表示"……之前"，用于**过去某个时间点**的动作。→ *Il y a deux ans, j'ai commencé le français.*（两年前，我开始学法语。）
    - *Depuis* + 时间段：表示"自从……以来"，用于**持续到现在的动作**。→ *J'apprends le français depuis deux ans.*（我学法语已经两年了。）

**完整叙事范例：**

以下是用复合过去时叙述电影院求婚事件的完整范例：

1. *Il y a cinq mois, Antoine a décidé de faire une surprise à Julie.*（五个月前，Antoine 决定给 Julie 一个惊喜。）
2. *D'abord, il a contacté le cinéma pour organiser la surprise.*（首先，他联系了电影院来安排惊喜。）
3. *Puis, il a préparé une vidéo avec leurs photos.*（然后，他准备了一段带有他们照片的视频。）
4. *Ensuite, il a invité Julie au cinéma sans lui dire la surprise.*（接着，他邀请了 Julie 去电影院，但没有告诉她惊喜。）
5. *Ils sont arrivés au cinéma à 19h.*（他们晚上7点到了电影院。）
6. *Ils ont regardé le film ensemble.*（他们一起看了电影。）
7. *Après le film, la lumière s'est allumée.*（电影结束后，灯亮了。）
8. *Soudain, la vidéo a commencé sur l'écran.*（突然，屏幕上开始播放视频。）
9. *Julie est devenue très émue.*（Julie 变得非常感动。）
10. *Antoine est tombé à genoux et a sorti la bague.*（Antoine 单膝跪地，拿出了戒指。）

**语法分析：**

- 用 *avoir* 作助动词：*a décidé, a contacté, a préparé, a invité, ont regardé, a commencé, a sorti*
- 用 *être* 作助动词：*sont arrivés*（复数配合 *-s*），*est devenue*（阴性配合 *-e*），*est tombé*（阳性单数不变）
- 时间顺序词：*D'abord, Puis, Ensuite, Après*
- 时间表达：*Il y a cinq mois*

## Leçon 23 : Critiques de restaurant（餐厅评论）

**Structure（餐厅评论五步结构）**

| 步骤 | 法语表达 | 中文 |
|------|----------|------|
| 1. 描述菜系 | *C'est un restaurant **français / italien / chinois / japonais**.* | 这是一家法/意/中/日餐厅。 |
| 2. 氛围和服务 | *L'ambiance est **chaleureuse / moderne / décontractée**.* | 氛围温馨/现代/轻松。 |
|  | *Le service est **rapide / lent / excellent**.* | 服务快捷/慢/优秀。 |
| 3. 你吃了什么 | *J'ai commandé **un steak / une salade / des pâtes**.* | 我点了牛排/沙拉/意面。 |
|  | *J'ai bu **un verre de vin rouge**.* | 我喝了一杯红酒。 |
| 4. 总体评价 | *Le plat était **délicieux / bon / trop salé**.* | 菜品美味/好/太咸。 |
|  | *Le rapport qualité-prix est **excellent / raisonnable / mauvais**.* | 性价比高/合理/差。 |
| 5. 推荐与否 | *Je **recommande / ne recommande pas** ce restaurant.* | 我推荐/不推荐这家餐厅。 |

**范文：**

*Le week-end dernier, je suis allé dans un restaurant italien près de chez moi. L'ambiance était très chaleureuse et le service était excellent. J'ai commandé une pizza et j'ai bu un verre de vin rouge. Le plat était délicieux ! Le rapport qualité-prix est raisonnable. Je recommande vivement ce restaurant à tous les amateurs de cuisine italienne.*

（上周末，我去了家附近的一家意大利餐厅。氛围非常温馨，服务也很棒。我点了一份披萨，喝了一杯红酒。菜品非常美味！性价比也很合理。我强烈推荐这家餐厅给所有意大利美食爱好者。）
