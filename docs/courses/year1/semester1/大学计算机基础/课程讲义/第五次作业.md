### 1. 输出n个连续偶数（10.00 分）

**【问题描述】**
编写一个 Python 程序，要求用户输入一个正整数 $n$，输出前 $n$ 个连续的偶数（从 0 开始）。

**【输入形式】**
一个正整数 $n$。

**【输出形式】**
前 $n$ 个连续偶数，中间用空格分隔。

**【样例输入】**

```
4
```

**【样例输出】**

```
0 2 4 6
```

**【评分标准】**
正确生成前 $n$ 个连续偶数。输出结果格式正确。

**参考答案（Python）：**

```python
n = int(input())
for i in range(n):
    print(i * 2, end=' ')
```

### 4. 辗转相除（10.00 分）

**【问题描述】**
给定两个正整数 $a$ 和 $b$，请编写一个Python程序并在适当位置加入注释，计算它们的最大公约数。使用辗转相除法进行计算。

**【输入形式】**
输入两个正整数 $a$ 和 $b$，中间用空格分隔。

**【输出形式】**
输出两个数的最大公约数。

**【样例输入】**

```
48 18
```

**【样例输出】**

```
最大公约数为: 6
```

**【样例说明】**
对于输入 48 18，计算过程为：

- $48 \div 18$ 余数为 12，将 18 和 12 继续代入；
- $18 \div 12$ 余数为 6，将 12 和 6 继续代入；
- $12 \div 6$ 余数为 0，此时最大公约数为 6。

**【评分标准】**
程序能够正确读取输入的两个正整数。程序能使用辗转相除法求出最大公约数。输出格式正确。

**参考答案（Python）：**

```python
a, b = map(int, input().strip().split())
if a < b:
    a, b = b, a
while b != 0:
    remainder = a % b
    a = b
    b = remainder
print(f"最大公约数为: {a}")
```

### 5. 三数运算器（10.00 分）

**【问题描述】**
模拟冯诺依曼体系的"运算器 + 存储器"工作过程：程序会存储 3 个浮点数到"存储器"（变量），然后根据用户输入的操作码，对这 3 个浮点数进行指定运算：

- 操作码为 1：计算三个数的和；
- 操作码为 2：计算三个数的平均值（保留 2 位小数）；
- 操作码为 3：找出三个数中的最大值；

用户需要先输入 3 个浮点数，再输入操作码（整数 1/2/3），程序输出对应运算结果。

**【输入形式】**
四行输入，前三行各输入一个浮点数（依次为 `num1`、`num2`、`num3`），第四行输入操作码（整数 1、2 或 3）

**【输出形式】**

- 若操作码为 1：输出 `Sum: 和`；
- 若操作码为 2：输出 `Average: 平均值`（保留 2 位小数）；
- 若操作码为 3：输出 `Max: 最大值`；

**【样例输入】**

```
1.5
2.7
3.9
1
```

**【样例输出】**

```
Sum: 8.1
```

**【样例说明】**
样例中，三个数求和 $1.5+2.7+3.9=8.1$。

**【评分标准】**
正确读取 3 个浮点数和操作码；操作码 1 的求和逻辑正确；操作码 2 的平均值计算（含保留 2 位小数）正确；操作码 3 的最大值查找正确；输出格式正确。

**参考答案（Python）：**

```python
num1 = float(input())
num2 = float(input())
num3 = float(input())
op_code = int(input())
if op_code == 1:
    res = num1 + num2 + num3
    print(f"Sum: {res}")
elif op_code == 2:
    avg = (num1 + num2 + num3) / 3
    print(f"Average: {avg:.2f}")
elif op_code == 3:
    max_num = max(num1, num2, num3)
    print(f"Max: {max_num}")
```
