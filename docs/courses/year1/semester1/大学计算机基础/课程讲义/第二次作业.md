### 1. 计算圆的面积（10.00 分）

**【问题描述】**
输入圆的半径 $r$，计算并输出圆的面积，保留两位小数（$\pi$ 取 3.14）。

**【输入形式】**
一行，一个浮点数 $r$

**【输出形式】**
一行，格式为：`圆的面积为: area`

**【样例输入】**

```
2
```

**【样例输出】**

```
圆的面积为: 12.56
```

**【样例说明】**
$area = 3.14 \times 2^2 = 12.56$

**【评分标准】**
正确读取圆的半径输入；正确使用公式计算面积；输出格式正确且结果保留两位小数。

**参考答案（Python）：**

```python
r = float(input())
pi = 3.14
area = pi * r * r
print("圆的面积为: {:.2f}".format(area))
```

### 2. 判断闰年（10.00 分）

**【问题描述】**
输入一个年份 year，判断该年是否为闰年。

闰年规则：能被4整除但不能被100整除，400除外（即能被400整除也是闰年）。

**【输入形式】**
一行，一个整数 year

**【输出形式】**
如果是闰年，输出一行 `"True"`，否则输出一行 `"False"`

**【样例输入】**

```
2000
```

**【样例输出】**

```
True
```

**【样例说明】**
2000 能被 400 整除，是闰年。

**【评分标准】**
正确读取年份输入；正确实现闰年判断逻辑；输出结果正确（`True` 或 `False`），格式规范。

**参考答案（Python）：**

```python
year = int(input().strip())
if year % 400 == 0:
    print("True")
elif year % 4 == 0 and year % 100 != 0:
    print("True")
else:
    print("False")
```

### 3. 计算矩形面积（10.00 分）

**【问题描述】**
输入矩形的长和宽，计算并输出矩形的面积，保留两位小数。

**【输入形式】**
两行，第一行为长，第二行为宽（两个浮点数）

**【输出形式】**
一行，格式为：`矩形的面积为: area`

**【样例输入】**

```

3.0
```

**【样例输出】**

```
矩形的面积为: 15.00
```

正确读取矩形的长和宽；正确计算矩形面积；输出格式正确且保留两位小数。

**参考答案（Python）：**

```python
length = float(input().strip())

area = length * width
print("矩形的面积为: {:.2f}".format(area))
```

### 4. 计算商品折扣价格（10.00 分）

**【问题描述】**
输入商品原价和折扣率（如8折输入0.8），计算并输出商品的折后价格，保留两位小数。

一行，格式为：`折后价格为: price`

```
0.8
```

```
折后价格为: 160.00
```

**【样例说明】**
原价 200 元，折扣率 0.8，折后价 $= 200 \times 0.8 = 160.00$

**【评分标准】**
正确读取商品原价和折扣率；正确计算折后价格；输出格式正确且保留两位小数。

**参考答案（Python）：**

```python
price = float(input().strip())
discount = float(input().strip())
final_price = price * discount
print("折后价格为: {:.2f}".format(final_price))
```

### 5. 计算到期本息和（10.00 分）

**【问题描述】**
输入本金、年利率和存款年限，计算并输出到期后的本息和，保留两位小数。
复利计算公式：$\text{本息和} = \text{本金} \times (1 + \text{年利率})^\text{存款年限}$

**【输入形式】**
三行，分别为本金、年利率和存款年限（两个浮点数，一个整数）

**【输出形式】**
一行，格式为：`到期本息和为: amount`

**【样例输入】**

```
10000
0.03
5
```

**【样例输出】**

```
到期本息和为: 11592.74
```

**【样例说明】**
本息和 $= 10000 \times (1 + 0.03)^5 = 11592.74$

**【评分标准】**
正确读取本金、年利率和存款年限；正确计算复利本息和；输出格式正确且保留两位小数。

**参考答案（Python）：**

```python
principal = float(input())
rate = float(input())
years = int(input())
amount = principal * (1 + rate) ** years
print("到期本息和为: {:.2f}".format(amount))
```
