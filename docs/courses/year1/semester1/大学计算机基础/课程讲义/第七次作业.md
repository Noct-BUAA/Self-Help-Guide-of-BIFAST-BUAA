### 1. 统计正整数数量（10.00 分）

**【问题描述】**
输入一行整数，统计其中大于 0 的整数数量。

**【输入形式】**
一行整数，整数之间用空格分隔。

**【输出形式】**
输出一个整数，表示大于 0 的整数的个数。

**【样例输入】**

```
3 -1 0 5 7 -2
```

**【样例输出】**

```
3
```

**【样例说明】**
输入的整数中，大于 0 的数有 3、5、7 共 3 个，因此输出 3。

**【评分标准】**
能准确将输入中大于0的整数数量统计并输出。

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
count = 0
for x in nums:
    if x > 0:
        count += 1
print(count)
```

### 2. 输出所有偶数的平方（10.00 分）

**【问题描述】**
输入一行整数，找出其中所有的偶数，并按输入顺序输出这些偶数的平方，数字之间用空格分隔。

**【输入形式】**
一行整数，整数之间用空格分隔。

**【输出形式】**
一行，所有偶数的平方，使用空格分隔；如果没有偶数，则输出空行。

**【样例输入】**

```
1 2 3 4
```

**【样例输出】**

```
4 16
```

**【样例说明】**
输入的整数中，偶数为 2 和 4，对应的平方为 4 和 16，按顺序输出为 4 16。

**【评分标准】**
准确将输入中的偶数选出，并正确计算输出其平方。

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
res = []
for x in nums:
    if x % 2 == 0:
        res.append(x * x)
print(' '.join(map(str, res)))
```

### 3. 判断字符串是否包含子串（10.00 分）

**【问题描述】**
输入两个字符串 $s$ 和 $t$，判断 $t$ 是否为 $s$ 的子串。如果是，则输出 `Yes`，否则输出 `No`。

### 4. 列表相邻元素最大差值（10.00 分）

**【问题描述】**
输入一行整数，找出相邻两个数之间的差（绝对值）的最大值，并输出该最大差值。

**【输入形式】**
一行整数，整数之间用空格分隔。

**【输出形式】**
一个整数，表示最大相邻差值。

**【样例输入】**

```
5 2 9 3 8
```

**【样例输出】**

```
7
```

**【样例说明】**
相邻差值分别为 3，7，6，5，最大值为 7，因此输出 7。

**【评分标准】**
将输入中相邻数的差值统计并准确输出其中最大值。

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
max_diff = 0
for i in range(1, len(nums)):
    diff = abs(nums[i] - nums[i-1])
    if diff > max_diff:
        max_diff = diff
print(max_diff)
```

### 1. 找出连续出现次数最多的数字及其次数（10.00 分）

**【问题描述】**
输入一行整数（用空格分隔），找到其中连续出现次数最多的数字，输出该数字和它的连续出现次数。

**【输入形式】**
一行整数，整数之间用空格分隔。

**【输出形式】**

- 第一行：连续出现次数最多的数字。
- 第二行：该数字连续出现的次数。

**【样例输入】**

```
1 1 2 2 2 3 3
```

**【样例输出】**

```
2
3
```

**【样例说明】**
数字 1 连续出现 2 次，数字 2 连续出现 3 次，数字 3 连续出现 2 次，其中 2 的连续次数最多，因此输出数字 2 和 3。

**【评分标准】**
准确统计连续出现次数。

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
cur = nums[0]        # cur为当前连续出现的数字，初始化为列表第一个元素
cur_cnt = 1          # cur_cnt为cur连续出现的次数，初始化为1
best_num = cur       # best_num为连续出现次数最多的数字，初始化为第一个cur
best_cnt = 1         # best_cnt为best_num连续出现的次数，初始化为1
for i in range(1, len(nums)):
    if nums[i] == cur:       # 填空：判断条件
        cur_cnt += 1
    else:
        if cur_cnt > best_cnt:
            best_cnt = cur_cnt
            best_num = cur   # 填空：参数状态更新
        cur = nums[i]
        cur_cnt = 1
if cur_cnt > best_cnt:
    best_cnt = cur_cnt
    best_num = cur
print(best_num)
print(best_cnt)
```
