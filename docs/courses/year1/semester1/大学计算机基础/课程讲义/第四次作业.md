### 1. 两数之和（10.00 分）

**【问题描述】**
给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回一个列表，从小到大排列它们的数组下标。

你可以假设每种输入只会对应一个答案。

**【输入形式】**
两行，第一行为整数数组，第二行为目标值

**【输出形式】**
一行，两个整数从小到大排列的数组下标列表

**【样例输入】**

```
2 7 11 15
9
```

**【样例输出】**

```
[0,1]
```

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
target = int(input())
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        if nums[i] + nums[j] == target:
            result = [i, j]
            result.sort()
            print(result)
```

### 2. 计算阶乘（10.00 分）

**【问题描述】**
输入一个非负整数 $n$，计算 $n$ 的阶乘。

**【输入形式】**
一行，一个非负整数 $n$

**【输出形式】**
一行，$n$ 的阶乘

**【样例输入】**

```
5
```

**【样例输出】**

```
120
```

**【样例说明】**
$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$

**参考答案（Python）：**

```python
n = int(input())
fact = 1
for i in range(1, n + 1):
    fact *= i
print(fact)
```

### 4. 列表中的最值（10.00 分）

**【问题描述】**
输入一个整数列表，找出其中的最大值和最小值并输出。

**【输入形式】**
一行，整数列表，元素间用空格分隔

**【输出形式】**
一行，格式为：`最大值: max_value, 最小值: min_value`

**【样例输入】**

```
3 1 4 1 5 9 2 6
```

**【样例输出】**

```
最大值: 9, 最小值: 1
```

**参考答案（Python）：**

```python
a = list(map(int, input().split()))
maxx = a[0]
minn = a[0]
for i in range(1, len(a)):
    if maxx < a[i]:
        maxx = a[i]
    if minn > a[i]:
        minn = a[i]
print("最大值:", maxx, ", ", "最小值:", minn)
```

### 1. 只出现一次的数字（10.00 分）

**【问题描述】**
给定一个非空整数数组，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

**【输入形式】**
一行，整数数组，元素间用空格分隔

**【输出形式】**
一行，只出现一次的数字

**【样例输入】**

```
2 2 1
```

**【样例输出】**

```
1
```

**【样例说明】**
在数组 `[2, 2, 1]` 中，数字1只出现了一次，其他数字都出现了两次。

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
count_dict = {}
for num in nums:
    if num in count_dict:
        count_dict[num] += 1   # 填空更新次数
    else:
        count_dict[num] = 1
for num, count in count_dict.items():
    if count == 1:             # 填空判断条件
        print(num)
        break
```
