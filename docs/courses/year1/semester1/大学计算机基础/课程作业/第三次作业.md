### 1. 列表逆序输出（10.00 分）

**【问题描述】**
输入一个整数列表，将其逆序输出，要求使用切片完成逆序。

**【输入形式】**
一行整数列表（以空格分隔）

**【输出形式】**
逆序后的列表（以空格分隔）

**【样例输入】**

```
1 2 3 4 5
```

**【样例输出】**

```
5 4 3 2 1
```

**【评分标准】**
能正确读取列表，使用切片逆序，正确输出。

**参考答案（Python）：**

```python
lst = list(map(int, input().split()))
for x in range(len(lst)-1, -1, -1):
    print(lst[x], end=" ")
```

### 2. 输出列表前N个元素（10.00 分）

**【问题描述】**
输入一个整数列表和整数 N，输出列表的前 N 个元素。

**【输入形式】**
两行：

- 第一行：整数列表
- 第二行：整数 N

**【输出形式】**
前 N 个整数（空格分隔）

**【样例输入】**

```
1 2 3 4 5
3
```

**【样例输出】**

```
1 2 3
```

**【评分标准】**
能正确截取前 N 个元素并输出。

**参考答案（Python）：**

```python
lst = list(map(int, input().split()))
n = int(input())
sub = lst[:n]
for x in sub:
    print(x, end=" ")
```

### 3. 列表最大值（10.00 分）

**【问题描述】**
列表元素最大值查找。

**【输入形式】**
一行整数列表，中间使用空格。

**【输出形式】**
最大值。

**【样例输入】**

```
1 5 3
```

**【样例输出】**

```
5
```

**【评分标准】**
能正确找到列表元素中最大值。

**参考答案（Python）：**

```python
lst = list(map(int, input().split()))
mx = lst[0]
for x in lst:
    if x > mx:
        mx = x
print(mx)
```

### 1. 列表目标值查找（10.00 分）

**【问题描述】**
输入一个整数列表和目标值，查找目标值在列表中的索引，若未找到则输出 -1。

**【输入形式】**
两行输入，第一行为整数列表（元素以空格分隔），第二行为目标整数

**【输出形式】**
一行，输出目标值的索引或 -1

**【样例输入】**

```
1 3 5 7
5
```

**【样例输出】**

```
2
```

**【评分标准】**
能正确转换输入为列表，准确查找目标值索引，输出结果正确。

**参考答案（Python）：**

```python
lst = list(map(int, input().split()))  # 列表输入
t = int(input())                        # 目标值输入
found = -1                              # 初始化，未找到时返回-1
for i in range(len(lst)):               # 填空满足循环查找条件
    if lst[i] == t:                     # 判断条件填空
        found = i
        break
print(found)
```

### 2. 统计某元素在列表中数目（10.00 分）

**【问题描述】**
输入一个整数列表和一个目标值，统计目标值在列表中出现的次数。

**【输入形式】**

- 第一行：整数列表
- 第二行：目标整数

**【输出形式】**
出现次数。

**【样例输入】**

```
1 2 2 3 2
2
```

**【样例输出】**

```
3
```

**【评分标准】**
正确统计目标值在列表中出现的次数。

**参考答案（Python）：**

```python
lst = list(map(int, input().split()))  # 列表输入
t = int(input())                        # 目标值输入
cnt = 0                                 # 初始化计数器cnt
for x in lst:                           # 遍历列表元素
    if t == x:                          # 填空判断条件
        cnt = cnt + 1                   # 填空执行操作
print(cnt)
```
