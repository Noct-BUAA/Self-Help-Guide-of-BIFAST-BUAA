### 1. 多数元素（10.00 分）

**【问题描述】**
给定一个大小为 $n$ 的数组 `nums`，返回其中的多数元素。多数元素是指在数组中出现次数大于 $\lfloor n/2 \rfloor$ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素，尽量尝试不使用额外的存储空间，达到 $O(1)$ 的空间复杂度。

**【输入形式】**
一行，若干个整数，用空格分隔

**【输出形式】**
数组中的多数元素

**【样例输入1】**

```
3 2 3
```

**【样例输出1】**

```
3
```

**【样例输入2】**

```
2 2 1 1 1 2 2
```

**【样例输出2】**

```
2
```

**【解释】**

- 样例1：数组长度为3，$\lfloor3/2\rfloor = 1$，元素3出现2次 $> 1$，所以输出3
- 样例2：数组长度为7，$\lfloor7/2\rfloor = 3$，元素2出现4次 $> 3$，所以输出2

**参考答案（Python）：** — Boyer-Moore 投票算法

```python
nums = list(map(int, input().split()))
candidate = None
count = 0
for num in nums:
    if count == 0:
        candidate = num
    if num == candidate:
        count += 1
    else:
        count -= 1
print(candidate)
```

### 3. 列表元素去重（10.00 分）

**【问题描述】**
编写一个 Python 程序，输入若干个整数（用空格分隔），输出一个列表，其中包含输入的所有整数（按输入顺序）但去掉重复的元素。

**【输入形式】**
一行，若干个整数，用空格分隔。

**【输出形式】**
一个列表，不含重复元素，保持原顺序。

**【样例输入】**

```
1 2 2 3 4 4 5
```

**【样例输出】**

```
[1, 2, 3, 4, 5]
```

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
result = []
for num in nums:
    if num not in result:
        result.append(num)
print(result)
```

### 1. 矩阵对角线元素之和（10.00 分）

**【问题描述】**
编写一个Python程序，输入一个 $n \times n$ 的矩阵，计算并输出：

- 主对角线元素之和
- 副对角线元素之和

**【输入形式】**

- 第一行：整数 $n$
- 接下来 $n$ 行：每行 $n$ 个整数，用空格分隔

**【输出形式】**

- 第一行：主对角线元素之和
- 第二行：副对角线元素之和

**【样例输入】**

```
3
1 2 3
4 5 6
7 8 9
```

**【样例输出】**

```
15
15
```

**【解释】**

- 主对角线：$1+5+9=15$
- 副对角线：$3+5+7=15$

**参考答案（Python）：**

```python
n = int(input())
matrix = []
for _ in range(n):
    row_str = input().split()
    row_int = []
    for num_str in row_str:
        num = int(num_str)
        row_int.append(num)
    matrix.append(row_int)
main_diag_sum = 0
anti_diag_sum = 0
for i in range(n):
    main_diag_sum += matrix[i][i]
    anti_diag_sum += matrix[i][n-1 - i]
print(main_diag_sum)
print(anti_diag_sum)
```

### 2. 统计奇偶数并排序（10.00 分）

**【问题描述】**
编写一个Python程序，输入若干个整数（用空格分隔），先输出所有的奇数（按输入顺序），再输出所有的偶数（按输入顺序），每个数字用空格分隔。

**【输入形式】**
一行，若干个整数，用空格分隔

**【输出形式】**

- 第一行：所有奇数，空格分隔
- 第二行：所有偶数，空格分隔

**【样例输入】**

```
1 2 3 4 5 6 7 8
```

**【样例输出】**

```
1 3 5 7
2 4 6 8
```

**参考答案（Python）：**

```python
nums = list(map(int, input().split()))
odds = []
evens = []
for num in nums:
    if num % 2 == 1:
        odds.append(num)
    else:
        evens.append(num)
for i in range(len(odds)):
    if i == len(odds) - 1:
        print(odds[i])
    else:
        print(odds[i], end=' ')
for i in range(len(evens)):
    if i == len(evens) - 1:
        print(evens[i])
    else:
        print(evens[i], end=' ')
```
