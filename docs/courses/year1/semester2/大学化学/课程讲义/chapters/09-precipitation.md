# 第9章 沉淀溶解平衡

## 9.1 溶度积常数

!!! abstract "定义"
    在一定温度下，当难溶电解质的沉淀速率与溶解速率相等时，达到沉淀溶解平衡。此时所得溶液为该温度下的饱和溶液，溶质的浓度即为饱和浓度。

对于难溶电解质 $\mathrm{A}_m\mathrm{B}_n(\mathrm{s}) \rightleftharpoons m\mathrm{A}^{n+}(\mathrm{aq}) + n\mathrm{B}^{m-}(\mathrm{aq})$：

!!! success "重要公式"
    溶度积常数：

    $$K_{sp} = [\mathrm{A}^{n+}]^m [\mathrm{B}^{m-}]^n$$

    $K_{sp}$ 是难溶电解质饱和溶液中离子浓度幂的乘积，**仅与温度有关**。

    注意：$K_{sp}$ 表达式中不出现固相的浓度。

## 9.2 沉淀生成的计算与应用

### 9.2.1 溶度积规则

!!! abstract "定义"
    对于难溶电解质，溶液中离子浓度幂的乘积 $Q$（离子积）与 $K_{sp}$ 的比较：

    - **$Q < K_{sp}$**：不饱和溶液，无沉淀生成，固体继续溶解
    - **$Q = K_{sp}$**：饱和溶液，达到溶解平衡
    - **$Q > K_{sp}$**：过饱和溶液，有沉淀生成

### 9.2.2 同离子效应与盐效应

- **同离子效应**：在难溶电解质饱和溶液中加入含有相同离子的易溶强电解质，使难溶电解质的溶解度降低
- **盐效应**：加入不含相同离子的强电解质，使难溶电解质的溶解度略有增大（离子强度增大，活度系数减小）

## 9.3 沉淀的溶解与转化

### 9.3.1 沉淀的溶解

使沉淀溶解的常用方法：

1. 生成弱电解质（如用酸溶解碳酸盐、金属氢氧化物）
2. 发生氧化还原反应
3. 生成配位化合物（络合物）

### 9.3.2 沉淀的转化

!!! abstract "定义"
    将一种难溶电解质转化为另一种更难溶的电解质（$K_{sp}$ 更小）的过程。转化常数：

    $$K = \frac{K_{sp}(\text{原沉淀})}{K_{sp}(\text{新沉淀})}$$

### 9.3.3 分步沉淀

当溶液中含有多种可被同一沉淀剂沉淀的离子时，$Q$ 最先达到 $K_{sp}$ 的离子最先沉淀。通过控制沉淀剂浓度，可以实现离子的分离。

!!! question "典型例题"
    **例题：** 已知 $K_{sp}(\mathrm{AgCl}) = 1.8 \times 10^{-10}$，$K_{sp}(\mathrm{Ag_2CrO_4}) = 1.1 \times 10^{-12}$。某溶液中含有 $\mathrm{Cl^-}$ 和 $\mathrm{CrO_4^{2-}}$，浓度均为 $0.010\ \mathrm{mol \cdot L^{-1}}$，逐滴加入 $\mathrm{AgNO_3}$。问哪种沉淀首先生成？

    **解析：**

    AgCl 开始沉淀所需的 $[\mathrm{Ag^+}]$：

    $$[\mathrm{Ag^+}] = \frac{K_{sp}(\mathrm{AgCl})}{[\mathrm{Cl^-}]} = \frac{1.8 \times 10^{-10}}{0.010} = 1.8 \times 10^{-8}\ \mathrm{mol \cdot L^{-1}}$$

    $\mathrm{Ag_2CrO_4}$ 开始沉淀所需的 $[\mathrm{Ag^+}]$：

    $$[\mathrm{Ag^+}] = \sqrt{\frac{K_{sp}(\mathrm{Ag_2CrO_4})}{[\mathrm{CrO_4^{2-}}]}} = \sqrt{\frac{1.1 \times 10^{-12}}{0.010}} = 1.05 \times 10^{-5}\ \mathrm{mol \cdot L^{-1}}$$

    $1.8 \times 10^{-8} < 1.05 \times 10^{-5}$，故 **$\mathrm{AgCl}$ 首先生成沉淀**。这就是 Mohr 法测定 $\mathrm{Cl^-}$ 的基本原理。
