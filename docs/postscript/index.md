# 后记

## 项目缘起

北航中法未来科技学院（BIFAST）于 2025 年获批成立，首届学生踏入杭州瓶窑校园时，
一切都在"从零开始"——全法语授课的数学课听不懂术语、第一次口语考试不知道从何准备、
杭州新校区的衣食住行全是未知……

这个项目最初只是几份散落在群聊里的笔记和课件。2026 年 6 月，我们决定把这些零散的
资料整理成一份结构化的自助指南，让后来的学弟学妹不用再"重复踩坑"。

## 当前成果

项目运行至今，已完成以下核心建设：

### 课程学习资料

| 板块 | 已建成内容 |
|------|-----------|
| **基础数学** | 6 章完整讲义（逻辑与集合 → 整除关系），含定义、定理证明、例题解析与公式速查表 |
| **数理基础法语（1）** | 7 讲扫描讲义 PDF、课程总览、备考建议 |
| **综合法语（1）** | Inspire A1 教材 + 练习册 PDF、口语考试指南（5 个情景对话）、10 板块系统语法概要、备考建议 |
| **大学计算机基础** | 7 次作业原题 |
| **大学化学** | 10 章完整讲义（物质状态 → 电化学），含例题与公式总结 |
| **航空航天概论** | 课程总览 |
| **大一下学期** | 中国近现代史纲要、人工智能导论、力学、基础英语（2）、数学分析（1）、数理基础法语（2）、综合法语（2）框架已搭建 |

### 校园生活指南

杭州国际校园的住宿、餐饮、交通出行、文化活动 4 个板块，覆盖瓶窑校区的实用信息。

| 项目 | 现状 |
|------|------|
| **网站框架** | MkDocs Material + indigo 主题，亮暗切换、全站搜索、代码复制、评论系统 |

## 如何贡献

本项目完全开源，托管于 [GitHub](https://github.com/Noct-BUAA/Self-Help-Guide-of-BIFAST-BUAA)。

=== "通过 Issue 反馈"

    1. 进入仓库 **Issues** 页面
    2. 点击 **New Issue**
    3. 描述你发现的错误或想补充的内容

=== "通过 Pull Request 贡献"

    1. **Fork** 本仓库到你的 GitHub 账号
    2. 克隆到本地，进行修改
    3. 提交 **Pull Request**
    4. 维护者审核后合并

### 贡献原则

- 内容准确有据，标注信息来源
- 用语简洁，方便学弟学妹理解
- 遵守 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 协议
- 尊重知识产权，引用请注明出处

!!! success "你的每一点贡献都有价值"
    无论是修正一个错别字、补充一门课的笔记、
    还是分享一条校园生活小贴士，都能帮到后来的同学。
