# 后记

## 项目总结

本项目起源于北航中法未来科技学院首届学生在学习和生活中遇到的真实需求和挑战。
作为一所 2025 年全新获批的中外合作办学机构，学院的一切都在"从零开始"——
课程体系在完善、校园文化在形成、生活配套在建设。

项目从最初的简单笔记汇集，逐步发展为覆盖课程学习和杭州校园生活
两大板块的自助指南，凝聚了多位同学的共同努力。

## 项目目标

本项目旨在为北航中法未来科技学院的同学提供一套系统化、社区维护、持续更新的自助参考指南：

| 目标 | 说明 |
|------|------|
| 汇集学习资源 | 整理各专业课程的教学大纲、推荐教材、在线学习平台与学习资料 |
| 解析重难点 | 针对课程中的关键概念和常见难点，提供深入浅出的解析与解题思路 |
| 分享杭州生活经验 | 覆盖杭州国际校园的住宿、餐饮、交通、周边等各方面实用信息 |
| 促进互助共享 | 鼓励同学之间知识共享，形成互帮互助的学习氛围 |

## 使用说明

### 导航方式

- 使用顶部标签页或左侧导航栏浏览各章节
- 使用右上角搜索框快速查找关键词
- 页面右侧目录可快速跳转到当前页面的各小节
- 点击页面底部按钮快速返回顶部

### 页面特性

- 支持亮色/暗色模式切换，保护视力
- 代码块支持一键复制，方便粘贴到本地
- 全文搜索支持中文、英文、法语三语检索
- 每页底部标注最后更新日期

## 如何贡献

本项目完全开源，托管于 [GitHub](https://github.com/Noct-BUAA/Self-Help-Guide-of-BIFAST-BUAA)。
欢迎所有同学参与内容贡献！

=== "通过 Issue 反馈"

    1. 点击仓库页面的 **Issues** 标签
    2. 选择 **New Issue**
    3. 描述你发现的问题或想要补充的内容
    4. 提交后维护者会尽快处理

=== "通过 Pull Request 贡献"

    1. **Fork** 本仓库到你的 GitHub 账号
    2. 在本地克隆并进行修改
    3. 提交 **Pull Request**，描述你的修改内容
    4. 维护者审核通过后合并

### 贡献原则

- 内容应准确可靠，有据可查
- 用语简洁明了，便于理解
- 遵守 CC BY-NC 4.0 开源协议
- 尊重知识产权，引用内容请注明出处

!!! success "一起让这份指南变得更好！"

    无论你是修正一个错别字、补充一门课程的完整笔记，
    还是分享一条杭州校园生活的实用信息，
    你的每一份贡献都能帮助到更多的同学。
