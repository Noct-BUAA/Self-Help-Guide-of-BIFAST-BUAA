# 后记

## 项目总结

本网站是北航中法未来科技学院（杭州）的学习生活自助指南，面向学院在读学生，
汇集课程学习资料与校园生活实用信息。

### 课程学习资料

| 板块 | 已建成内容 |
|------|-----------|
| **大一上学期** | 基础数学（6 章完整讲义）、大学计算机基础（7 次作业原题）、数理基础法语（1）、综合法语（1）（口语考试指南 + 语法概要）、航空航天概论 |
| **大一下学期** | 中国近现代史纲要、人工智能导论、力学、基础英语（2）、大学化学（10 章完整讲义）、数学分析（1）、数理基础法语（2）、综合法语（2）框架已搭建 |
| **大二学年** | 学年框架已搭建，数学分析（3）、几何等课程待充实 |

### 校园生活指南

住宿、餐饮、交通出行、文化活动 —— 四个板块覆盖瓶窑校区日常所需。

### 技术配套

| 项目 | 现状 |
|------|------|
| **网站框架** | MkDocs Material，支持亮暗切换、全站搜索、代码复制 |
| **评论系统** | Giscus，基于 GitHub Discussions |
| **部署** | GitHub Pages 主站 + Vercel 备用站点 |

## 项目目标

本项目旨在为北航中法未来科技学院的同学提供一套系统化、社区维护、持续更新的自助参考指南：

| 目标 | 说明 |
|------|------|
| 汇集学习资源 | 整理各专业课程的教学大纲、推荐教材、在线学习平台与学习资料 |
| 解析重难点 | 针对课程中的关键概念和常见难点，提供深入浅出的解析与解题思路 |
| 分享杭州生活经验 | 覆盖杭州国际校园的住宿、餐饮、交通、周边等各方面实用信息 |
| 促进互助共享 | 鼓励同学之间知识共享，形成互帮互助的学习氛围 |

## 使用说明

### 导航方式

- 使用顶部标签页或左侧导航栏浏览各章节
- 使用右上角搜索框快速查找关键词
- 页面右侧目录可快速跳转到当前页面的各小节
- 点击页面底部按钮快速返回顶部

### 页面特性

- 支持亮色/暗色模式切换，保护视力
- 代码块支持一键复制，方便粘贴到本地
- 全文搜索支持中文、英文、法语三语检索
- 每页底部标注最后更新日期

## 如何贡献

本项目完全开源，托管于 [GitHub](https://github.com/Noct-BUAA/Self-Help-Guide-of-BIFAST-BUAA)。
欢迎所有同学参与内容贡献！

=== "通过 Issue 反馈"

    1. 点击仓库页面的 **Issues** 标签
    2. 选择 **New Issue**
    3. 描述你发现的问题或想要补充的内容
    4. 提交后维护者会尽快处理

=== "通过 Pull Request 贡献"

    1. **Fork** 本仓库到你的 GitHub 账号
    2. 在本地克隆并进行修改
    3. 提交 **Pull Request**，描述你的修改内容
    4. 维护者审核通过后合并

### 贡献原则

- 内容应准确可靠，有据可查
- 用语简洁明了，便于理解
- 遵守 CC BY-NC 4.0 开源协议
- 尊重知识产权，引用内容请注明出处

!!! success "一起让这份指南变得更好！"

    无论你是修正一个错别字、补充一门课程的完整笔记，
    还是分享一条杭州校园生活的实用信息，
    你的每一份贡献都能帮助到更多的同学。
